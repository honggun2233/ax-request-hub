## 1. 개요

### 1.1 목적

전사 AI 도구(GPT, Gemini) 계정을 체계적으로 배분·운영하여 업무 생산성을 높이고, 정보보안 및 비용 통제를 병행한다.

### 1.2 대상 도구 및 계정 한도

| 도구 | 티어 | 계정 한도 | 용도 | 비고 |
|------|------|-----------|------|------|
| ChatGPT (OpenAI) | Chat | 100석 | 문서 작성·요약·분석·프롬프트 기반 업무 | Level 2 대상 |
| ChatGPT (OpenAI) | for Excel/M365 | 50석 | Excel·Word·Outlook AI 기능 | Level 1 대상 |
| Gemini Enterprise (Google) | Enterprise | 50석 | 구글 워크스페이스 통합 AI 기능 | Level 1 대상 |
| **합계** | | **200석** | | |

> ⚠️ 계정 한도는 AX팀이 분기별 재검토한다. 초과 신청 시 대기 큐에 등록.

### 1.3 근거 체계

```
AX-REGULATION-2026-001 제5조 (AI 서비스 승인 기준)
      │
      ├─ AX-POLICY-2026-001 제33조 (리터러시 레벨별 도구 배분)
      │
      └─ 본 가이드 (계정 신청·발급·회수·모니터링 실무 절차)
```

## 2. 계정 배분 기준

> ℹ️ **계약 구조**: 삼성자산운용 ↔ **삼성SDS (턴키)** ↔ OpenAI · Google. 계정 발급·회수는 SDS 담당 채널을 통해 처리된다. 업체(OpenAI/Google)와 직접 연락하지 않는다.

### 2.1 배분 원칙

**개인이 아닌 부서(팀) 단위로 쿼터를 배정**하고, 부서장/본부장이 쿼터 내 배정을 자율 관리한다.

| 역할 | 책임 |
|------|------|
| AX팀 | 부서별 쿼터 설정·조정, 전체 현황 모니터링, SDS 계정 발급 요청 |
| 부서장/본부장 | 쿼터 내 자율 배정·회수·재배정, 분기 현황 보고 |
| 임직원 | 부서장에게 필요성 설명 후 배정 요청 (AX Hub 직접 신청 불가) |

### 2.2 쿼터 산정 공식

```
부서 쿼터 = round( 부서 인원 수 × AI 활용 밀도 가중치 × 조정계수 )
조정계수 : 전체 가중 합산이 200석이 되도록 정규화
```

**AI 활용 밀도 가중치**

| 밀도 | 가중치 | 해당 부서 예시 |
|------|--------|---------------|
| 고밀도 | 2.0 | IT업무개발팀, AX팀, 운용역, 리서치, 전략기획 |
| 중밀도 | 1.5 | 마케팅, 컴플라이언스, 리스크관리, 경영기획 |
| 기본 | 1.0 | 인사, 재무, 후선운영, 기타 |

### 2.3 부서별 초기 쿼터 배분 (안)

> 아래는 산정 공식 적용 예시다. 실제 인원 데이터는 인사팀 협조 후 최종 확정한다.

| 부서/본부 | 인원(안) | 밀도 | 쿼터(안) | 비고 |
|-----------|---------|------|---------|------|
| AX/IT업무개발팀 | 30 | 고밀도 | 28 | GPT Chat 중심 |
| 운용본부 (운용역·리서치) | 60 | 고밀도 | 56 | GPT Chat 중심 |
| 전략기획·마케팅 | 40 | 중밀도 | 28 | GPT Chat + Gemini 혼합 |
| 컴플라이언스·리스크 | 40 | 중밀도 | 28 | GPT for Excel 중심 |
| 경영지원·재무·인사 | 80 | 기본 | 30 | GPT for Excel 중심 |
| 후선·기타 | 250 | 기본 | 30 | Gemini Enterprise 중심 |
| **합계** | **500** | | **200** | |

### 2.4 부서장 관리 위임 규칙

**권한**
- 쿼터 내 자유 배정·회수·재배정 (AX팀 승인 불필요)
- AX Hub 부서장 메뉴에서 계정 배정 신청 및 현황 확인

**제한**
- 타 부서 쿼터 이전 불가 (AX팀 사전 승인 필요)
- G3 데이터 사용 허가 불가 (전사 절대 금지, 부서장 권한 밖)
- 동일인 중복 보유: GPT Chat + GPT for Excel 중복 불가

**분기 재심사 (AX팀 주관)**
- 미사용 쿼터 50% 이상 부서 → 회수 후 수요 부서 재배분
- HR 증원·감원 반영 쿼터 조정
- 한도 증량 필요 시 → SDS 계약 담당자 협의 후 AX위원회 보고

## 3. 계정 배정 절차

임직원이 AX Hub에 직접 신청하지 않는다. **부서장이 쿼터 내에서 배정 권한을 행사한다.**

### 3.1 배정 흐름

```
임직원 → 부서장에게 필요성 구두/이메일 전달
              │
              ▼
        부서장이 AX Hub 부서 관리 메뉴에서 잔여 쿼터 확인
              │
        ┌─────┴──────┐
    쿼터 없음         쿼터 있음
        │                │
   임직원에게         배정 신청 입력
   대기 안내         (도구 선택 + 사유 20자)
                         │
                         ▼
                   AX팀 → SDS 계정 발급 요청
                         │
                         ▼ (통상 1~2영업일)
                   계정 발급 → 임직원 이메일 안내
```

### 3.2 부서 쿼터 소진 시

1. 부서장이 기존 배정자 중 미사용자 회수 후 재배정
2. 회수 후에도 부족하면 AX팀에 쿼터 증량 요청
3. AX팀이 타 부서 미사용 쿼터 회수분에서 조정 (즉시 또는 분기 재심사 시)

### 3.3 발급 후 온보딩

계정 발급 후 **5영업일 이내** 아래를 완료해야 활성화된다.

| 단계 | 내용 | 방법 |
|------|------|------|
| 1. 계정 활성화 | 발급 이메일의 초대 링크 수락 | 이메일 링크 |
| 2. 필수 교육 이수 | AX Hub 리터러시 과정 (1~2시간) | `/me/literacy` |
| 3. 보안 서약 확인 | G1/G2/G3 데이터 사용 제한 확인 | AX Hub 내 전자서약 |

> 5영업일 내 미완료 시 계정 자동 회수 → 부서 쿼터로 반환.

## 4. 사용 정책

### 4.1 데이터 기밀등급별 사용 제한 (**절대 준수**)

| 기밀등급 | GPT Chat | GPT for Excel | Gemini Enterprise |
|---------|----------|---------------|------------------|
| G1 (일반) — 공시자료·뉴스·외부정보 | ✅ 사용 가능 | ✅ 사용 가능 | ✅ 사용 가능 |
| G2 (내부) — 내부 보고서·비공개 운용정보 | ✅ 가능 (업로드 금지) | ✅ 가능 (파일 전송 주의) | ✅ 가능 |
| G3 (기밀) — 미공개정보·투자결정·고객정보 | ❌ **절대 금지** | ❌ **절대 금지** | ❌ **절대 금지** |

> ⚠️ G3 데이터를 외부 AI에 입력하면 자본시장법 위반·미공개정보 유출에 해당할 수 있다.  
> 위반 발견 즉시 정보보호팀(DLP 알림)에 보고되며, 계정 즉시 정지 처리된다.

### 4.2 허용·금지 사용 범위

**허용**
- 공개 자료 요약·번역·편집
- 업무 문서·이메일·보고서 초안 작성
- 코드 리뷰·스크립트 자동화 (G1·G2 코드에 한함)
- 회의록 정리 (G3 언급 내용 제외)

**금지**
- 고객 개인정보·투자자 정보 입력
- 펀드 미공개 운용전략·포지션 입력
- 내부 통제 자료·감사 보고서 전문 입력
- 업무 외 개인 용도 사용

### 4.3 정보보호팀 DLP 연계

- GPT/Gemini 트래픽은 사내 DLP(Data Loss Prevention) 솔루션 모니터링 범위에 포함
- G3 키워드 포함 입력 감지 시 자동 알림 → AX팀 + 정보보호팀 동시 통보

**보고 대상**: AX위원회 (부사장 포함)

| 보고 항목 | 내용 |
|-----------|------|
| 계정 가동률 | 도구별 활성/대기/잔여 현황 |
| 부서별 활용도 | 월별 사용 세션 수 / 부서별 분포 |
| 비용 집계 | 도구별 실사용 비용 (OpenAI·Google 청구서 기준) |
| 보안 이슈 | DLP 탐지 건수 · 조치 결과 |
| 대기 현황 | 신청 중 대기자 수 · 예상 발급 일정 |

### 6.2 비용 관리

- **청구 구조**: SDS 단일 인보이스 수령 (OpenAI + Google 비용 통합 청구). 업체별 개별 청구서 수령 없음.
- AX팀이 SDS 인보이스 기준으로 월 단위 도구별 비용 분리 집계
- CFO 보고 (AX-REGULATION-2026-001 제11조 준용)
- 부서별 사용량 기반 배부율 산정 (2026 Q4부터 부서 원가 배부 검토)
- **DLP 연계**: SDS 경유 트래픽 모니터링 범위 확인 필요 → 정보보호팀 + SDS 3자 협의 후 확정

### 6.3 분기 재심사

매 분기 AX팀이 아래를 점검한다.
1. 90일 미사용 계정 회수 실행
2. 계정 배분 적정성 재검토 (부서 증원·감소 반영)
3. 한도 증액 필요 여부 검토 → AX위원회 보고

| 기능 | 설명 |

## 9. 자주 묻는 질문 (FAQ)

**Q. 레벨이 L0인데 신청할 수 있나요?**  
A. 신청 전 AX Hub `/me/level`에서 Level 1 신청을 먼저 완료해야 합니다.

**Q. GPT Chat과 Gemini를 동시에 쓸 수 있나요?**  
A. 원칙적으로 1인 1도구이지만, 부서장 사유서 제출 시 심사 후 중복 보유 가능합니다.

**Q. 계정을 받았는데 필요 없어졌어요.**  
A. AX Hub `/me/tools`에서 즉시 반납하면 됩니다. 반납 계정은 대기자에게 우선 배정됩니다.

**Q. 출장·휴가 중에도 계정이 유지되나요?**  
A. 90일 이상 장기 미사용이 아니면 유지됩니다. 6개월 이상 장기 휴직 시 일시 정지 가능.

**Q. G2 자료를 ChatGPT에 붙여넣어도 되나요?**  
A. G2 자료의 경우 텍스트 직접 입력은 허용되나, 원본 파일 업로드는 지양하세요. 반드시 개인정보·미공개정보가 포함되지 않았는지 확인 후 사용하세요.

**Q. 계정 문제가 생겼을 때 어디에 문의하나요?**  
A. OpenAI·Google 고객센터가 아닌 **삼성SDS 담당 채널**로 문의하세요. 계약 구조상 SDS가 업체와의 창구 역할을 합니다. AX팀을 통해 SDS에 에스컬레이션합니다.

**Q. 계정 한도를 늘릴 수 있나요?**  
A. SDS와의 계약 변경 사항이므로, AX팀이 분기 재심사에서 증량 필요성을 AX위원회에 보고 후 SDS 계약 담당자와 협의합니다. 자체적으로 바로 증설하는 구조가 아닙니다.
