끊긴 지점 분석 — 총 7개 GAP

G-1
AI-native 인테이크 UI + API — app/projects/new/page.tsx가 여전히 대분류/중분류/소분류 드롭다운. /api/intake/synthesize 미존재.
→ 현재 WIP 에이전트가 구현 중. synthesize API + 3단계 UI 재작성.
G-2
AX팀 AI override UI — Gate 심사 화면에 Qwen 추천 벤더 + 원클릭 변경 버튼 없음. routing.ts는 구현됐지만 UI가 없어서 AX팀이 볼 수가 없음.
→ Gate1~3 심사 페이지에 추천 패널 추가 필요 (수동 경로 전용).
G-3
middleware.ts 서비스토큰 인증 경로 없음 — 현재 NextAuth 세션만 처리. 배포된 에이전트나 배치 작업이 Bearer 토큰으로 호출할 경로가 없어 C트랙 전체가 블로킹.
→ 현재 WIP 에이전트가 구현 중. /api/internal/* 분기 추가.
G-4
ServiceToken 스키마 + 발급 API 없음 — C트랙의 핵심 인증 엔티티. schema.prisma에 ServiceToken 모델 없음, 발급/관리 UI도 없음.
→ G-3와 동시 처리. tokenHash(sha256) 저장, rawToken 1회 노출 방식.
G-5
A트랙 수집 스크립트 없음 — Claude/GPT/Gemini Enterprise Analytics API 수집 배치 스크립트 전무. UsageRecordDaily 스키마는 있지만 데이터가 한 건도 들어오지 않는 상태.
→ Claude Enterprise API Primary Owner 키 발급 (인표님) 후 착수 가능. 코드 결합 없어 병렬 진행 안전.
G-6
ModelProvider 시드 데이터 없음 — ModelProvider 스키마는 있지만 anthropic/openai/gemini/onprem 4개 레코드가 없어 라우팅 기본 동작 불가.
→ G-1 에이전트에서 함께 처리 중.
G-7
A+B+C 통합 대시보드 없음 — 경영진이 "이번 달 AI 비용 총액"을 볼 방법 없음. 세 트랙이 각자 안정화되기 전까지는 재료 자체가 없음.
→ G-3·G-4·G-5 완료 후 착수. 현재 착수 시점 아님.
