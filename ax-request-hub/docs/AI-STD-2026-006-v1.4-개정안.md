# AI 과제 개발 표준 (전사용)

| 항목 | 내용 |
|------|------|
| 문서번호 | AI-STD-2026-006 |
| 버전 | v1.4 |
| 최종 개정일 | 2026-09-07 |
| 적용범위 | AX Hub 등록 및 전사 배포 대상 AI 과제 |
| 근거 | 「AI 운영 규정」 제5조, 「AI 운영 지침」 제9~11조, 「AI 거버넌스 규정」 AI-REG-003 제8조④⑤ |
| 담당 | AX팀 |

---

## 1. 적용 대상

- AX Hub에 과제 신청 후 전사 배포를 목표로 개발하는 모든 AI 과제
- 개인 업무 자동화(배포 없음), PoC 단계(승인 전), 개인 실험은 미적용

---

## 2. 개발 3단계

### Phase 1 — PoC (임직원 자체 개발)

필수 준수사항 2가지:
- **샘플·더미 데이터만 사용** (운영 DB·개인정보·기밀 문서 사용 금지)
- **AX Hub 과제 등록** (전사 배포 목표 시 개발 착수 전에 신청)

**외부 AI API 사용 기준**: PoC 단계에서 Claude·GPT API 등 외부 AI 서비스를 직접 연동할 때는 아래 기준을 준수한다.

| 기밀등급 | 외부 AI API 연동 가능 여부 |
|---------|--------------------------|
| G1(공개정보) | 허용 |
| G2(대외비) | 허용 (파일 업로드 및 대량 전송 주의) |
| G3(기밀·극비) | **절대 금지** — 온프레미스 모델만 사용 |

**Phase 1 완료 시 AX팀 인수 제출물**:

| 제출물 | 내용 |
|--------|------|
| 핵심 기능 시연 | 로컬·개발 환경에서 동작 확인 가능한 상태 |
| 입출력 명세 | 입력 데이터 형식, 출력 결과 형식 문서화 |
| 버전관리 저장소 | GitHub private 또는 내부 GitLab 등록 (기밀 데이터 연동 시 내부 GitLab 필수) |
| 데이터 기밀등급 명시 | G1 / G2 / G3 중 해당 등급 표시 |

위 4가지 모두 준비되면 AX Hub 과제 상세 화면에서 **"인수 신청"**을 클릭한다.

### Phase 2 — AX팀 검토 및 Gate 통과

Gate 2 기술 자가점검 **6항목** (전부 충족 필수):

> **v1.4 개정**: 4항목에서 6항목으로 확대. R-07(데이터 무결성), R-09(Human-in-the-loop) 2개 항목 추가.
> 근거: 「AI 거버넌스 규정」 AI-REG-003 제8조④(데이터 검증 의무)·제8조⑤(인간 검토 절차 의무)
> AX Hub 기술 표준 검증 시스템이 이미 6항목 기준으로 운영 중 — 문서와 시스템 기준을 일치시킴.

| 항목 | 요건 | 관련 조항 |
|------|------|----------|
| API 명세 | 입력·출력 인터페이스 문서화 | — |
| 데이터 기밀 처리 계획 | 일반/내부/기밀 등급 분류 및 처리 계획 | — |
| 감사로그 설계 | 주요 이벤트 로그 구조·보존 기간 | — |
| 테스트 커버리지 | 비즈니스 로직 단위 테스트 80% 이상 | — |
| **데이터 무결성 검증 (R-07)** | **입출력 데이터 유효성 검증 절차 수립** | **AI-REG-003 제8조④** |
| **Human-in-the-loop 절차 (R-09)** | **AI 결과를 사람이 검토·승인하는 절차 정의** | **AI-REG-003 제8조⑤** |

미충족 시 보류 (거부 아님), AX팀 컨설팅 후 재신청 가능.

### Phase 3 — 전사 배포

임직원이 직접 운영 인프라에 배포하지 않는다. AX팀이 결과물을 인수하고, AI데이터플랫폼팀이 배포 환경을 결정하여 배포 처리한다.

|------|------|
| 언어 | Python 3.10+, TypeScript 5+ |
| 컨테이너 | Docker 25+ |
| 의존성 | requirements.txt 또는 package.json 고정 버전 관리 |

## 개정 메모 (결재 상신용)

**개정 사유**: AX Hub의 기술 표준 검증 시스템(Gate 2 하드블록)이 2026-09-07 기준 6항목으로 운영 중인데, 공식 문서(v1.3)는 4항목만 기재되어 문서-시스템 간 불일치 상태. 추가된 2항목(R-07·R-09)은 「AI 거버넌스 규정」AI-REG-003 제8조④⑤에 근거가 있어 문서에 명시적으로 반영하는 것이 타당함.

**결재선 제안**: AX팀 검토 → AX/PI센터장 결재 → 배포
