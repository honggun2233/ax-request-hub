## 2. AI 에이전트 운영 관리 프로세스

**(1) 에이전트 유형 분류 및 등재 기준**

AI 솔루션을 자율성 기준 4단계로 분류하며, 유형 2 이상은 AX팀 과제 등록 절차 이행 필요.

| 유형 | 정의 | 등재 요건 |
|------|------|---------|
| 유형 1 | 규칙 기반 자동화 (AI 판단 없음) | 없음 |
| 유형 2 | AI 직접 활용·다단계 워크플로 (사람 확인 포함) | AX팀 과제 등록 |
| 유형 3 | AI가 도구를 자율 호출하는 에이전트 | 과제 등록 + Agent ID 발급 + Kill Switch 필수 |
| 유형 4 | 멀티 에이전트 협업 시스템 | 유형 3 요건 + AX 위원회 최종 승인 |

**(2) 우수 에이전트 선정 및 보상**

분기 1회 심사. 운영(Active) 90일 이상 에이전트 대상. 100점 만점 평가 (KPI 달성률 30·ROI 실현 25·지속 활용 20·문서화 15·혁신성 10).

- **우수 에이전트 (80~89점)**: AX팀장 포상 추천, 차기 과제 우선 배정, 사내 공유
- **탁월 에이전트 · AX Excellence (90점 이상)**: AX/PI센터장 표창, 성과 인센티브 연계, 전사 발표

**(3) AI 산출물 내부 지식화**

AI 활용 결과를 조직 자산으로 축적하기 위해 3단계로 평가, 반기 AX 위원회 보고.

① **기록** — 과제 정의서·프롬프트 GitHub 저장·감사 로그 완비 (분기 측정)

② **재사용** — Prompt Caching 적용, 기존 사례 인용, 이관 재작업율 30% 이하 관리 (반기 측정)

③ **이전** — 담당자 교체 시에도 에이전트 독립 운영 가능 여부 확인 (반기 측정)

## 3. 생성형 AI 도입 및 운영

**(1) 기업용 AI 모델 배분 기준**

GPT(OpenAI)·Claude(Anthropic)·Gemini(Google) 3개 공급사 지원. 사용자 임의 선택 금지. CREW 등급·과제 위험등급·데이터 기밀등급 기준 AX팀 배분.

| CREW 등급 | 허용 모델 | 접근 경로 |
|---------|---------|---------|
| Lv.1 탐색 | GPT Enterprise (Copilot), Claude.ai | 사내 SSO 통합 도구, 개인 API 키 발급 불가 |
| Lv.2 실험 | 위 Lv.1 + AX 샌드박스 API (Sonnet·GPT-4o·Gemini Flash) | AX팀 발급 공유 키, 샌드박스·G1 전용 |
| Lv.3 개발 / AX 엔지니어 | 전 모델 (위험등급 준수) | 과제별 전용 API 키 |

| 기밀등급 | 허용 경로 |
|---------|---------|
| G1 일반 | 모든 AI 서비스 (Copilot, Claude.ai, Google Workspace) |
| G2 내부제한 | 사내 승인 인프라 (AWS Bedrock VPC, Azure Private Endpoint) |
| G3 기밀 | 온프레미스 전용 (인터넷 차단 환경) |

**(2) 활용 현황 모니터링 및 관리 방안**

AI 서비스 사용 내역을 과제·목적·보안등급별로 추적·기록하고, 전사→과제→건별 3단계 비용 한도를 설정하여 예산 초과 시 자동 차단.

| 한도 단계 | 기준 | 초과 시 조치 |
|---------|------|-----------|
| 전사 월 한도 | 전체 AI 서비스 비용 상한 | 신규 과제 착수 금지 |
| 과제별 월 한도 | 과제 등록 시 사전 확정 금액 | 해당 과제 자동 정지 |
| 건별 상한 | 1회 AI 호출 최대 비용 | 해당 요청 차단 |

알림 기준: 월 한도 80% 도달 시 AX팀장·담당 CREW 통보 / 100% 도달 시 고위험 과제 자동 정지 / 전주 대비 사용량 2배 초과 시 24시간 내 원인 파악·조치.

**(3) AI 리터러시 제고 방안 — AI CREW 체계**

AI를 "쓰는 사람"에서 "과제를 설계하는 사람"으로 키우기 위해, 전 임직원 중 AI 과제 선도 담당자를 'AI CREW'로 선발·운영. 코딩 경험 없이도 Lv.1부터 진입 가능하며, 성과에 따라 AX팀이 등급 부여·갱신(연 1회 이상).

| 등급 | 역할 | AX팀 지원 | 진입 조건 |
|------|------|---------|---------|
| Lv.1 탐색 | No-Code 도구로 업무 아이디어 발굴·간단 자동화 시도 | 기초 교육 + 30분 시작 가이드 제공 | 누구나 자원신청 |
| Lv.2 실험 | 팀 내 PoC 설계, 파일럿 UAT 수행 | AX 샌드박스 API 제공, 1:1 기술 자문 | Lv.1 과제 1건 완료 |
| Lv.3 개발 | AX팀과 공동 개발, 실운영 에이전트 구축 | 공동 개발·고급 템플릿·우선 과제 배정 | Lv.2 PoC + AX팀 심사 |

운영 방식:
- **진입**: AX팀에 자원신청 → 부서 배정·초기 교육 → Lv.1 활동 시작
- **성과 공유**: 완료 과제(성공·실패 모두)를 사내 채널에 사례 형태로 공유하여 조직 전체 학습 가속
- **팀장 역할**: 소속 CREW 자원 승인, 파일럿 기간 데이터 제공·일정 지원
- **동기부여**: 분기별 기여 우수 CREW를 AX/PI센터장에게 보고하여 공식 인정 및 성과 인센티브 연계 예정
