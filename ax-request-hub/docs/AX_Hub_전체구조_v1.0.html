AX Request Hub — 전체 시스템 구조서

삼성자산운용 전사 AI 거버넌스 허브 · 내부 배포용 참고문서 (honggun2233/ax-request-hub PRIVATE)

🎯 1. 시스템 목표

삼성자산운용 전사 AI 도입을 신청 → 평가 → 데이터 연계 → 개발/파일럿 → 협의회 상용 전환 → 운영/폐기 전 과정을 하나의 시스템으로 추적·거버넌스한다.

문제
AI 도입 과제가 파악 안 됨
답
정형 신청 폼 + 자동 스코어카드로 전수 등록
문제
승인 근거가 남지 않음
답
AuditLog + ScoreCard + CouncilAgendaItem으로 모든 의사결정 추적
문제
데이터 사용 통제 불가
답
DataRequest → DataProvision 흐름으로 데이터 이력 관리
문제
에이전트 상태를 아무도 모름
답
AgentRegistry 단일 모델 + 이중 라이프사이클
문제
AI 도구 계정 난립
답
ToolAccount + DepartmentQuota + DistributionPolicy로 통제

⚠️ 9. 미결 사항

SQLite → PostgreSQL 전환
