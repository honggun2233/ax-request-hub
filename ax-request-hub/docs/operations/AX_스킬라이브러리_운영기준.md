## 1. 목적 및 적용 범위

전사 AI 스킬 라이브러리의 등록·운영·폐기 기준을 명시하여 고품질 프롬프트 자산을 체계적으로 관리한다.

**적용 대상:** AI 스킬을 등록하는 AX팀, 스킬을 사용·평가하는 전 직원

---

## 2. 스킬 분류 체계

### 2-1. 카테고리

| 카테고리 | 설명 | 예시 |
|----------|------|------|
| ETF운용 | ETF 가격·성과 분석, NAV 점검 | ETF NAV 이상 점검, 모멘텀 분석 |
| 리서치 | 보고서·공시·뉴스 요약·분석 | 리서치 보고서 요약 |
| 업무자동화 | 반복 문서 작업, 회의록, 메일 초안 | 회의록 작성, 업무 메일 초안 |
| 데이터분석 | SQL/Python 쿼리 생성, 데이터 해석 | 데이터 분석 쿼리 생성 |
| 문서작성 | 보고서, 기획서, 발표 자료 초안 | |
| 기타 | 위 분류에 해당하지 않는 일반 스킬 | |

### 2-2. 보안 등급

| 등급 | 의미 | 허용 범위 |
|------|------|-----------|
| G1 | 일반 | 전 직원 열람·사용 가능 |

## 3. 스킬 등록 절차

### 3-1. 등록 주체

- **등록 권한:** AX팀 (`AX_TEAM` 역할)
- **제안 가능:** 전 직원 (AX팀에 제안 이메일 또는 이슈 제출)

### 3-2. 등록 검토 기준

등록 전 다음 항목을 확인한다.

| 검토 항목 | 기준 | 미충족 시 |
|-----------|------|-----------|
| 명확한 목적 정의 | `purpose` 필드 50자 이상 | 반려 |
| 사용 지침 구체성 | `instructions` 필드에 단계별 안내 포함 | 보완 요청 |
| 프롬프트 텍스트 존재 | `promptText` 비어있지 않음 | 반려 |
| 보안 등급 적정성 | G3 키워드(개인정보·미공개 수익률) 미포함 | 등급 상향 또는 반려 |
| 적용 가이드 | `cautions` 필드에 오남용 방지 문구 | 보완 요청 |
| 중복 여부 | 기존 스킬과 목적 90% 이상 중복 여부 확인 | 기존 스킬 업데이트 권고 |

### 3-3. 부적절 프롬프트 필터링 기준

다음에 해당하면 등록을 거부하고 제안자에게 사유를 통보한다.

1. **기밀 정보 포함**: 미공개 펀드 수익률, 개인정보(사번·계좌), 내부 시스템 접근 정보
2. **외부 기관 사칭**: 특정 외부 기관·경쟁사의 내부 지침 흉내
3. **규제 위반 소지**: 금융투자업 관련 법규 위반 가능성이 있는 투자 권고 프롬프트
4. **과도한 자동화**: 인간 검토 없이 실제 거래·발주를 유발할 수 있는 프롬프트
5. **저작권 침해**: 외부 저작물을 무단으로 포함한 프롬프트 템플릿

## 4. 스킬 평가 운영 기준 (SkillRating 기반)

### 4-1. 평가 방법

- 스킬 사용 후 `/api/skills/rate` POST를 통해 1~5점 + 코멘트 제출
- 직원 1인당 스킬 1개에 최대 1회 평가 (중복 방지 `@@unique([skillId, employeeEmail])`)

### 4-2. 평가 기반 품질 관리

| 기준 | 조치 |
|------|------|
| 평균 평점 ≤ 2.0 (평가 10건 이상) | AX팀 검토 → 개선 또는 폐기 검토 |
| 평균 평점 ≥ 4.5 (평가 10건 이상) | 베스트 스킬 태그 부여, 온보딩 자료에 포함 |
| 부정적 코멘트 3건 이상 누적 | 즉시 AX팀 검토, 필요 시 사용 중단 |

### 4-3. 사용 빈도 추적

- `Skill.usageCount` 필드로 누적 사용 횟수 관리
- 90일간 `usageCount` 증가 없는 스킬 → 검토 대상 목록 등재

## 5. 스킬 폐기 기준 및 절차

### 5-1. 폐기 트리거

다음 조건 중 하나 이상 충족 시 폐기(`status = deprecated`) 전환 검토:

| 조건 | 판단 기준 |
|------|-----------|
| 낮은 평점 | 평균 ≤ 2.0 (평가 10건 이상) |
| 장기 미사용 | 90일 이상 `usageCount` 변화 없음 |
| 기반 서비스 변경 | 대상 AI 도구(ChatGPT·Gemini 등) 모델 변경으로 프롬프트 작동 방식 변화 |
| 보안 이슈 발생 | 스킬 사용 중 기밀 정보 노출 사고 발생 |
| 규정 변경 | AI 거버넌스 지침 개정으로 내용이 규정에 위배 |

### 5-2. 폐기 절차

1. AX팀이 폐기 사유를 내부 검토
2. 대체 스킬이 있으면 `instructions` 또는 이메일로 대체 스킬 안내
3. `status = deprecated`로 전환 (UI에서 검색 결과 노출 제외)
4. 3개월 후 데이터 영구 삭제 또는 별도 아카이브 보존 결정

## 6. 버전 관리

- 스킬 내용 변경 시 `version` 필드 업데이트 (예: `1.0.0` → `1.1.0`)
- 기존 버전 삭제 없이 버전 문자열로 변경 이력 추적
- 주요 변경 내용은 `purpose` 또는 `instructions`에 괄호로 버전 노트 추가
