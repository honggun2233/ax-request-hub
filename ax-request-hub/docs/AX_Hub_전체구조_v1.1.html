1. 시스템 목표

삼성자산운용 전사 AI 도입을 신청 → 평가 → 데이터 연계 → 개발/파일럿 → 협의회 상용 전환 → 운영/폐기 전 과정을 하나의 시스템으로 추적·거버넌스한다.

해결하려는 문제AX Hub의 답
AI 도입 과제가 파악 안 됨정형 신청 폼 + 자동 스코어카드로 전수 등록
승인 근거가 남지 않음AuditLog + ScoreCard + CouncilAgendaItem으로 모든 의사결정 추적
데이터 사용 통제 불가DataRequest → DataProvision 흐름으로 데이터 이력 관리
에이전트 상태를 아무도 모름AgentRegistry 단일 모델 + 이중 라이프사이클
AI 도구 계정 난립ToolAccount + DepartmentQuota + DistributionPolicy로 통제

2. 전체 플로우 다이어그램

신청·평가 직원 /chat → /submit 신청 → G3 판정: G3이면 Claude API 생략, AX팀 수동 검토 → 6차원 Claude 자동 스코어링 (100점) → 70점+ AND G1/G2: 자동 파일럿 승인 → AgentRegistry 생성(devStage=GATE1) → 나머지: AX팀 에스컬레이션 → 수동 승인/반려 데이터 연계 PILOT 착수 → 데이터 필요 여부 확인 → /data/catalog 탐색 → DataRequest 신청 (ACCESS or NEW) → 데이터플랫폼팀 검토(/dp/requests) └─ G3 기밀: 정보보호 협의 추가 → 승인: DataProvision 생성 (이용기간 설정) → GATE2 → GATE3 → 파일럿 운영 에이전트 라이프사이클 파일럿 KPI 실증(최소 1개월) → 협의회 상정 (안건 5종) → 의결: ├─ 승인: phase=PRODUCTION / prodStatus=ACTIVE ├─ 조건부: 조건이행 후 재상정 └─ 반려/기각: 개발 복귀 or 종료 상용 운영(월별 KPI 추적) → 폐기 조건 충족: DEPRECATED(30일 예고) → RETIRED → DataProvision 전건 자동 회수

8. 핵심 서브시스템

8-1. 과제 신청 · 평가 · 승인

직원 /chat → AI 상담 → /submit 신청서 확인 → G3 판정: G3이면 Claude API 생략, AX팀 수동 검토 (P1-1) → 6차원 Claude 자동 스코어링 (100점) → 70점+ AND G1/G2: 자동 파일럿 승인 → AgentRegistry 생성(devStage=GATE1) → 나머지: AX팀 에스컬레이션 → 수동 승인/반려 → 이의제기: /api/projects/[id]/appeal (신청→처리, P1-3)
차원배점
비즈니스 임팩트25점
ROI25점
기밀등급 적합성15점
기술 난이도15점
AI 준비도10점
전략 정합성10점

8-2. 에이전트 이중 라이프사이클

개발 트랙 (devStage): SUBMITTED → EVALUATED → GATE1 → GATE2 → GATE3 → PILOT_PROVEN → COUNCIL_PENDING → COND_APPROVED ※ GATE1→GATE2: DataRequest 전건 PROVISIONED 필수 ※ COUNCIL_PENDING: 협의회 안건 상정 대기 전환점: 협의회 의결 (CouncilAgendaItem) — 이것 없이 상용 전환 불가 상용 트랙 (prodStatus): ACTIVE → SUSPENDED / DEPRECATED(30일 예고) → RETIRED └─ RETIRED 시: DataProvision 전건 자동 회수 (미결 §7)

8-3. 데이터 프로비저닝

/data/catalog 탐색 → DataRequest 신청 (type: ACCESS=기존자산 이용 / NEW=신규수집) → DATA_PLATFORM 검토(/dp/requests) └─ G3 기밀: 정보보호 협의 추가 → 승인: DataProvision 생성 (deliveryMode: API/FILE/DB, connectionRef, expiresAt) → 상용 전환 시: 파일럿 제공 만료 → forProduction=true 재신청 필수

8-4. AI 도구 계정 · 토큰 관리

  • GPT 150석 + Gemini 50석 (총 200석) → DepartmentQuota로 부서별 배분

  • /admin/tools/quota-setup에서 AX팀이 전체 쿼터 조정
  • ToolAccount → UsageRecord → UsageAlert → 초과 시 자동 알림
