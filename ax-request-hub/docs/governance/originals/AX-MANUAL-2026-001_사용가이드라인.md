## 1단계 — 신청 방법 선택

AI 도입 과제를 신청하는 방법은 두 가지다. 아이디어가 막연하면 AI 상담 챗을 먼저 이용한다.

### 방법 A — AI 상담 챗 (추천)

이런 경우에 적합:
- 아이디어는 있지만 표현이 막막할 때
- "이게 AI로 가능한지" 먼저 물어보고 싶을 때
- 비슷한 사례를 먼저 들어보고 싶을 때

접속: `/chat` 페이지 → AI 어드바이저에게 업무 고민을 자유롭게 이야기하면, 대화가 끝날 때 신청서를 자동으로 완성해준다.

### 방법 B — 직접 신청서 작성

이런 경우에 적합:
- 과제 내용이 이미 구체적으로 정해진 경우
- 이전에 챗으로 신청서 초안을 만든 후 제출
- 팀 회의에서 정리된 내용을 바로 입력할 때

접속: `/submit` 페이지 → 신청서 양식을 직접 작성한다. 각 필드 아래 예시와 팁을 참고하면 높은 점수를 받을 수 있다.

## 2단계 — 신청서 잘 쓰는 법 (점수 올리는 팁)

신청서 품질이 AI 평가 점수에 직접 영향을 미친다.

| 항목 | 낮은 점수 예시 | 높은 점수 예시 |
|------|---------------|---------------|
| 현재 업무 방식 (As-Is) | 현재 수작업으로 처리하고 있습니다 | 운용팀 3명이 매월 1회 Excel로 보고서 초안을 작성하며 건당 약 4시간 소요. 오탈자·수치 오류가 월평균 2건 발생 |
| 기대 효익 | 시간이 많이 절감될 것 같습니다 | 보고서 작성 시간 90% 단축 (4시간→30분). 3명×12회 기준 연 126시간 절감. 수치 오류 제로화 |
| 예상 사용자 수 | 여러 명 | 초기 파일럿: 운용팀 3명. 검증 후 리스크팀·준법감시팀 포함 15명으로 확대 예정 |

### 기밀등급 선택 가이드

| 등급 | 해당 데이터 | AI 서비스 범위 |
|------|------------|----------------|
| G1 일반 | 공시자료, 뉴스, 업계 보고서, 인터넷 공개 정보 | 외부 AI 서비스 제한 없음 (Claude, ChatGPT 등) |
| G2 내부제한 | 사내 업무문서, 회의자료, 내부 보고서, 비공개 분석자료 | AX팀 승인 AI 서비스만 사용 가능 |
| G3 기밀 | 고객 개인정보(PI), 운용 포지션, 미공개 투자정보, 내부 전략문서 | 외부 AI 금지. 사내 온프레미스만 허용 |

## 3단계 — 제출 후 처리 절차

| 단계 | 처리 | 내용 |
|------|------|------|
| ① | 제출 | 신청서 작성 완료 후 제출 |
| ② | AI 평가 | 6차원 자동 평가 (약 30초 소요) |
| ③ | 점수 산출 | 100점 만점 스코어카드 생성 |
| ④ | 승인 판정 | G1/G2 + 70점 이상 → 자동 파일럿 승인 / 68~70점 → AX팀장 검토 / G3 또는 68점 미만 → 상위 결재 |
| ⑤ | 알림 발송 | 결과를 텔레그램으로 신청자에게 발송 |

> **Gate 2 자가점검(기술표준 4개 항목: API 명세·기밀처리·감사로그·테스트 80%)은 초기 신청 단계가 아니라 PoC 완료 후 AX팀 인수 신청 시 별도 제출한다.**

**자동 파일럿 승인 (G1/G2 · 70점 이상)**
- 평가 완료 즉시 파일럿 진행 허가
- AX팀에 자동 통보(팀장 포함 메시지 알림)
- 30일·90일 후 실효과 측정

**검토 요청 (68점 이상 70점 미만)**
- AX팀장 검토 후 승인 또는 보완 요청
- 5영업일 내 회신

**상위 결재 (G3 또는 68점 미만)**
- 컴플라이언스 검토 후 팀장/본부장 결재
- 최대 10영업일 내 처리
- 보완 요청 시 수정 후 재제출 가능

## 4단계 — AI 상담 챗 100% 활용하기

AI 상담 챗(`/chat`)은 신청 도우미 외에도 다음과 같이 활용할 수 있다.

| # | 활용 방법 | 예시 질문 |
|---|-----------|-----------|
| 1 | 가능성 탐색 | "펀드 운용보고서를 AI로 자동 작성하는 게 가능한가요?" |
| 2 | 사례 검색 | "국내 자산운용사에서 AI를 도입한 사례가 있나요?" |
| 3 | 범위 조정 | "리스크 관리 전체를 AI로 하려는데 너무 큰 것 같아요" |
| 4 | 아이디어 구체화 | "뭔가 문서 작업을 줄이고 싶은데 어디서 시작해야 할지..." |
| 5 | 신청서 작성 | "신청서 작성해줘" 또는 대화가 자연스럽게 마무리될 때 |

## 6단계 — 데이터 카탈로그 검색·신청·제공 실무 가이드

AI 과제 개발에 데이터플랫폼팀 관리 데이터가 필요한 경우, 아래 4단계 절차를 따른다.  
(규정 근거 → `AX-POLICY-2026-001_AI거버넌스지침.md` 제27조의2·제27조의3)

### 1단계: DataAsset 카탈로그 탐색

AX Request Hub `/data/catalog` 페이지에서 필요한 데이터 자산을 검색한다.

| 항목 | 방법 |
|------|------|
| 검색 | 키워드·부서·기밀등급으로 필터 |
| 상세 확인 | 데이터 명칭, 기밀등급(G1/G2/G3), 갱신 주기, 데이터 오너 |
| 유무 판단 | 검색 결과 있음 → 이용 신청(ACCESS) / 없음 → 신규 수집 요청(NEW) |

### 2단계: DataRequest 신청

해당 자산 → [이용 신청] 또는 [신규 요청] 버튼을 누른 후 아래 항목을 기재한다.

| 항목 | 내용 |
|------|------|
| 사용 목적 | AX Request Hub 과제 번호 포함. AI 추론·학습·조회 등 용도 구분 |
| 기밀등급 | G1/G2/G3 선택 (데이터플랫폼팀 Data Owner 확인으로 최종 확정) |
| 이용 기간 | 파일럿 기간 또는 상용 운영 기간 명시 |
| 갱신 주기 | 실시간 / 일배치 / 주배치 중 선택 |
| 인터페이스 방식 | DB 직접 조회 / REST API / 파일 드롭 중 선택 |

> ※ **G3 기밀 데이터**를 신청하는 경우 데이터플랫폼팀이 정보보호 협의(기밀 검토)를 추가로 진행하므로 승인까지 추가 시간이 소요될 수 있다.

### 3단계: DATA_PLATFORM(데이터플랫폼팀) 검토

데이터플랫폼팀이 `/dp/requests`에서 신청 건을 검토한다.

| 결과 | 처리 |
|------|------|
| 승인(ACCESS) | 즉시 제공 — 연결 정보 발급 |
| 승인(NEW) | 신규 수집·적재 완료 후 카탈로그 등록 → 제공 |
| 반려 | 반려 사유 통보. 재신청 시 새 DataRequest 생성 |

### 4단계: DataProvision 제공 확인

승인 완료 시 `/me/data`에서 제공 현황(연결 정보·이용기간·상태)을 확인한다.

> ⚠️ **Gate 진행 조건**: 데이터가 필요한 과제는 DataRequest 전건이 PROVISIONED 상태가 되어야 GATE1 → GATE2 전환이 가능하다. 데이터 제공 완료 전까지 Gate 2 진행 불가.

> ⚠️ **상용 전환 시 재신청 필수**: 파일럿용 제공분은 상용 전환 시 만료 처리된다. 상용 기준(가용성·갱신주기·계정 분리)으로 신규 DataRequest(forProduction=true)를 제출하여 별도 재승인을 받아야 한다.

## 자주 묻는 질문 (FAQ)

**Q1. AI 아이디어가 있는데 실현 가능한지 모르겠어요.**  
먼저 `/chat`에서 AI 어드바이저에게 물어보세요. "이런 업무를 AI로 할 수 있나요?"라고 자유롭게 물어보면 됩니다.

**Q2. 점수가 낮게 나왔어요. 재신청할 수 있나요?**  
네, 가능합니다. 평가 근거를 확인해 As-Is 상세화, 효익 수치화, 챔피언 지정 후 재신청하면 점수가 올라갑니다.

**Q3. G3 기밀 과제는 아예 AI를 못 쓰나요?**  
아닙니다. 외부 AI(Claude, ChatGPT 등)는 사용 불가하지만, 사내 온프레미스 AI 인프라는 사용 가능합니다. AX팀에 문의하세요.

**Q4. 챔피언이 없어도 신청할 수 있나요?**  
네, 선택사항입니다. 다만 챔피언이 있는 과제가 평가 점수(준비도 차원)에서 3점 추가 반영됩니다.

**Q5. 파일럿 승인 후 전사 확대는 어떻게 하나요?**  
파일럿 30일, 90일 효과 측정 후 AX팀과 협의하여 확대 계획을 수립합니다.

**Q6. 신청서를 제출했는데 평가에 얼마나 걸리나요?**  
AI 자동 평가는 약 30초 내에 완료됩니다. 결과는 텔레그램 알림으로 즉시 발송됩니다.

**Q7. 이미 파일럿 중인데 비슷한 과제를 다시 신청해도 되나요?**  
가능합니다. 범위가 다르거나 다른 팀에서 적용하는 경우 별도 과제로 신청하세요. AX팀과 사전 협의를 권장합니다.

**Q8. 대시보드 접근 권한은 어떻게 받나요?**  
AX팀 및 팀장급 이상에게 기본 접근 권한이 부여됩니다. 추가 접근이 필요하면 AX팀에 문의하세요.

**Q9. 신청서 초안을 저장해뒀다가 나중에 제출해도 되나요?**  
현재 버전에서는 자동 저장 기능이 없습니다. AI 상담 챗에서 대화 후 신청서를 완성하면 곧바로 제출하는 것을 권장합니다.

**Q10. 운영 중 문제 발생 시 어떻게 신고하나요?**  
AI 활용 과정에서 발생한 오류나 보안 이슈는 **AX팀에 즉시 보고**하세요. AX팀이 접수 후 필요 시 컴플라이언스팀으로 에스컬레이션합니다. 시스템 오류는 AX Request Hub 내 [문의하기]를 이용하세요.
