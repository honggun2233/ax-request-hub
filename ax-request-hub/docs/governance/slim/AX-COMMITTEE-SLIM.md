## 제1장 AX 위원회

**제1조 (구성)**

| 역할 | 담당 |
|------|------|
| 위원장 | AX/PI센터장 |
| 위원 | CCO, CRO, CISO, 현업임원 |
| 간사 | AX팀장 |

정기회의: 반기 1회 | 긴급 시 임시 소집

**제2조 (의결·심의 사항)** *(생략 — 원본 참조)*

**제3조 (안건 유형)**

| 코드 | 내용 |
|------|------|
| PROD_APPROVAL | 파일럿 완료 에이전트 상용 전환 심의 |
| RETIRE_APPROVAL | 상용 에이전트 폐기 의결 |
| MAJOR_CHANGE | 모델 교체·데이터 등급 변경·운영 범위 확대 심의 |
| PILOT_EXTENSION | 파일럿 30일 초과 연장 |
| EMERGENCY | 즉시 중단·보안 사고 대응 |

**제4조 (상정 요건)**
PROD_APPROVAL: devStage ≥ GATE3 + KPI 실측 30일 이상 + KPI 달성 (시스템 자동 검증).
**KPI 미달 안건도 사유서 첨부 시 조건부 상정 가능** — 승인 여부는 의결로 판단.

**제5조 (위임전결 — 신설)**
다음 안건은 AX위원회 갈음하여 **실무협의체 전결**로 처리. 결과는 차기 위원회에 일괄 보고.
1. 저위험 에이전트(운영기준 §3)의 PROD_APPROVAL·RETIRE_APPROVAL
2. PILOT_EXTENSION 전건
3. 데이터 등급·운영 범위 변경 없는 경미한 MAJOR_CHANGE

> ⚠️ G3 취급 에이전트·고위험 에이전트는 위임 대상 제외.

**제6조 (서면결의 — 신설)**
위원장 인정 시 회의 소집 없이 서면(전자결재 포함)으로 의결 가능.
EMERGENCY는 위원장 선조치 후 사후 서면결의로 갈음 가능.

**제7조 (의결 유형)**

| 코드 | 시스템 처리 |
|------|-------------|
| APPROVED | prodStatus=ACTIVE. 감사 로그 기록. |
| CONDITIONAL | 이행 조건 전건 완료 + 간사 확인 → ACTIVE (재상정 불필요) |
| REMANDED | GATE3 회귀. 보완 후 재상정 가능. |
| REJECTED | 재상정 불가. 개발 라이프사이클 종료. |
| DEFERRED | 차기 회의 이월, 사유 기록. |

## 제2장 AX 실무협의체

**제8조 (구성 및 권한)**

| 항목 | 내용 |
|------|------|
| 구성 | 유관 부서장, AX팀장 |
| 정기회의 | 월 1회 |
| 권한 | 제5조 위임전결 안건 심의·의결 |

**제9조 (역할)**
1. 고위험 Agent 식별 및 통제 절차 수립
2. 현업 개발 Agent 표준화·안정성 검증 후 위원회 상정
3. Agent 운영 현황·개선·폐기 시점 협의 (라이프사이클 관리)
4. Agent 성능 평가 및 보상 제안
5. 파일럿 KPI (30일·90일) 결과 검토 및 전사 확대 권고
6. 위임전결 안건 처리 및 위원회 보고
