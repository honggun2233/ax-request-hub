## 제1장 AX 위원회

**제1조 (AX위원회 구성)**

| 역할 | 담당자 |
|------|--------|
| 위원장 | AX/PI센터장 |
| 위원 | CCO, CRO, CISO, 현업임원 |
| 간사 | AX팀장 |

정기회의: **반기 1회**

**제2조 (의결 및 심의 사항)** *(생략 — 원본 참조)*

**제3조 (상용 전환 심의 안건 5종)**

| 코드 | 내용 |
|------|------|
| PROD_APPROVAL | 파일럿 완료 에이전트 상용 전환 심의 |
| RETIRE_APPROVAL | 상용 에이전트 폐기 의결 |
| MAJOR_CHANGE | AI 모델 교체·데이터 등급 변경·운영 범위 확대 심의 |
| PILOT_EXTENSION | 파일럿 기간 30일 초과 연장 의결 |
| EMERGENCY | 즉시 중단(SUSPENDED) 또는 보안 사고 긴급 심의 |

**제4조 (상용 전환 상정 요건 — 3개 전부 충족 필수)**

1. devStage ≥ **GATE3**
2. 파일럿 KPI 실측 **30일 초과** + 실적 데이터 존재
3. 파일럿 목표 **KPI 달성**

**제5조 (협의회 의결 유형)**

| 코드 | 시스템 처리 |
|------|-------------|
| APPROVED | prodStatus=ACTIVE. 감사 로그 기록. |
| CONDITIONAL | 이행 조건 전건 완료 후 AX 간사 확인 → ACTIVE (재상정 불필요) |
| REMANDED | devStage=GATE3 회귀. 보완 후 재상정 가능. |
| REJECTED | 재상정 불가. devStage=CLOSED. |
| DEFERRED | 차기 협의회 이월. |

## 제2장 AX 실무 협의체

**제6조 (실무 협의체 구성)**

| 항목 | 내용 |
|------|------|
| 구성 | 유관 부서장, AX팀장 |
| 정기회의 | **월 1회** |

**제7조 (실무 협의체 역할)**

1. 고위험 Agent 식별 및 통제 절차 수립
2. 현업 개발 Agent 표준화 여부·안정성 검증 후 AX위원회 상정
3. Agent 운영 현황·개선방안·폐기시점 협의 (Life-Cycle 관리)
4. AI 활용 결과 및 기여도 분석 → Agent 성능평가 및 보상 제안
5. 파일럿 KPI 30일·90일 실측 결과 검토 및 전사 확대 권고
