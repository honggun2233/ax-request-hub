## 제1장 총칙

**제1조 (목적)**
AI 도입 과제의 신청·평가·승인·개발·데이터 활용·상용 운영 절차를 정한다. 수치 기준·처리 기한·기술 기준은 **운영기준(별표)**에 따른다.

---

## 제2장 과제 신청 및 평가

**제2조 (신청 방법)**
소정의 신청서에 필요 항목을 기재하여 AX팀에 제출한다. 제출 방법·절차는 매뉴얼에 따른다.

**제3조 (신청 항목)**
과제명, 신청 부서·담당자, 현재 업무 방식(As-Is), 기대 효익, 데이터 기밀등급, 예상 사용자 수. 챔피언은 선택(지정 시 가점 — 운영기준 §1).

**제4조 (AI 자동 평가)**
6개 차원(파급 영향력·ROI·기밀등급·구현 용이성·실행 준비도·AX 전략 정합성) 100점 만점 자동 평가. 차원별 배점은 **운영기준 §1**.

**제5조 (승인 절차)**
기밀등급·위험도에 따라 ① 자동 승인, ② AX팀장 검토, ③ 상위 결재 중 하나를 거쳐 파일럿 착수를 승인한다. 세부 기준 및 처리 기한은 **운영기준**에 따른다. 기밀 데이터 취급 과제는 데이터플랫폼팀 추가 협의 필수.

---

## 제3장 개발 단계 (Gate)

**제6조 (개발 3단계)**

| 단계 | 주체 | 완료 기준(요지) |
|------|------|----------------|
| ① 탐색·프로토타이핑 | 개발 담당 임직원(크루) | 핵심 기능 작동, 데이터 플로우·입출력 명세 |
| ② AX 기획 검토 | AX팀 기획자 | SRS, 기밀등급 확정, 배포 환경 결정 |
| ③ 고도화 개발 | AX 엔지니어 | QA 통과, Runbook, 보안 점검 |

단계별 이관 기준·테스트 커버리지는 **위험등급별로 차등 적용 — 운영기준 §4**.

**제7조 (Gate 2 기술표준 자가점검)**
PoC 완료 후 AX팀 인수 신청 시 API 명세, 기밀 처리 계획, 감사로그 설계, 테스트 커버리지 4항목 자가점검.
- 커버리지 기준: **위험등급별 — 운영기준 §4**
- 미충족 항목: **보완계획서 제출을 조건으로 다음 단계 진행 허용** (전사 배포 전까지 보완 완료)

**제8조 (개발 기준)** *(생략 — `AX_개발표준_전사AI과제용.md` 참조)*

---

## 제4장 배포 환경

**제9조 (배포 환경 결정)**
기밀등급·처리 요건에 따라 결정. 사용 가능한 환경 목록은 운영기준에 따른다.

| 순서 | 판단 기준 | 결정 방향 |
|------|-----------|-----------|
| 1 | 기밀 데이터(최고 기밀등급) 처리 여부 | 온프레미스 환경만 허용 |
| 2 | 실시간·대용량 또는 코어 시스템 연동 필요 여부 | 사내 클라우드 환경 우선 |
| 3 | 단기 실증 + 기밀 데이터 미처리 여부 | AX팀 승인 외부 클라우드 AI 서비스 허용 |
| 4 | 기준 충돌 또는 판단 어려운 경우 | AX팀장 결정 |

---

## 제5장 데이터 활용 (데이터플랫폼팀 연계)

**제10조 (협업 원칙)**
1. 데이터 소싱 협의: AX 기획 검토 단계 착수 시점에 개시.
2. 데이터플랫폼팀 데이터 무단 복사·미승인 외부 AI 전달 금지.
3. 기밀등급: 데이터플랫폼팀 Data Owner 확인으로 확정.

**제11조 (데이터 프로비저닝 절차)**

| 단계 | 처리 | 담당 |
|------|------|------|
| ① 카탈로그 탐색 | 데이터 검색·기밀등급 확인 | 개발 담당자 |
| ② 이용 신청 | 보유 데이터 신청 / 미보유 신규 수집 요청 | 개발 담당자 |
| ③ 검토 | 품질·등급 검토. 기밀 데이터는 정보보호 협의 추가 | 데이터플랫폼팀 |
| ④ 제공 | 승인 시 연결 정보 발급·이용기간 설정 | 데이터플랫폼팀 |

**제12조 (데이터 플로우 문서화)** *(생략 — 운영 세부사항)*

**제13조 (Gate 진행과 데이터 제공)**
원칙: 신청 데이터 전건 제공 완료 후 Gate 2 진행.
**예외: 일부 데이터 지연 시 AX팀장 승인으로 조건부 진행 허용.**

**제14조 (상용 전환 시 데이터 재승인)**
원칙: 파일럿용 제공분 만료 → 상용 기준으로 재신청.
**예외: 저위험 과제 + 이용 조건 동일 → 이용기간 연장 신청으로 갈음 가능.**

## 제6장 에이전트 라이프사이클

**제15조 (이중 라이프사이클)**
- **개발**: 신청 → 평가 → 파일럿 승인 → 기술표준 충족 → 개발 완료 → 파일럿 KPI 실증 → 협의회 상정
- **상용**: 운영 → 일시중단 → 폐기예고 → 폐기
- 라이프사이클 전환은 AX위원회 의결(위임전결 포함)로만. 단계별 상태값: **운영기준 §5**.

**제16조 (Agent 위험등급)**
고위험·중위험·저위험 3등급. 등급별 심의 주체·기술 기준·모니터링 강도 차등. 분류 기준: **운영기준 §3**.

**제17조 (Agent 평가와 자산화)** *(생략 — 운영 세부사항)*

## 제7장 비용 및 효과 관리

**제18조 (AI 운영비용)**
1. AI 관련 비용의 집행·승인은 회사 예산관리 규정 및 관련 내부통제 절차에 따른다.
2. AX팀은 AI 과제별 운영비용을 정기 집계하여 관련 부서에 보고한다.
3. 전사 확대 수반 과제의 비용은 회사 경영계획 수립 절차에 따라 반영한다.

**제19조 (파일럿 효과 측정)**

| 측정 시점 | 항목 | 담당 |
|-----------|------|------|
| 도입 전 (기준선) | 처리 시간·인원·오류·비용 | 챔피언이 과제 관리 포털에 기록 |
| 30일 후 | 시간 절감률·만족도·오류 감소율 | 챔피언 실측치 입력 |
| 90일 후 | ROI·확대 가능성·AI 비용 대비 절감액 | 챔피언 + AX팀 공동 확인 |

측정 기한 기준: **운영기준 §2**.

---

## 제8장 시스템 운영

**제20조 (시스템 가용성·보존)**
- AI 과제 관리 포털: 평일 업무시간 기준 안정 운영 목표. 장애 또는 미운영 시 AX팀이 대체 신청 경로를 안내.
- 과제·평가 데이터 보존 기간 및 채팅로그 암호화 기준: **운영기준 §7**.

**제21조 (지침의 개정)** AX팀 주관 개정, 연 1회 이상 정기 검토.
