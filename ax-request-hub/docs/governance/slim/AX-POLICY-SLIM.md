## 제4장 AI 서비스 운영 기준

**제11조 (AI 운영비용 관리)**

1. AI API 호출 비용(외부 서비스), 클라우드 인프라 비용, 라이선스 비용은 AX팀이 월 단위로 집계하여 CFO에게 보고한다.
2. 과제별 예상 AI 운영비용이 AX팀이 별도 공고하는 기준금액 초과 시 CFO 사전 승인을 받은 후 파일럿을 진행한다.
3. 비용 효율 목표: 과제 도입 1년 내 AI 운영비용이 절감된 인건비의 **30% 미만** 유지를 권고 기준으로 한다.

**제12조 (금지 행위)**  
임직원은 AI 서비스를 이용하여 다음 행위를 하여서는 아니 된다.

1. G3 기밀 데이터를 외부 AI 서비스(클라우드 기반)에 입력하는 행위
2. 고객의 개인정보 또는 비공개 운용 포지션을 AI에 입력하는 행위
3. AI 생성 결과물을 검토 없이 공식 법적 문서, 투자설명서 등에 사용하는 행위
4. AI 서비스를 통해 내부 전략, M&A 관련 정보 등 중요 미공개정보를 처리하는 행위
5. 업무 무관한 개인적 목적을 위해 회사 AI 인프라 또는 API 예산을 사용하는 행위
6. AX팀의 비용 승인 없이 AX팀 공고 기준금액 초과 AI API 서비스를 과제에 적용하는 행위

**제13조 (AI 생성물 사용 기준)**

1. AI 생성 보고서, 분석 자료는 반드시 담당자가 내용을 검토·확인 후 사용한다.
2. AI 생성물을 근거로 투자 의사결정을 하는 경우 AI 활용 사실을 의사결정 문서에 명시한다.
3. 대외 공개 자료 또는 규제 제출 문서에 AI 생성물을 사용하는 경우 컴플라이언스 사전 검토를 받는다.

## 제8장 데이터 플랫폼팀 연계 및 플로우

**제25조 (데이터 플랫폼팀 협업 원칙)**

1. 데이터 소싱 협의는 AX 기획자 검토 단계(제19조 2단계) 착수 시점에 개시한다.
2. DT팀 데이터를 무단으로 복사하거나 사내 승인 없이 외부 AI 서비스에 전달하여서는 아니 된다.
3. 데이터 기밀등급은 DT팀 데이터 오너(Data Owner)의 확인을 받아 결정한다.

**제26조~제27조** *(생략 — 데이터 요청 표준 양식 및 플로우 문서화 기준)*

**제27조의2 (에이전트 이중 라이프사이클 — 개발/상용 분리)**  
AI 에이전트는 개발 라이프사이클과 상용 라이프사이클을 엄격히 분리하여 운영한다. Gate 3 통과 또는 파일럿 KPI 달성만으로는 상용 전환되지 않는다. 전환점은 **협의회 의결 하나뿐**이다.

**개발 라이프사이클 (DEVELOPMENT)**

| 단계 | 상태(devStage) | 설명 |
|------|---------------|------|
| 과제 신청 | SUBMITTED | 신청서 제출 완료 |
| 자동 평가 | EVALUATED | 6차원 스코어카드 생성 완료 |
| 승인(파일럿 착수) | GATE1 | 자동 또는 AX팀 검토 승인 |
| 기술 표준 충족 | GATE2 | Gate 2 자가점검 4항목 통과 + 데이터 PROVISIONED |
| 개발 완료 | GATE3 | 개발·테스트 통과 + 운영 Runbook 완성 |
| 파일럿 KPI 실증 | PILOT_PROVEN | 파일럿 KPI 최소 30일 실측 완료 |
| 협의회 상정 대기 | COUNCIL_PENDING | 상정 요건 충족 → 협의회 심의 대기 |

> ※ 데이터가 필요한 과제는 DataRequest 전건 PROVISIONED 확인 후 GATE1 → GATE2 전환 가능.

**상용 라이프사이클 (PRODUCTION)**

| 상태(prodStatus) | 설명 |
|-----------------|------|
| ACTIVE | 정상 상용 운영 중 |
| SUSPENDED | 운영 이슈·보안 사고·데이터 회수 등으로 일시 중단 |
| DEPRECATED | 폐기 예고 (30일 전 공지, 협의회 보고) |
| RETIRED | 폐기 완료 — 지식 추출·산출물 보존·데이터 제공 전건 회수 |

**제27조의3 (데이터 프로비저닝 절차)**

| 단계 | 처리 | 담당 |
|------|------|------|
| ① 카탈로그 탐색 | `/data/catalog`에서 검색 및 기밀등급 확인 | 개발 담당자 |
| ② DataRequest 신청 | ACCESS(보유) 또는 NEW(신규). 용도·이용기간·기밀등급 필수 기재 | 개발 담당자 |
| ③ DT팀 검토 | G3는 정보보호 협의 추가 | 데이터플랫폼팀 |
| ④ DataProvision 제공 | 승인 시 연결 정보 발급·이용기간 설정 | 데이터플랫폼팀 |
| ⑤ Gate 전환 | 전건 PROVISIONED 확인 후 GATE1 → GATE2 허용 | 시스템 자동 |

> ※ 상용 전환 시 파일럿 제공분 만료 처리 + forProduction=true로 신규 DataRequest 재승인 필수.

## 제9장 AX 위원회 및 실무 협의체 운영

**제28조 (AX위원회 구성 및 운영)**

- 위원장: AX/PI센터장. 위원: CCO·CRO·CISO·현업임원. AX팀장 간사. 반기 1회 정기회의.
- AX위원회 심의 사항: 전사 AI 전략·로드맵 승인 / AI 투자(예산) 승인 / Agent 상용 전환 심의 및 Agent-HR 등재 승인

**[상용 전환 심의 상정 요건 — 3개 전부 충족 시에만 상정]**

1. devStage ≥ **GATE3**
2. 파일럿 KPI 실측 기간 **30일 초과** + 실적 데이터 존재
3. 파일럿 목표 **KPI 달성**

**제29조** *(생략 — 실무협의체 구성·운영 상세)*

**제29조의2 (협의회 의결 유형)**

| 의결 | 코드 | 시스템 처리 |
|------|------|-------------|
| 승인 | APPROVED | prodStatus=ACTIVE |
| 조건부 승인 | CONDITIONAL | 이행 조건 전건 완료 후 AX 간사 확인 → ACTIVE (재상정 불필요) |
| 반려 | REMANDED | devStage=GATE3 회귀. 보완 후 재상정 가능 |
| 최종 반려 | REJECTED | 재상정 불가. devStage=CLOSED |
| 보류 | DEFERRED | 차기 협의회 이월 |

## 제10장 AI Agent 운영 관리

**제30조 (Agent 위험 등급 분류)**

- **고위험**: 대외 고객 응대·핵심 전략·개인정보 취급·시스템 직접 변경. 출시 전 보안·규제 심사 + 상시 모니터링 필수.
- **중위험**: 내부 업무 프로세스 자동화·비기밀 데이터 분석. Human-in-the-loop 최종 검토.
- **저위험**: 단순 규정 조회·공개 데이터 리서치. 표준 운영 절차 준수.
