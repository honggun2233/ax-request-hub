## 1. AI 스킬 관리 체계

### 스킬 파일 헤더 표준 (필수)

```markdown
---
id: skill-{카테고리}-{이름}
name: 스킬명
version: 1.0.0
category: ETF운용 / 업무자동화 / 리서치 / 문서작성 / 데이터분석
author: 이름 (부서)
approved_by: AX팀
status: active / deprecated / draft
security_level: G1 / G2 / G3
---
```

### 권한 구분

| 역할 | 권한 |
|------|------|
| 전사원 | AX Hub `/skills` G1 스킬 조회·복사 |
| 해당 부서원 | G2 스킬 접근 (부서 승인 후) |
| 크루 (제안자) | GitLab MR 생성 (스킬 초안 제출) |
| AX팀 | MR 리뷰·승인·머지, 스킬 폐기 결정 |
| 정보보호팀 | G3 스킬 접근 제한·감사 |

## 2. 거버넌스 문서 관리 SSOT 원칙

**.md 파일 = 원본. Word = 보고·배포용 변환본.**

### 문서 상황별 참조 기준

| 상황 | 참조 문서 |
|------|-----------|
| AI 과제 신청 전 금지행위 체크 | AX-REGULATION 제7조 |
| 신청서 작성 | AX-MANUAL 2단계 (점수 올리는 팁) |
| 개발 착수 시 기술 스택 | AX_개발표준 §4 (강제 스택) |
| Gate 2 통과 준비 | AX_AI개발플로우 §4 (자가점검 4항목) |
| 스킬 찾을 때 | AX Hub `/skills` 카탈로그 |

### 개정 절차

| 변경 유형 | 절차 |
|-----------|------|
| 경미한 수정 (오타·사실 수정) | 담당자 직접 수정 → AX팀장 승인 → 반영 |
| 내용 변경 (조항 추가·삭제·정책 변경) | MR 생성 → AX팀 + 관련 부서 리뷰 → 부사장 승인 → 반영 → 전사 공지 |

**정기 현행화**: 분기 1회 (1·4·7·10월) — 담당 AX팀.

## 3. A2A 에이전트 환경 — 단계별 로드맵

### Phase 1 — 현재 (2026-07): Human-to-Agent 안착

```
사용자 → AX Hub → [평가 에이전트] → 승인/반려 결과
```

완료 기준: 월 과제 신청 **10건 이상**, 자동승인율 **60% 이상**  
잔여 과제: Gate 2 실질화, 운용역 리뷰 체계 완성

### Phase 2 — 2026-Q4: Agent-to-Agent 기본

```
오케스트레이터 에이전트
    ├→ 컴플라이언스 검토 에이전트 (자동 규정 확인)
    ├→ 기술 검토 에이전트 (Gate 2 자가점검 자동화)
    └→ 문서 생성 에이전트 (승인결과 자동 문서화)
```

선행 조건: **정보보호팀과 MCP 서버 보안 요건 협의** 필요

### Phase 3 — 2027-H1: 전사 에이전트 네트워크

에이전트가 DMS·데이터플랫폼·ETF운용시스템·AX Hub API를 자율 호출하여 멀티스텝 업무 자동 처리.

### A2A 거버넌스 원칙

- 에이전트 모든 작업 → AX Hub에 과제로 등록
- G3 데이터 접근 → 에이전트도 사람과 동일한 승인 절차 적용
- 분기 1회 감사팀이 에이전트 행동 로그 검토
