## 1단계 — 신청 경로 선택

AI 도입 과제 신청 경로는 다음 두 가지로 구분한다.

### 신청 경로 A — AI 채팅 이용

과제 내용이 명확하지 않거나 사전 검토가 필요한 경우 이 경로를 이용한다.

접속: `/chat` 페이지에서 업무 내용을 입력하면 AI가 과제 요건을 정리하고 신청서 초안을 생성한다. 초안 확인 후 제출한다.

### 신청 경로 B — 신청서 직접 작성

과제 내용이 구체적으로 확정된 경우 이 경로를 이용한다.

접속: `/submit` 페이지에서 신청서 양식을 직접 작성하여 제출한다.

## 2단계 — 신청서 작성 기준

「AI 운영 지침」 제5조에 따라 신청서에는 다음 항목을 기재한다.

| 기재 항목 | 작성 기준 |
|-----------|-----------|
| 과제명 | 도입 목적이 명확하게 드러나도록 기재한다 |
| 신청 부서·담당자 | 부서명 및 담당자 성명을 기재한다 |
| 기대 효익 | 정량 수치를 포함하여 기재한다 (예: 처리 시간 단축, 오류 감소 등) |
| 취급 데이터의 개요 | 과제에서 활용하는 데이터의 종류와 기밀등급을 기재한다 |

### 기밀등급 선택 기준

| 등급 | 해당 데이터 | AI 서비스 범위 |
|------|------------|----------------|
| G1 일반 | 공시자료, 뉴스, 업계 보고서, 인터넷 공개 정보 | 외부 AI 서비스 사용 가능 |
| G2 내부제한 | 사내 업무문서, 회의자료, 내부 보고서, 비공개 분석자료 | 승인된 AI 서비스만 사용 가능 |
| G3 기밀 | 고객 개인정보(PI), 운용 포지션, 미공개 투자정보, 내부 전략문서 | 외부 AI 사용 금지. 사내 온프레미스 환경만 허용 |

## 3단계 — 제출 후 처리 절차

| 단계 | 내용 |
|------|------|
| ① 제출 | 신청서 작성 완료 후 제출 |
| ② AI 평가 | 6차원 자동 평가 (약 30초 소요) |
| ③ 점수 산출 | 100점 만점 스코어카드 생성 |
| ④ 승인 판정 | G1/G2 + 70점 이상 → 자동 파일럿 승인 / 68~70점 → 검토 / G3 또는 68점 미만 → 상위 결재 |
| ⑤ 알림 발송 | 처리 결과를 신청자에게 발송 |

> **기술표준 자가점검(Gate 2)**: API 명세·데이터 보호 조치 계획·감사 기록 설계·테스트 수준의 4개 항목은 초기 신청 단계가 아니라 PoC 완료 후 고도화 개발 인수 신청 시 별도 제출한다.

**자동 파일럿 승인 (G1/G2 · 70점 이상)**
- 평가 완료 즉시 파일럿 진행 허가
- 30일·90일 후 실효과 측정 등록

**검토 요청 (68점 이상 70점 미만)**
- 담당자 검토 후 승인 또는 보완 요청
- 5영업일 내 회신

**상위 결재 (G3 또는 68점 미만)**
- 컴플라이언스 검토 후 팀장·본부장 결재
- 최대 10영업일 내 처리
- 보완 요청 시 수정 후 재제출 가능

## 4단계 — AI 채팅 활용

AI 채팅(`/chat`)은 과제 신청 지원 외에도 다음과 같이 활용할 수 있다.

| # | 활용 방법 | 예시 |
|---|-----------|------|
| 1 | 도입 가능성 검토 | "펀드 운용보고서를 AI로 자동 작성하는 게 가능한가요?" |
| 2 | 사례 조회 | "국내 자산운용사에서 AI를 도입한 사례가 있나요?" |
| 3 | 과제 범위 조정 | "리스크 관리 전체를 AI로 하려는데 범위 조정이 필요할까요?" |
| 4 | 과제 요건 구체화 | "문서 작업 자동화를 검토 중인데 어디서 시작해야 할지 안내해 주세요." |
| 5 | 신청서 작성 지원 | 대화 내용을 바탕으로 신청서 초안 생성 |

| 화면 | 내용 |
|------|------|

| 칸반 보드 | 신청 대기 → 평가 중 → 승인됨 / 부서별 필터링 / 과제 클릭 시 상세 스코어카드 확인 |
| 거버넌스 로그 | `/governance` — AI 자동 승인 이력 전체 기록 / 정책 버전별 변경 이력 |
| 에이전트 레지스트리 | `/registry` — 전사 AI 에이전트 라이프사이클 관리. [에이전트 뷰]: 파이프라인 바 필터(DEVELOPING→ACTIVE) + 카드에 소속 프로젝트 태그 표시. [프로젝트 뷰]: 프로젝트별 소속 에이전트 목록 조회. 에이전트 클릭 → 슬라이드오버에서 Gate 진행도·신뢰점수 태깅·프로젝트 연결 관리 가능. |

## 6단계 — 데이터 카탈로그 검색·신청·제공 절차

AI 과제 개발에 데이터플랫폼팀 관리 데이터가 필요한 경우 다음 4단계 절차를 따른다.

### 1단계: 카탈로그 탐색

AX Request Hub `/data/catalog` 페이지에서 필요한 데이터 자산을 검색한다.

| 항목 | 방법 |
|------|------|
| 검색 | 키워드·부서·기밀등급으로 필터 |
| 상세 확인 | 데이터 명칭, 기밀등급(G1/G2/G3), 갱신 주기, 데이터 오너 |
| 유무 판단 | 검색 결과 있음 → 이용 신청(ACCESS) / 없음 → 신규 수집 요청(NEW) |

### 2단계: 데이터 이용 신청

해당 자산 → [이용 신청] 또는 [신규 요청] 버튼을 선택하여 아래 항목을 기재한다.

| 항목 | 내용 |
|------|------|
| 사용 목적 | AX Request Hub 과제 번호 포함. AI 추론·학습·조회 등 용도 구분 |
| 기밀등급 | G1/G2/G3 선택 (데이터플랫폼팀 Data Owner 확인으로 최종 확정) |
| 이용 기간 | 파일럿 기간 또는 상용 운영 기간 명시 |
| 갱신 주기 | 실시간 / 일배치 / 주배치 중 선택 |
| 인터페이스 방식 | DB 직접 조회 / REST API / 파일 드롭 중 선택 |

> ※ G3 기밀 데이터를 신청하는 경우 데이터플랫폼팀이 정보보호 협의를 추가로 진행하므로 승인까지 추가 시간이 소요될 수 있다.

### 3단계: 데이터플랫폼팀 검토

데이터플랫폼팀이 `/dp/requests`에서 신청 건을 검토한다.

| 결과 | 처리 |
|------|------|
| 승인(ACCESS) | 즉시 제공 — 연결 정보 발급 |
| 승인(NEW) | 신규 수집·적재 완료 후 카탈로그 등록 → 제공 |
| 반려 | 반려 사유 통보. 재신청 시 새 신청 건 생성 |

### 4단계: 제공 확인

승인 완료 시 `/me/data`에서 제공 현황(연결 정보·이용기간·상태)을 확인한다.

> ⚠️ **Gate 진행 조건**: 데이터가 필요한 과제는 데이터 신청 전건이 PROVISIONED 상태가 되어야 GATE1 → GATE2 전환이 가능하다.

> ⚠️ **상용 전환 시 재신청**: 파일럿용 제공분은 상용 전환 시 만료 처리된다. 상용 기준으로 신규 신청하여 별도 재승인을 받아야 한다.

## 자주 묻는 질문

**Q1. 과제 내용이 구체적이지 않은 경우 어떻게 신청하나요?**  
`/chat` 페이지에서 업무 내용을 설명하면 AI가 과제 요건을 정리하고 신청서 초안을 생성해준다. 초안 확인 후 제출한다.

**Q2. 평가 점수가 낮게 나온 경우 재신청할 수 있나요?**  
가능하다. 스코어카드의 평가 근거를 확인하여 기대 효익을 수치화하고 취급 데이터 개요를 보완한 후 재신청한다.

**Q3. G3 기밀 데이터를 취급하는 과제는 AI를 사용할 수 없나요?**  
외부 AI 서비스 사용은 금지되나, 사내 온프레미스 AI 인프라는 사용 가능하다. AX팀에 문의한다.

**Q4. 과제 책임자를 지정하지 않아도 신청할 수 있나요?**  
가능하다. 과제 책임자 지정은 선택사항이다.

**Q5. 파일럿 승인 후 전사 확대는 어떻게 진행하나요?**  
파일럿 30일·90일 효과 측정 결과를 등록한 후 AX팀과 협의하여 확대 계획을 수립한다.

**Q6. 신청서 제출 후 평가에 얼마나 걸리나요?**  
AI 자동 평가는 약 30초 내에 완료된다.

**Q7. 이미 파일럿 중인 과제와 유사한 과제를 별도로 신청해도 되나요?**  
범위 또는 적용 대상이 다른 경우 별도 과제로 신청한다. 사전에 AX팀과 협의할 것을 권장한다.

**Q8. 대시보드 접근 권한은 어떻게 부여받나요?**  
AX팀 및 팀장급 이상에게 기본 접근 권한이 부여된다. 추가 접근이 필요한 경우 AX팀에 문의한다.

**Q9. AI 활용 중 오류 또는 보안 이슈가 발생한 경우 어떻게 신고하나요?**  
소속 부서장에게 즉시 보고한다. 시스템 오류는 AX Request Hub 내 [문의하기]를 이용한다.
