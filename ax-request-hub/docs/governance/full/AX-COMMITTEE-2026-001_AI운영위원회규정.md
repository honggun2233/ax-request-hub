## 제1장 AX 위원회

**제1조 (구성)**
전사 AI 도입 전략의 최종 의사결정 기구로 AX위원회를 둔다.

| 역할 | 담당 |
|------|------|
| 위원장 | AX/PI센터장 |
| 위원 | CCO, CRO, CISO, 현업임원 등 |
| 간사 | AX팀장 |

- 정기회의 반기 1회, 긴급 사안 시 간사가 임시회의 소집. 회의는 오프라인 진행을 원칙으로 하며, AX팀(간사)이 안건 편성과 의결 결과를 시스템에 기록한다.

**제2조 (의결·심의 사항)**
1. 전사 AI 도입 전략 및 연간 AX 과제 로드맵 승인
2. AI 도입 우선순위 및 주요 AI 투자(예산) 승인
3. AI Agent 효용성·안정성 최종 심의 및 Agent-HR 등재 승인
4. 우수 에이전트 포상 및 전사 확산 결정

**제3조 (안건 유형)**

| 안건 유형 | 코드 | 내용 |
|-----------|------|------|
| 상용 전환 승인 | PROD_APPROVAL | 파일럿 완료 에이전트의 상용 전환 심의 |
| 폐기 승인 | RETIRE_APPROVAL | 상용 에이전트 폐기 의결 |
| 주요 변경 승인 | MAJOR_CHANGE | 모델 교체·데이터 등급 변경·운영 범위 확대 심의 |
| 파일럿 연장 승인 | PILOT_EXTENSION | 파일럿 30일 초과 연장 |
| 긴급 대응 | EMERGENCY | 즉시 중단·보안 사고 대응 |

**제4조 (상정 요건)**
PROD_APPROVAL 안건은 운영기준 §5의 요건(Gate 3 통과, KPI 실측 30일 이상, KPI 달성)을 충족한 경우 상정하며, 시스템이 자동 검증한다. 다만 **KPI 미달 안건도 간사가 사유서를 첨부하는 경우 조건부 상정할 수 있으며**, 승인 여부는 의결로 판단한다.

**제5조 (위임전결)**
다음 안건은 AX위원회 의결을 갈음하여 **실무협의체 전결**로 처리할 수 있다. 전결 처리 결과는 차기 위원회에 일괄 보고한다.
1. **저위험 에이전트**(운영기준 §3)의 PROD_APPROVAL·RETIRE_APPROVAL
2. PILOT_EXTENSION 전건
3. 처리 데이터 등급·운영 범위 변경이 없는 경미한 MAJOR_CHANGE

단, G3 데이터 취급 에이전트와 고위험 에이전트는 위임 대상에서 제외한다.

**제6조 (서면결의)**
위원장이 필요하다고 인정하는 경우 회의 소집 없이 서면(전자결재 포함)으로 의결할 수 있다. EMERGENCY 안건은 위원장 선조치 후 사후 서면결의로 갈음할 수 있다.

**제7조 (의결 유형)**

| 의결 | 코드 | 시스템 처리 |
|------|------|-------------|
| 승인 | APPROVED | 개발 라이프사이클 종료, 상용 개시(ACTIVE). 상용 KPI 확정, 감사 로그 기록 |
| 조건부 승인 | CONDITIONAL | 이행 조건 등록. 전건 이행 + 간사 확인 시 ACTIVE 전환(재상정 불필요) |
| 반려 | REMANDED | 사유 기재, GATE3 회귀. 보완 후 재상정 가능 |
| 최종 반려 | REJECTED | 재상정 불가. 개발 라이프사이클 종료, 지식 추출 후 정리 |
| 보류 | DEFERRED | 차기 회의 이월, 사유 기록 |

## 제2장 AX 실무협의체

**제8조 (구성 및 권한)**
AX위원회 산하에 실무협의체를 두며, 유관 부서장과 AX팀장으로 구성한다. 월 1회 정기, 필요 시 수시 개최한다. 제5조의 위임전결 안건을 심의·의결할 수 있다.

**제9조 (역할)**
1. 고위험 Agent 식별 및 통제 절차 수립
2. 현업 개발 Agent의 표준화·안정성 검증 후 위원회 상정
3. Agent 운영 현황·개선·폐기 시점 협의 (라이프사이클 관리)
4. Agent 성능 평가 및 보상 제안
5. 파일럿 KPI(30일·90일) 결과 검토 및 전사 확대 권고
6. 위임전결 안건 처리 및 위원회 보고
