| 항목 | 내용 |
|------|------|
| 문서번호 | AX-STANDARD-2026-001 |
| 버전 | v1.0 |
| 제정일 | 2026-07-28 |
| 성격 | 규정·지침이 위임한 **수치 기준·처리 기한·기술 기준·시스템 상태값**의 단일 출처(SSOT) |

## §1 평가 배점 및 승인 점수

**6차원 배점**

| 차원 | 만점 | 비고 |
|------|------|------|
| 파급 영향력 | 25 | 영향 인원·업무 빈도·핵심 업무 연관성 |
| ROI | 25 | 정량 수치(시간·비용) 제시 시 가점 |
| 기밀등급 | 15 | G1=15 / G2=10 / G3=3 |
| 구현 용이성 | 15 | 단기 quick win 우선 |
| 실행 준비도 | 10 | 데이터 보유 4 + 챔피언 지정 3 + As-Is 구체성 3 |
| AX 전략 정합성 | 10 | 등대과제 8~10 / 핵심영역 5~7 / 지원 효율화 3~4 |

**승인 점수 기준**

| 구분 | 기준 |
|------|------|
| 자동 파일럿 승인 | G1·G2 + 총점 **70점 이상** |
| AX팀장 검토(경계값) | **68점 이상 70점 미만** |
| 상위 결재 | G3 또는 68점 미만 |

## §3 Agent 위험등급 분류

| 등급 | 기준 | 통제 |
|------|------|------|
| 고위험 | 대외 고객 응대 / 핵심 전략·개인정보 취급 / 사람 개입 없이 업무 시스템 상태 변경 | 출시 전 보안·규제 심사, 상시 모니터링, **AX위원회 의결 필수** |
| 중위험 | 내부 임직원 대상 프로세스 자동화, 비기밀 데이터 분석·초안 작성 | Human-in-the-loop 최종 검토, AX위원회 의결(서면결의 가능) |
| 저위험 | 사내 규정 조회, 공개 데이터 리서치 지원 등 | 표준 운영 절차, **실무협의체 전결 가능** |

## §4 Gate 2 기술기준 (위험등급별 차등)

| 항목 | 고위험 | 중위험 | 저위험 |
|------|--------|--------|--------|
| API 명세 문서 | 필수 | 필수 | 필수 |
| 기밀 처리 계획 | 필수 | 필수 | 해당 시 |
| 감사로그 설계 | 필수 | 필수 | 권고 |
| 테스트 커버리지 | 80% | 70% | 핵심 시나리오 스모크 테스트 |

- 1단계 이관 기준: 기능 테스트 통과율 80% 이상, 데이터 플로우·입출력 명세 문서화, 코드 버전관리(PoC는 GitHub private 허용, 내부 데이터 연동 시 내부 GitLab)

## §5 라이프사이클 시스템 상태값

**개발 (devStage)**: SUBMITTED → EVALUATED → GATE1(파일럿 승인) → GATE2(기술기준+데이터 제공) → GATE3(개발 완료) → PILOT_PROVEN(KPI 실측 30일+) → COUNCIL_PENDING(상정 대기)

**상용 (prodStatus)**: ACTIVE → SUSPENDED(일시중단) / DEPRECATED(폐기예고 — 30일 전 공지) / RETIRED(폐기 완료 — 지식 추출·데이터 회수)

**상정 자동검증 요건 (PROD_APPROVAL)**: devStage ≥ GATE3 + 파일럿 KPI 실측 30일 이상 + KPI 달성 (미달 시 사유서 첨부로 조건부 상정 — 위원회 규정 제4조)
