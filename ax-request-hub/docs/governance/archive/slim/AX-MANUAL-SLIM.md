## 1단계 — 신청 방법 선택

- **방법 A — AI 상담 챗** (`/chat`, 추천): 아이디어가 막연할 때. 대화 후 신청서 자동 완성.
- **방법 B — 직접 신청** (`/submit`): 과제 내용이 이미 구체적으로 정해진 경우.

---

## 2단계 — 신청서 잘 쓰는 법 (점수 올리는 팁)

| 항목 | 낮은 점수 예시 | 높은 점수 예시 |
|------|---------------|---------------|
| 현재 업무 방식 (As-Is) | 현재 수작업으로 처리하고 있습니다 | 운용팀 3명이 매월 1회 Excel로 보고서 초안을 작성하며 건당 약 4시간 소요. 오탈자·수치 오류가 월평균 2건 발생 |
| 기대 효익 | 시간이 많이 절감될 것 같습니다 | 보고서 작성 시간 90% 단축 (4시간→30분). 3명×12회 기준 연 126시간 절감. 수치 오류 제로화 |
| 예상 사용자 수 | 여러 명 | 초기 파일럿: 운용팀 3명. 검증 후 리스크팀·준법감시팀 포함 15명으로 확대 예정 |

### 기밀등급 선택 가이드

| 등급 | 해당 데이터 | AI 서비스 범위 |
|------|------------|----------------|
| G1 일반 | 공시자료, 뉴스, 업계 보고서, 인터넷 공개 정보 | 외부 AI 서비스 제한 없음 (Claude, ChatGPT 등) |
| G2 내부제한 | 사내 업무문서, 회의자료, 내부 보고서, 비공개 분석자료 | AX팀 승인 AI 서비스만 사용 가능 |
| G3 기밀 | 고객 개인정보(PI), 운용 포지션, 미공개 투자정보, 내부 전략문서 | 외부 AI 금지. 사내 온프레미스만 허용 |

## 3단계 — 제출 후 처리 절차

| 단계 | 처리 | 내용 |
|------|------|------|
| ① | 제출 | 신청서 작성 완료 후 제출 |
| ② | AI 평가 | 6차원 자동 평가 (약 30초 소요) |
| ③ | 점수 산출 | 100점 만점 스코어카드 생성 |
| ④ | 승인 판정 | G1/G2 + 70점 이상 → 자동 파일럿 승인 / 68~70점 → AX팀장 검토(5영업일) / G3 또는 68점 미만 → 상위 결재(10영업일) |
| ⑤ | 알림 발송 | 결과를 텔레그램으로 신청자에게 발송 |

> **Gate 2 자가점검**(기술표준 4개 항목: API 명세·기밀처리·감사로그·테스트 80%)은 초기 신청 단계가 아니라 PoC 완료 후 AX팀 인수 신청 시 별도 제출한다.

## 5단계 — 관리자 대시보드 (/dashboard)

AX팀 및 팀장급 이상은 대시보드에서 전체 과제 현황을 확인할 수 있다.

| 화면 구성 | 내용 |
|-----------|------|
| KPI 카드 | 전체 과제 수 / 자동 승인 건수 / 평균 평가 점수 / 파일럿 진행 중 건수 |
| 칸반 보드 | 신청 대기 → 평가 중 → 승인됨 / 부서별 필터링 / 과제 클릭 시 상세 스코어카드 |
| 거버넌스 로그 | `/governance` — AI 자동 승인 이력 전체 기록 / 정책 버전별 변경 이력 |
| 에이전트 레지스트리 | `/registry` — 전사 AI 에이전트 라이프사이클 관리. [에이전트 뷰] / [프로젝트 뷰] |

## 6단계 — 데이터 카탈로그 검색·신청·제공 실무 가이드

AI 과제 개발에 데이터플랫폼팀 관리 데이터가 필요한 경우, 아래 4단계 절차를 따른다.

### 1단계: DataAsset 카탈로그 탐색

`/data/catalog`에서 키워드·부서·기밀등급으로 검색. 결과 있음 → 이용 신청(ACCESS). 없음 → 신규 수집 요청(NEW).

### 2단계: DataRequest 신청

| 항목 | 내용 |
|------|------|
| 사용 목적 | AX Request Hub 과제 번호 포함. AI 추론·학습·조회 등 용도 구분 |
| 기밀등급 | G1/G2/G3 선택 (Data Owner 확인으로 최종 확정) |
| 이용 기간 | 파일럿 기간 또는 상용 운영 기간 명시 |
| 갱신 주기 | 실시간 / 일배치 / 주배치 중 선택 |
| 인터페이스 방식 | DB 직접 조회 / REST API / 파일 드롭 중 선택 |

> ※ G3 기밀 데이터 신청 시 데이터플랫폼팀이 정보보호 협의를 추가로 진행하므로 승인까지 추가 시간 소요.

### 3단계: DATA_PLATFORM(데이터플랫폼팀) 검토

| 결과 | 처리 |
|------|------|
| 승인(ACCESS) | 즉시 제공 — 연결 정보 발급 |
| 승인(NEW) | 신규 수집·적재 완료 후 카탈로그 등록 → 제공 |
| 반려 | 반려 사유 통보. 재신청 시 새 DataRequest 생성 |

### 4단계: DataProvision 제공 확인

`/me/data`에서 제공 현황(연결 정보·이용기간·상태) 확인.

> ⚠️ **Gate 진행 조건**: DataRequest 전건 PROVISIONED 상태가 되어야 GATE1 → GATE2 전환 가능.  
> ⚠️ **상용 전환 시 재신청 필수**: 파일럿용 제공분은 만료 처리. forProduction=true로 신규 DataRequest 제출 후 별도 재승인.

## 자주 묻는 질문 (FAQ)

**Q. G3 기밀 과제는 아예 AI를 못 쓰나요?**  
외부 AI(Claude, ChatGPT 등)는 사용 불가하지만, 사내 온프레미스 AI 인프라는 사용 가능합니다. AX팀에 문의하세요.

**Q. 점수가 낮게 나왔어요. 재신청할 수 있나요?**  
네. 평가 근거를 확인해 As-Is 상세화, 효익 수치화, 챔피언 지정 후 재신청하면 점수가 올라갑니다.

**Q. 파일럿 승인 후 전사 확대는 어떻게 하나요?**  
파일럿 30일·90일 효과 측정 후 AX팀과 협의하여 확대 계획을 수립합니다. 전사 확대 및 상용 전환은 AX위원회 의결 필요.

**Q. 운영 중 문제 발생 시 어떻게 신고하나요?**  
오류나 보안 이슈는 AX팀에 즉시 보고. AX팀이 접수 후 필요 시 컴플라이언스팀으로 에스컬레이션.
