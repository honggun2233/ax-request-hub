## 1. 이 가이드를 읽는 방법

이 가이드는 임직원 여러분이 업무에서 데이터를 찾고, 쓰고, AI에 활용할 때 무엇을 어떻게 하면 되는지를 안내하는 문서입니다.

- 공식 기준은 「데이터관리규정」과 「데이터취급지침」입니다. 이 가이드는 그 내용을 쉽게 풀어 쓴 안내서이며, 해석에 다툼이 있으면 규정·지침이 우선합니다.
- 읽는 순서: 데이터를 찾으려면 2장, 등급이 궁금하면 3장, AI에 넣어도 되는지 궁금하면 4장만 보셔도 됩니다.
- 궁금한 점은 8장의 문의 채널로 언제든 연락 주세요.

## 2. 데이터 찾기 — 데이터 카탈로그 사용법

### 2.1 카탈로그에서 검색하기

- 데이터 카탈로그에 접속하여 키워드(예: "ETF 설정액", "펀드 기준가")나 업무 도메인(운용/리서치/마케팅/상품/리스크)으로 검색합니다.
- [서비스 오픈 시 접속 경로·화면 캡처 반영 예정]

### 2.2 데이터 상세 정보 읽는 법

검색 결과에서 데이터를 클릭하면 다음 정보를 확인할 수 있습니다.
(명칭, 데이터 오너, 등급, 개인정보 여부, 출처, 갱신 주기, 용도, 계약상 AI 활용 허용 여부)

### 2.3 원하는 데이터가 없을 때

- 카탈로그에 없는 데이터가 필요하면 AI데이터플랫폼팀에 요청해 주세요. 사내에 이미 있는 데이터라면 등록을, 외부 구매가 필요한 데이터라면 도입 검토를 진행합니다.
- 외부 데이터 도입은 계약 검토를 포함해 심의에 통상 **15영업일** 정도 걸립니다. 일정에 여유를 두고 요청해 주세요.

## 3. 데이터 등급 이해하기

### 3.1 세 가지 등급 한눈에 보기

| 등급 | 표시명 | 예시 |
|------|--------|------|
| G1 | 공개정보 | 공시자료·뉴스·공개 정보 |
| G2 | 대외비 | 사내 업무문서·비공개 보고서 |
| G3 | 기밀(극비) | 고객 개인정보·운용 포지션·미공개 투자정보 |

### 3.2 개인정보는 별도로 확인

- 개인정보는 등급과 별개의 축입니다. 등급이 낮아도 개인정보가 들어 있으면 법령상 처리 근거(수집 목적, 동의 等)를 먼저 확인해야 합니다.
- 고객 이름·연락처·계좌정보가 보이면 일단 멈추고, 개인정보 보호 담당 조직 또는 AI데이터플랫폼팀에 문의하세요.

### 3.3 등급이 없는 데이터를 발견했다면

- 등급이 확인되지 않은 데이터는 외부 활용(기업용 외부 AI 포함)이 금지됩니다.
- 데이터 오너 또는 AI데이터플랫폼팀에 등급 확인을 요청해 주세요. 판정이 어려운 건은 실무협의체가 심의합니다.

## 4. "이 데이터, AI에 넣어도 되나요?" — 판단 플로우

### 4.1 판단 순서 (4단계)

① 등급 확인 → ② 개인정보 확인 → ③ AI 선택(등급별) → ④ 승인 확인

등급이 없으면 그 자리에서 멈추고 등급 확인부터 요청하세요.

### 4.2 등급별 허용표

| 등급 | 내부 AI 플랫폼 | 기업용 외부 AI |
|------|--------------|--------------|
| G1 공개정보 | 허용 | 허용 |
| G2 대외비 | 허용 | 비식별 처리 후 허용 |
| G3 기밀(극비) | 접근권한 보유자 한정 | **절대 금지** |

- 외부에서 구매한 데이터는 등급과 별개로 계약상 AI 활용 허용 여부를 추가로 확인해야 합니다. 카탈로그의 해당 데이터 상세 정보에서 확인할 수 있습니다.

### 4.3 승인이 필요한 경우와 신청 방법

다음의 경우 승인 신청이 필요합니다 (지침 별지 4 양식).

- 신규·외부 데이터를 업무 분석에 활용할 때 (Track A)
- 데이터를 기업용 외부 AI 또는 내부 AI 플랫폼에 연계·투입할 때 (Track B)
- 신청서는 데이터 오너 승인을 거쳐 처리되며, AI 관련 건은 실무협의체 심의를 거칩니다.

### 4.4 기밀 데이터를 꼭 써야 한다면 — 비식별 후 등급 하향

- 기밀(극비) 데이터도 비식별 처리로 유출 위험을 없애면 등급을 낮춰 활용할 수 있습니다. 개인정보뿐 아니라 펀드운용정보(미공개 전략·포트폴리오·리밸런싱 等)도 이 절차의 대상입니다.
- **절차**: ① 비식별 처리(종목명·비중·고객명 等 식별 요소 삭제·범주화) → ② 재식별 위험 검토 → ③ 컴플라이언스·CISO 합의 → ④ 데이터 오너 최종 결재 → ⑤ 등급 하향 확정 후 낮아진 등급 기준으로 활용
- 신청은 「데이터취급지침」 별지 6(비식별 처리 검토서)으로 합니다. 운용정보는 처리 후에도 미공개중요정보에 해당하는지 컴플라이언스가 함께 확인합니다.
- **주의**: 승인 전에 임의로 "가렸으니 괜찮겠지"라고 판단해 쓰는 것은 금지입니다. 하향은 결재 완료 후에만 유효합니다.

## 5. 접근권한 신청하기

### 5.1 권한 신청 절차

1. 카탈로그에서 대상 데이터와 데이터 오너를 확인
2. 접근권한 신청서(지침 별지 2) 작성 — 목적과 기간을 구체적으로
3. 데이터 오너 승인 → (기밀 또는 반출 시) 정보보안·컴플라이언스 합의 → 권한 부여

처리 기한: 통상 **5영업일**, 기밀·반출 건은 **10영업일**

### 5.2 어떤 권한을 신청해야 하나

| 권한 유형 | 설명 |
|-----------|------|
| 조회 | 시스템 내에서 데이터를 볼 수 있는 권한 |
| 추출 | 쿼리·다운로드로 데이터를 꺼낼 수 있는 권한 |
| 반출 | 시스템 외부로 데이터를 내보내는 권한 (가장 엄격한 통제 적용) |

- 기간을 쓰지 않으면 최대 1년으로 부여되고, 이후 재신청이 필요합니다.

## 6. 외부 데이터를 쓰고 싶을 때

- 시장 데이터, 지수, 대체 데이터 等 외부 데이터가 필요하면 AI데이터플랫폼팀에 수요를 제기해 주세요 (지침 별지 3).
- **계약 조건이 왜 중요한가**: 외부 데이터는 계약서에 적힌 범위(재배포·가공·AI 활용 가능 여부)를 벗어나 쓰면 회사가 계약 위반 책임을 질 수 있습니다. 그래서 도입 전에 반드시 계약 검토를 거칩니다.
- 이미 도입된 데이터라도 "AI에 넣어도 되는지"는 계약마다 다릅니다. 카탈로그에서 확인하거나 문의해 주세요.

## 7. 자주 하는 실수와 FAQ

**Q. 등급 판단이 애매해요.**
→ 데이터 오너에게 먼저 문의하고, 판단이 어려우면 실무협의체 심의를 요청하세요. 확정 전에는 보수적으로(높은 등급으로) 취급하세요.

**Q. 급하게 권한이 필요해요.**
→ 신청서에 긴급 사유를 기재하고 데이터 오너에게 직접 연락하세요. 다만 기밀·반출 건은 합의 절차를 생략할 수 없습니다.

**Q. 이 파일, 파기해야 하는 건가요?**
→ 법정 보존 대상(판매 기록 10년 等)일 수 있으니 임의로 삭제하지 말고 AI데이터플랫폼팀에 문의하세요. 파기는 데이터 오너 확인을 거쳐 이력을 남기며 진행합니다.

**Q. 기밀 운용정보를 분석·AI에 쓰고 싶어요.**
→ 비식별 처리 후 등급 하향 절차(4.4)를 이용하세요. 컴플라이언스·CISO 합의와 데이터 오너 결재가 완료되기 전에는 기밀 기준의 통제가 그대로 적용됩니다.

**Q. 사고(유출·오전송)를 냈거나 발견했어요.**
→ 숨기지 말고 즉시 AI데이터플랫폼팀과 정보보안 조직에 알려 주세요. 빠른 보고가 피해를 줄입니다.
