# AI 규정 2원화 배분표 — 「AI 운영 규정」 × 「AI 거버넌스 규정」

**작성일**: 2026-07-29 | **담당부서**: AX/PI센터 AX팀
**목적**: 같은 레벨의 두 규정이 관할 중복 없이 공존하도록 경계·조항·하위 문서를 배분한다.

---

## 1. 관할 정의

| 규정 | 규율 대상 | 핵심 질문 |
|------|-----------|-----------|
| 「AI 운영 규정」 (AX-REGULATION-2026-001 v3.3) | **사람** — 임직원의 AI 활용 행위, AI 과제의 신청·승인·수행 | 임직원이 AI를 어떻게 쓰는가 |
| 「AI 거버넌스 규정」 (IT-AX-REG-001 v7.0) | **시스템** — AI 시스템·에이전트의 통제, 유형·위험 분류, R&R | AI 시스템을 어떻게 통제하는가 |

경계 명문화: 양 규정 총칙에 상호 관할 조항(운영 규정 제4조 / 거버넌스 규정 제3조)을 두었다. 데이터의 분류·보호는 양쪽 모두 데이터 거버넌스 관련 규정으로 위임한다.

## 2. 거버넌스 규정 v6.4 → v7.0 조항 처리 내역

| v6.4 조항 | 처리 | 사유·행선지 |
|-----------|------|-------------|
| 제1조② 현황 진단 선행 | 제4조 1호로 이동 | 목적이 아닌 원칙 성격 |
| 제3조 책임 귀속·보조 수단 원칙 | **삭제** | 운영 규정 제5조와 중복 — 사람 축 소관 |
| 제3조 데이터 기밀등급 준수 원칙 | **삭제** | 데이터 거버넌스 소관 (제3조 관계 조항으로 대체) |
| 제3조 AI 생성 출처 명시 원칙 | **이동** | 사람의 산출물 표시 행위 — AI 운영 지침 제3조에 후속 반영 필요 |
| 제3조 AI Native / 중단 기능 / 기술적 통제 / 장애 행동 | 제4조 유지 | 시스템 통제 성격 — "지식 축적 지향"으로 표현 완화 |
| 제4조 유형 분류 | 제5조 유지 (예시 열 삭제) | 예시는 가이드라인 소관 |
| 제5조 G1/G2/G3 정의 및 허용 경로 | **삭제** | 등급 정의는 데이터 거버넌스 소관(확정 원칙). 민감도별 허용 AI 경로 매핑은 「AX 운영기준」에 신설 필요 → 후속 조치 ① |
| 제6조 위험 업무 분류 (예시 표 2개) | 제6조 축약 — 분류·처리 원칙만 | 세부 예시 표는 「AX 운영기준」으로 이관 → 후속 조치 ② |
| 제7조 에이전트 통제 원칙 | 제7조 유지 + Agent ID 등록 원칙 3항 신설 | 이 규정의 핵심 |
| 제8조 절대 금지 5개 | 제8조 "하여서는 아니 되는 행위"로 유지·재편 | 금감원 RMF 대응상 규정 레벨 유지. G3 전송 → "데이터 보호 기준 위반 전송·처리"로 일반화, Agent ID → "등록되지 않은 에이전트 운영" |
| 제9조 R&R 표 2개 | 제9~10조로 분리·산문화 | "월 1회" 등 수치 표현 제거("정기"), 위원회 세부는 「AI 운영위원회 규정」 참조 |
| 부록 하위 문서 목록 표 | **삭제** | 규정 본문에 문서 목록을 두면 문서 추가마다 규정 개정 필요 — 본 배분표가 대체 |
| 헤더 적용범위 "AX/PI센터 전 임직원" | "전 부서 및 임직원(AI 시스템·서비스 기준)"으로 수정 | 본문과 불일치 오류 |

## 3. 하위 문서 트리 통합 배분 (두 벌 → 한 벌)

| IT-AX-OPS-004 지침_AI_개발배포기준 | 운영 규정 산하 | 「AI 운영 지침」 제4장 + 개발표준 문서에 **흡수·폐지** |
| IT-AX-OPS-003 지침_AI_에이전트등록통제 | **거버넌스 규정 산하 유지** | 거버넌스 규정 제7조 3항의 위임 근거로 존치. 위험등급별 통제 요건은 「AX 운영기준」과 수치 SSOT 정합 필요 |

| IT-AX-GUIDE-003 가이드라인_AI_거버넌스 | 매뉴얼 계열 | 실무 안내서로 존치 (사규 아님). 유형 선택·설계 예시 수록처 |

```

(사람·과제)             └── 「AX 운영기준」 v1.1 (별표 — 양 규정 공용 수치 SSOT)
「AI 거버넌스 규정」 v7.0 ─┬── 「AI 운영위원회 규정」 v1.2
(시스템·에이전트)          └── 「AI 에이전트 등록·통제 지침」 (OPS-003 개정)
부속(사규 외): 사용 매뉴얼 · 가이드라인 · 운영계획
```

## 4. 후속 조치

1. **「AX 운영기준」에 "데이터 민감도별 허용 AI 경로" 항목 신설** — 거버넌스 규정 구 제5조 매핑의 수용처 (데이터 거버넌스 규정의 등급을 참조 표기로 사용)
2. **「AX 운영기준」에 "위험 업무 분류 세부 예시" 항목 신설** — 거버넌스 규정 구 제6조 표 2개의 수용처
3. **「AI 운영 지침」에 AI 생성 출처(도구) 명시 의무 반영** — 제3조 보완
4. **문서번호 체계 통일** — AX-* 와 IT-AX-* 병존 해소. 사규 등록 시 인사팀 채번 체계 확인 후 일괄 적용
5. OPS-002·004·GOV-001 폐지 및 archive 이관, OPS-003 개정(용어·수치 SSOT 정합)
