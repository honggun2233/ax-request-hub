# Full vs SLIM 조항 비교표

> **두 버전은 독립 관리됩니다.** Full은 완결성 기준, SLIM은 실무 적용성 기준으로 각각 유지합니다.
> SLIM이 Full의 축약이 아닌, 사용 목적이 다른 별도 버전임을 전제합니다.
>
> ✅ = SLIM에 포함 | ❌ = SLIM에서 제외 (제외 이유 기재)
