> **이 문서의 목적**: "이건 에이전트로 하면 안 됩니다"를 명확히 정의한다

## 왜 불가 영역을 정의하는가

에이전트는 자율적으로 행동한다. 그래서 강력하다. 그래서 위험하기도 하다.  
"기술적으로 가능한가"와 "해도 되는가"는 다른 질문이다.

---

## 1. 절대 불가 — 어떤 경우에도 에이전트가 단독으로 하면 안 된다

### 1-1. 금융·투자 실행

| 행위 | 이유 |
|------|------|
| 실 자금 투자·거래 주문 실행 | 금융투자업법 — 투자 결정은 사람이 |
| 리밸런싱 실제 발주 (FIX 오더) | 오류 시 고객 자산 피해, 취소 불가 |
| 담보·레버리지 설정 | 규제 위반 및 막대한 손실 가능 |
| 신탁·펀드 자산 이동 | 금감원 규제 영역 |

### 1-2. 규제·법률 행위

| 행위 | 이유 |
|------|------|
| 금감원 공시·법정문서 제출 | 법적 책임, 허위공시 형사 처벌 |
| 컴플라이언스 위반 판정 | 징계·법적 책임 수반, 사람이 최종 판단 |
| 계약 체결·서명 | 법적 구속력, 사람의 의사표시 필요 |
| 법적 분쟁 대응 문서 발송 | 소송 전략상 전략적 판단 필요 |

### 1-3. 인사·조직

| 행위 | 이유 |
|------|------|
| 채용 합격·불합격 결정 | 차별 금지법, 인사위원회 권한 |
| 인사 평가 결정 | 개인 경력 영향, 이의신청 권리 |
| 징계 조치 실행 | 취업규칙상 인사위원회 권한 |

### 1-4. 고객 커뮤니케이션 최종 발송

| 행위 | 이유 |
|------|------|
| 고객 자산 현황 통보 발송 | 오류 시 분쟁, 민원 |
| 투자 권유 메시지 발송 | 투자권유준칙 위반 가능 |
| 민원·컴플레인 최종 답변 | 브랜드·법적 리스크 |

---

## 2. 원칙적 불가 — 단독 에이전트 불가, Human-in-the-loop 필수

이 영역은 에이전트가 **초안·분석·추천**까지는 가능하다.  
하지만 **실행·최종 판단**은 반드시 사람이 한다.

| 영역 | 에이전트 가능 범위 | Human 검토 이유 |
|------|-----------------|----------------|
| 운용 의사결정 | 리밸런싱 제안, 포트폴리오 분석 | 실행은 운용역 승인 |
| 공시 작성 | 초안 생성, 필수 항목 점검 | 제출은 담당자 최종 확인 |
| 법적 계약 검토 | 위험 조항 탐지, 비교 분석 | 법무팀 최종 검토 |
| G3 기밀 데이터 접근 | 접근 권한 신청 | 정보보호 담당자 승인 |
| 예산 집행 | 집행 요청서 작성 | CFO/팀장 결재 |

---

## 3. 기술적 부적합 — 에이전트보다 다른 방식이 낫다

이건 "금지"가 아니라 "다른 방식이 더 적합하다"는 것.

| 케이스 | 이유 | 적합한 방식 |
|--------|------|-----------|
| 밀리초 단위 응답 필요 | 에이전트 추론 시간 = 수초 | 룰 기반 시스템 |
| 100% 동일한 반복 작업 | AI 변동성이 오히려 문제 | RPA |
| 데이터 없이 판단 | 환각 위험이 너무 높음 | 데이터 수집 먼저 |
| 규칙이 명확한 분기 | AI 비용 낭비 | 조건문 코드 |
| 실시간 HFT 신호 | 지연·불확실성 | 알고리즘 트레이딩 엔진 |

---

## 4. AI 에이전트가 다른 에이전트를 만드는 것 (Self-Replication)

에이전트가 스스로 새 에이전트를 무제한 생성하는 패턴은 **원칙적으로 금지**.

허용: 오케스트레이터가 사전 정의된 워커 에이전트를 정해진 수만큼 생성  
금지: 에이전트가 동적으로 새 에이전트 유형을 설계하고 무한 생성

---

## 5. 불가 영역 판단 기준 (현업이 헷갈릴 때)

```
Q1. 이 결정이 틀렸을 때 사람이 책임질 수 있는가?
  └─ No → 에이전트가 단독으로 하면 안 됨

Q2. 이 행위가 외부(고객·규제기관·거래소)에 직접 나가는가?
  └─ Yes → Human-in-the-loop 필수

Q3. 이 결정을 되돌릴 수 없는가? (거래 실행, 발송 등)
  └─ Yes → Human-in-the-loop 필수

Q4. 기존에 이 결정을 내리는 조직 규정·권한이 있는가?
  └─ Yes → 그 권한을 가진 사람이 최종 판단해야 함
```
