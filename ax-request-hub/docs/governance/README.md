## 폴더 구조

```
docs/governance/
├── README.md                ← 이 파일 (인덱스)
├── l1-규정/                 ← 최종 규정 (MD + DOCX)
├── l2-지침/                 ← 최종 지침 (MD + DOCX)
├── l3-가이드라인/            ← 최종 가이드라인 (MD + DOCX)
├── l3-매뉴얼/               ← 최종 매뉴얼 (MD + DOCX)
├── meta/                   ← 문서 관리 정보 (체계, CHANGELOG, 버전 가이드)
└── archive/
    ├── reference/          ← 타 부서 규정 참조 MD (데이터관리규정 등)
    └── prior-versions/     ← 구버전 전체 (수정 금지)
```

## 운영 규칙

1. **MD 파일이 SSOT** — MD를 먼저 수정, DOCX는 스크립트로 생성
2. **파일명 규칙**: `[유형]_문서명_코드.md`
3. **버전 관리**: MD 파일 내 `문서이력` 테이블에 기록
4. **구버전 보관**: 수정 전 버전은 `archive/prior-versions/`로 이동
5. **배포**: 각 계층 폴더의 DOCX 파일이 배포본 (git 추적 중)

- **생성 스크립트**: `tmp/md_to_regulation.py` (DOCX 자동 생성)
