# AX 스킬 라이브러리 운영 기준

| 항목 | 내용 |
|------|------|
| 문서번호 | AX-STD-2026-003 |
| 버전 | v2.0 |
| 최종 개정일 | 2026-07-31 |
| 근거 | 「AI 운영 지침」 관련 조항 |
| 담당 | AX팀 |

---

## 1. 목적

전사 AI 스킬 라이브러리의 등록·운영·폐기 최소 기준을 정한다.

---

## 2. 스킬 등록 기준

스킬(프롬프트·워크플로우 템플릿)을 AX Hub에 등록하려면 아래를 충족해야 한다.

- 명확한 업무 목적 명시
- G3 기밀 데이터를 포함하지 않는 예시 포함
- AX팀 검토 통과 (품질·보안·저작권 확인)

---

## 3. 역할과 책임

| 역할 | 책임 |
|------|------|
| 등록자 (L2 이상 임직원) | 스킬 초안 작성·제출 |
| AX팀 | 품질·보안 검토 후 승인 또는 반려, 스킬 라이브러리 유지 관리 |
| 전 임직원 | 등록된 스킬 활용·평가 |

---

## 4. 폐기 기준

아래 조건 중 하나 해당 시 AX팀이 스킬을 폐기(비공개) 처리한다.

- 6개월 이상 사용 이력 없음
- 보안 이슈 발견
- 관련 서비스 종료 또는 변경으로 동작 불가
