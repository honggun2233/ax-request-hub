# AX 스킬 라이브러리 운영 기준

| 항목 | 내용 |
|------|------|
| 문서번호 | AX-STD-2026-003 |
| 버전 | v1.2 |
| 최종 개정일 | 2026-08-27 |
| 근거 | 「AI 운영 지침」 관련 조항 |
| 담당 | AX팀 |

---

## 1. 목적

전사 AI 스킬 라이브러리의 등록·운영·폐기 최소 기준을 정한다.

스킬이란 임직원이 반복적으로 사용하는 프롬프트 템플릿 또는 AI 워크플로우 절차를 표준화한 단위다. 개인이 만든 유용한 프롬프트를 조직 전체가 재사용할 수 있도록 공유하는 것이 스킬 라이브러리의 목적이다.

---

## 2. 스킬 유형

| 유형 | 설명 | 예시 |
|------|------|------|
| 프롬프트 템플릿 | 특정 업무에 재사용 가능한 프롬프트 패턴 | 보고서 요약, 회의록 정리, 이메일 초안 |
| 워크플로우 가이드 | AI 도구를 활용한 업무 처리 절차 | 공시 분석 흐름, 리포트 자동 생성 순서 |

---

## 3. 스킬 등록 기준

스킬(프롬프트·워크플로우 템플릿)을 AX Hub에 등록하려면 아래를 충족해야 한다.

- 등록자 리터러시 레벨 L2 이상
- 명확한 업무 목적 명시 (어떤 상황에서, 어떤 결과를 위해 사용하는지)
- 기밀 데이터를 포함하지 않는 실사용 예시 1건 이상 포함
- AX팀 검토 통과 (품질·보안·저작권 확인)

**스킬 제목 작성 기준**: `[업무영역] 기능설명` 형식으로 작성한다. (예: `[리서치] 공시 요약 프롬프트`, `[운용] ETF 성과 분석 가이드`)

---

## 4. 스킬 등록 절차

1. AX Hub `/skills/new`에서 스킬 초안 작성·제출
2. AX팀이 아래 기준으로 검토 (통상 3영업일 내)

| 검토 항목 | 기준 |
|----------|------|
| 업무 목적 명확성 | "이 스킬이 왜 필요한가" 이해 가능 여부 |
| 예시 적절성 | 기밀 데이터 미포함, 실제 활용 가능성 |
| 중복 여부 | 기존 등록 스킬과 실질적 차이 존재 여부 |
| 저작권·보안 | 외부 출처 인용 시 출처 명시, 기밀 내용 미포함 |

3. 검토 결과 등록자에게 통보 (승인 / 수정 요청 / 반려)
4. 승인 후 스킬 라이브러리 공개

---

## 5. 스킬 수정·업데이트

- 등록자 본인이 AX Hub에서 수정 요청 가능
- 내용 변경 시 AX팀 재검토 후 반영
- 타인의 스킬에 개선 제안은 AX Hub 내 '피드백' 기능 사용

---

## 6. 역할과 책임

| 역할 | 책임 |
|------|------|
| 등록자 (L2 이상 임직원) | 스킬 초안 작성·제출, 수정 요청 대응 |
| AX팀 | 품질·보안 검토 후 승인 또는 반려, 스킬 라이브러리 유지 관리 |
| 전 임직원 | 등록된 스킬 활용·평가 (별점·댓글) |

---

## 7. 폐기 기준

아래 조건 중 하나 해당 시 AX팀이 스킬을 폐기(비공개) 처리한다.

- 6개월 이상 사용 이력 없음
- 보안 이슈 발견
- 관련 서비스 종료 또는 변경으로 동작 불가
- 저작권 문제 확인

폐기 전 등록자에게 사전 통보하며, 등록자가 30일 내 수정·갱신 시 폐기를 보류한다.
