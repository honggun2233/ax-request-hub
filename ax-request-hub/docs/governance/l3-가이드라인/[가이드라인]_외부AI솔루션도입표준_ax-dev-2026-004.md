# 외부 AI 솔루션 도입 표준

| 항목 | 내용 |
|------|------|
| 문서번호 | AI-STD-2026-008 |
| 버전 | v1.0 |
| 최종 개정일 | 2026-09-04 |
| 적용범위 | 외부(타 조직, 외부 벤더, 오픈소스)에서 개발된 AI 솔루션을 전사 업무에 도입하는 경우 |
| 근거 | 「AI 운영 규정」 제5조, 「AI 운영 지침」 제9조 |
| 담당 | AX팀 |

---

## 1. 적용 대상

이 표준은 아래 유형의 AI 솔루션을 전사 업무에 도입할 때 적용한다.

| 유형 | 예시 |
|------|------|
| 외부 SaaS AI 도구 | Copilot, Notion AI, Midjourney, 외부 AI 플랫폼 |
| 오픈소스 AI 모델 | HuggingFace 모델, LLaMA, Mistral 등 |
| 타 기업·기관 개발 AI | 계열사 개발 AI, 파트너사 AI 솔루션 |
| 벤더 공급 AI 솔루션 | 국내외 SI/ISV가 납품하는 AI 기능 포함 시스템 |
| 전사 공통 외부 API | AX팀이 직접 계약한 Claude Enterprise, GPT 등 (별도 승인 과정 생략 가능) |

**미적용 대상**: 개인이 개인 PC에서 사용하는 무료 AI 도구 (데이터 입력에 주의만 요망)

---

## 2. 도입 유형 분류

도입 방식에 따라 절차 수준이 다르다.

| 유형 | 정의 | 절차 |
|------|------|------|
| A형 — 전사 표준 도구 채택 | AX팀이 전사 계약한 도구 사용 신청 | AX Hub 신청 → 계정 발급 |
| B형 — 부서 단독 도입 | 부서가 자체 예산으로 외부 AI 도구 도입 | 도입 신청서 → AX팀 검토 → 보안 확인 |
| C형 — 전사 배포 목적 도입 | 도입 후 전사 공통 서비스로 확장 예정 | 전체 도입 절차 (본 표준 5~7절) |

---

## 3. 도입 전 자가점검 (전 유형 공통)

도입 신청 전 아래 4가지를 반드시 확인한다.

| 항목 | 확인 내용 | 판단 기준 |
|------|-----------|-----------|
| 데이터 처리 위치 | 데이터가 어디서 처리·저장되는가 | 국내 서버 또는 계약서에 명시된 안전 리전 |
| 학습 데이터 활용 여부 | 입력 데이터가 AI 학습에 사용되는가 | 학습 사용 = G3 데이터 절대 금지, 계약 명시 필수 |
| 기밀 등급 호환성 | 해당 도구에 어떤 등급 데이터를 입력할 것인가 | G3는 외부 AI 도구 사용 불가, G2는 계약 조건 확인 |
| 내부 보안 정책 위반 여부 | DLP, 정보보호팀 지침과 상충되는가 | 정보보호팀 확인 (G2 이상 또는 대용량 파일 업로드 포함 시) |

---

## 4. A형 도입 절차 (전사 표준 도구 신청)

1. AX Hub → 도구 목록에서 원하는 도구 선택
2. 사용 목적 기재 후 신청
3. 부서장 승인 → 계정 발급 (자동화, 1~3 영업일)
4. AX Hub에서 온보딩 가이드 확인 후 사용 시작

---

## 5. B형 도입 절차 (부서 단독 도입)

### 5.1 도입 신청

AX Hub → 외부 AI 도입 신청에 아래 항목 기재 후 제출한다.

| 항목 | 내용 |
|------|------|
| 도구명 / 벤더 | |
| 도입 목적 | |
| 사용 부서 / 사용자 수 | |
| 입력 데이터 기밀등급 | G1 / G2 / G3 |
| 월 비용 (예상) | |
| 계약 기간 | |
| 데이터 처리 위치 | |
| 학습 데이터 활용 여부 | 예 / 아니오 |

### 5.2 AX팀 검토 (5 영업일 이내)

AX팀은 아래 기준으로 검토한다.

| 검토 항목 | 기준 |
|-----------|------|
| 데이터 보안 적정성 | G2 이상 입력 시 정보보호팀 의견 수렴 |
| 기존 계약 중복 여부 | 전사 표준 도구와 기능 중복 시 A형 전환 권고 |
| 토큰·비용 정책 준수 | AX 토큰정책 운영기준(AI-STD-2026-004) 부합 여부 |
| 위험등급 분류 | AI 운영 지침 기준으로 저/중/고위험 분류 |

### 5.3 승인 후 조치

- 승인: AX Hub에 도구 등록, 부서 내 사용 시작
- 조건부 승인: AX팀 제시 조건 충족 후 사용 가능
- 반려: 사유 명시, 대안 도구 안내

---

## 6. C형 도입 절차 (전사 배포 목적)

B형 절차에 추가로 아래를 수행한다.

| 단계 | 내용 |
|------|------|
| 6.1 AI 위원회 상정 | 고위험 또는 전사 영향 도구는 AI 위원회 보고 |
| 6.2 파일럿 운영 | 지정 부서에서 4~8주 시범 운영 |
| 6.3 파일럿 결과 보고 | 사용 현황, 이슈, 개선점을 AX Hub에 등록 |
| 6.4 전사 확산 결정 | AX실무협의체 또는 AI위원회 승인 |
| 6.5 전사 온보딩 | AX Hub 도구 목록 등재, 온보딩 가이드 작성 의무 |

---

## 7. 도입 후 운영 의무

| 의무 | 주기 | 담당 |
|------|------|------|
| 사용 현황 보고 | 분기 1회 (AX Hub 자동 집계) | 부서장 |
| 계약 갱신 전 재검토 | 갱신 30일 전 | 부서 + AX팀 |
| 보안 이슈 즉시 신고 | 발생 즉시 | 임직원 → AX팀 |
| 도구 종료 시 데이터 처리 | 종료 전 AX팀 확인 | 부서 |

---

## 8. 외부 도입 판단 흐름도

```
외부 AI 솔루션을 쓰고 싶다
       ↓
AX Hub 전사 도구 목록에 있나?
  예 → A형 신청 (간단)
  아니오 ↓
개인 PC 비업무용 사용인가?
  예 → 자유 (단, 기밀 데이터 입력 금지)
  아니오 ↓
전사 확산 목적인가?
  예 → C형 (파일럿 포함)
  아니오 → B형 (부서 단독)
```
