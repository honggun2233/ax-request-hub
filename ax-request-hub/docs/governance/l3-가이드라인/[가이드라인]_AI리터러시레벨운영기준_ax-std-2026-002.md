# AI 리터러시 레벨 운영 기준

| 항목 | 내용 |
|------|------|
| 문서번호 | AX-STD-2026-002 |
| 버전 | v2.0 |
| 최종 개정일 | 2026-07-31 |
| 근거 | 「AI 운영 지침」 제33조 |
| 담당 | AX팀 (평가 운영), HR팀 (레벨 최종 승인) |

---

## 1. 목적

전사 AI 리터러시 레벨 체계(L0~L4)의 정의, 취득 절차, 레벨별 권한 연계를 명시한다.

---

## 2. 레벨 정의

| 레벨 | 명칭 | 기준 |
|------|------|------|
| L0 | 미취득 | 레벨 신청 전 또는 탈락 |
| L1 | 기초 | AI 개념 이해, 기본 교육 이수 |
| L2 | 활용 | 업무 AI 활용, 프롬프트 설계 역량 보유 |
| L3 | 응용 | AI 자동화 설계, AI 과제 기획·실행 경험 보유 |
| L4 | 전문 | AI 에이전트·시스템 개발, AX팀 또는 현업 전문개발자 수준 |

---

## 3. 레벨 취득 절차

1. AX Hub `/me`에서 레벨 취득 신청
2. AX팀이 아래 기준으로 평가
   - 교육 이수 이력 (AX 운영 과정)
   - AI 과제 참여·완료 이력
   - 실무 활용 성과 또는 기술 역량
3. **HR팀 최종 승인** 후 레벨 부여
4. 연 1회 이상 재평가 (미충족 시 강등 가능)

---

## 4. 레벨별 연계 권한

| 레벨 | AI 서비스 접근 | AX Hub 기능 |
|------|--------------|------------|
| L0 | 없음 | 과제 신청만 |
| L1 | GPT for Excel, Gemini | 기본 |
| L2 | GPT Chat | 과제 기획·스킬 등록 |
| L3 | GPT Chat · Claude | 에이전트 과제 등록 |
| L4 | 전체 + 개발 환경 | 전체 |
