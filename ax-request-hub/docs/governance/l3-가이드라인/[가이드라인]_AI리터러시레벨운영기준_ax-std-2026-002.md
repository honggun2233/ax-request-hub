# AI 리터러시 레벨 운영 기준

| 항목 | 내용 |
|------|------|
| 문서번호 | AX-STD-2026-002 |
| 버전 | v1.0 |
| 최종 개정일 | 2026-07-31 |
| 근거 | 「AI 운영 지침」 제33조 |
| 담당 | AX팀 (평가 운영), HR팀 (레벨 최종 승인) |

---

## 1. 목적

전사 AI 리터러시 레벨 체계(L0~L4)의 정의, 취득 절차, 레벨별 권한 연계를 명시한다.

---

## 2. 레벨 정의

| 레벨 | 명칭 | 기준 |
|------|------|------|
| L0 | 미취득 | 레벨 신청 전 또는 탈락 |
| L1 | 기초 | AI 개념 이해, 기본 교육 이수 |
| L2 | 활용 | 업무 AI 활용, 프롬프트 설계 역량 보유 |
| L3 | 응용 | AI 자동화 설계, AI 과제 기획·실행 경험 보유 |
| L4 | 전문 | AI 에이전트·시스템 개발, AX팀 또는 현업 전문개발자 수준 |

---

## 3. 레벨별 취득 요건

| 레벨 | 필수 요건 |
|------|----------|
| L1 | AX팀 운영 AI 기초 교육 이수 (온라인, 연 1회 이상 개설) |
| L2 | L1 취득 + 업무 AI 활용 성과 사례 1건 이상 제출 (AX Hub 등록) |
| L3 | L2 취득 + AI 과제 기획 또는 자동화 설계 완료 이력 1건 이상 |
| L4 | L3 취득 + AI 에이전트·시스템 개발 완료 이력 (AX팀 확인) |

> L4는 AX팀 또는 현업 전문개발자 수준으로, 사례 제출 외 기술 역량 인터뷰를 병행할 수 있다.

---

## 4. 레벨 취득 절차

1. AX Hub `/me`에서 레벨 취득 신청 (증빙 자료 첨부)
2. AX팀이 취득 요건 충족 여부 확인 (통상 5영업일 내)
3. **HR팀 최종 승인** 후 레벨 부여 및 서비스 접근 권한 자동 설정
4. 연 1회 이상 재평가 (미충족 시 강등 가능)

**레벨 유지 기준**: 연 1회 재평가 시 해당 레벨 활동 이력(교육 이수 또는 과제·활용 이력)이 확인되지 않으면 하위 레벨로 강등된다. 강등 시 해당 서비스 접근 권한이 자동 조정된다.

**이의신청**: 레벨 평가 결과에 이견이 있을 경우 결과 통보 후 10영업일 내 AX팀에 서면으로 이의신청할 수 있다.

---

## 5. 레벨별 연계 권한

| 레벨 | AI 서비스 접근 | AX Hub 기능 |
|------|--------------|------------|
| L0 | 없음 | 과제 신청만 |
| L1 | GPT for Excel, Gemini | 기본 |
| L2 | GPT Chat | 과제 기획·스킬 등록 |
| L3 | GPT Chat · Claude | 에이전트 과제 등록 |
| L4 | 전체 + 개발 환경 | 전체 |
