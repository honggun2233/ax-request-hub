---

## 1. 목적

AX Hub에 등록되는 AI 에이전트의 위험등급별 최소 통제 기준과 라이프사이클 관리 절차를 정한다.

---

## 2. 위험등급 결정 기준

| 조건 | 등급 |
|------|------|
| 기밀 데이터 처리, 고객 자산·계약에 직접 영향 | **고위험** |
| 내부 데이터 처리, 유형 2·3 에이전트 | **중위험** |
| 일반 데이터만, 유형 1 에이전트 | **저위험** |

등급이 명확하지 않으면 상위 등급으로 분류한다.

---

## 3. 등급별 최소 통제 요건

### 고위험

- Human-in-the-loop 의무 (담당자 + 팀장 이중 검토 후 실행)
- 감사로그 5년 보존 (입력·처리·출력 전 과정)
- Kill Switch(Circuit Breaker) 구현 의무
- 롤백 절차 사전 정의
- 운영 승격: AX팀장 + 준법감시인 사전 검토 후 AI 위원회 상정·의결 필수 (예외 없음)

### 중위험

- AI 산출물은 초안, 담당자 검토 후 최종 확정
- 분기별 KPI 점검 (정확도·오류율)
- AX Hub 과제 등록 의무

### 저위험

- AX Hub 과제 등록 권장
- 연 1회 운영 현황 보고

---

## 4. 에이전트 등록 절차

1. AX Hub `/registry/new`에서 에이전트 등록 신청
2. 위험등급 자가진단 후 선택 (불명확하면 AX팀 문의 — 상위 등급으로 분류)
3. AX팀 검토 및 위험등급 확정 (통상 3영업일 내)
4. 등급별 통제 요건 충족 후 단계 전환 요청

---

## 5. 에이전트 라이프사이클

```
신청(APPLIED) → 파일럿 승인(PILOT) → 운영 중(ACTIVE) → 유지보수(MAINTENANCE) → 폐기(RETIRED)
```

- 각 단계 전환은 AX팀이 AX Hub `/registry`에서 처리한다
- ACTIVE 전환은 Gate 2 기술 자가점검 4개 항목 전부 충족 필요
- 장기 미사용(6개월) 또는 보안 이슈 발생 시 AX팀이 RETIRED 처리 가능

**Kill Switch(비상 중단) 실행**: 운영 중 에이전트에서 비정상 동작이 감지될 경우, 담당자가 AX Hub `/registry` → 해당 에이전트 → [긴급 중단] 버튼을 클릭하면 즉시 SUSPENDED 상태로 전환된다. 이후 AX팀에 사유 보고 및 복구 계획 제출이 필요하다.

---

## 6. 감사로그 최소 필드 (고위험)

| 필드 | 내용 |
|------|------|
| timestamp | UTC ISO 8601 |
| agent_id | AX팀 발급 식별자 |
| event_type | llm_call / tool_call / human_checkpoint / error |
| input_summary | 입력 요약 (기밀 원문 제외) |
| output_summary | 출력 요약 |
| user_id | 요청자 식별자 |
