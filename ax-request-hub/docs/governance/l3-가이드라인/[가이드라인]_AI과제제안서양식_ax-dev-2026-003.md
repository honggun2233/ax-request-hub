## 목적

AX Hub에 AI 과제를 신청할 때 필요한 정보를 사전에 정리해 제출하는 표준 양식이다. 제안서가 있으면 AX팀이 타당성·우선순위·리소스를 일관된 기준으로 검토할 수 있다.

---

## 작성 원칙

- 항목별 가이드 문구(이탤릭)를 읽고 해당 내용으로 교체한다
- 모르거나 해당 없는 항목은 "미정" 또는 "해당 없음"으로 기재한다
- 분량 제한 없음. 핵심만 담되, 공란은 남기지 않는다
- 제출 경로: AX Hub → 과제 신청 → 제안서 업로드

### [샘플] 월간 운용보고서 핵심 지표 자동 요약 에이전트

#### 1. 기본 정보

| 항목 | 내용 |
|------|------|
| 과제명 | 월간 운용보고서 핵심 지표 자동 요약 에이전트 |
| 신청 팀 | 운용지원팀 |
| 신청자 | 김운용 / 대리 / 내선 1234 |
| 신청일 | 2026-09-04 |
| 과제 유형 | 신규 개발 |
| 목표 완료 시점 | 2026년 11월 (Phase 1 기준) |

#### 2. 문제 정의

**현재 상황**
운용지원팀 담당자 2명이 매월 20개 펀드의 운용보고서(PDF, 평균 15장)를 검토해 핵심 지표(수익률, 추적오차, 기준가, 주요 이벤트)를 엑셀로 수기 취합한다. 작업 소요 시간은 월 평균 6시간, 보고서 제출 마감일 전날 집중된다.

**문제점**
- 수기 입력 과정에서 월 2~3건 단순 오기 발생 (검토 추가 부담)
- 20개 펀드 중 일부 포맷이 달라 표준화가 어렵다
- 담당자 부재 시 대체 인원의 학습 비용이 크다

**해결 목표**
PDF 보고서를 업로드하면 AI가 핵심 지표를 자동 추출·요약하여 표준 형식의 엑셀/대시보드를 생성한다. 담당자는 AI 결과를 검수·승인하는 역할로 전환한다.

#### 3. 제안 솔루션

**솔루션 개요**
운용보고서 PDF를 입력받아 Claude API가 펀드명, 기준일, 수익률(1개월/3개월/연초이후), 추적오차, NAV, 주요 이벤트 텍스트를 추출하고, 표준 엑셀 템플릿과 AX Hub 대시보드에 자동 반영한다.

**주요 기능**

| 기능 | 설명 |
|------|------|
| PDF 텍스트 추출 | 보고서 PDF에서 지표 영역 자동 인식 및 파싱 |
| 핵심 지표 정형화 | 추출 결과를 표준 필드(수익률/추적오차/NAV 등)에 매핑 |
| 오류 플래그 | 추출 신뢰도가 낮거나 이상값 감지 시 담당자에게 경고 표시 |
| 엑셀 자동 생성 | 표준 양식 엑셀 파일 자동 완성 및 다운로드 |
| 이력 관리 | 월별 처리 이력 저장, AX Hub에서 조회 가능 |

**사용자 시나리오**
① 담당자가 AX Hub에 로그인 → ② 보고서 PDF 20개를 일괄 업로드 → ③ AI가 각 PDF에서 핵심 지표 추출 (예상 소요: 5분) → ④ 담당자가 이상 플래그 항목만 수동 확인 → ⑤ 확인 후 엑셀 다운로드 및 제출
