# AI 도구 계정 관리 운영 가이드

| 항목 | 내용 |
|------|------|
| 문서번호 | AX-OPS-2026-002 |
| 버전 | v1.0 |
| 최종 개정일 | 2026-07-31 |
| 근거 | 「AI 운영 규정」 제5조, 「AI 운영 지침」 제33조 |
| 담당 | AX팀 |

---

## 1. 목적

전사 AI 도구(GPT, Gemini) 계정 배분·운영의 최소 절차와 기준을 정한다.

---

## 2. 대상 도구 및 계약 구조

| 도구 | 용도 |
|------|------|
| ChatGPT Chat (OpenAI) | 문서 작성·요약·분석 |
| ChatGPT for Excel (M365) | Excel·Word·Outlook AI 기능 |
| Gemini Enterprise (Google) | Google Workspace 통합 AI |

> 계정 발급·회수는 삼성SDS 담당 채널을 통해 처리한다. OpenAI·Google에 직접 연락하지 않는다.

---

## 3. 역할과 책임

| 역할 | 책임 |
|------|------|
| AX팀 | 부서별 쿼터 설정, 전사 현황 모니터링, SDS 계정 발급 요청 |
| 부서장 | 쿼터 내 자율 배정·회수·재배정 |
| 임직원 | 부서장 경유 신청, 발급 후 온보딩 완료 |

---

## 4. 계정 배정 절차

1. 임직원이 부서장에게 필요성 전달
2. 부서장이 AX Hub `/dept/tools`에서 잔여 쿼터 확인 후 배정 신청
3. AX팀 → SDS 계정 발급 요청 (통상 1~2영업일)
4. 임직원이 발급 이메일 수락 + 필수 교육 이수 + 보안 서약 완료

---

## 5. 데이터 기밀등급 제한

| 기밀등급 | 사용 여부 |
|---------|---------|
| G1 (일반) | 허용 |
| G2 (내부) | 허용 (파일 업로드 주의) |
| G3 (기밀) | **절대 금지** |

---

## 6. 계정 회수 기준

| 조건 | 처리 |
|------|------|
| 90일 연속 미사용 | 경고 후 자동 회수 |
| 퇴직·이직·장기휴직 | HR 통보 즉시 회수 |
| 보안 정책 위반 | 즉시 강제 회수 |

---

## 7. 모니터링 및 보고

- AX팀은 월 1회 계정 가동률·비용·보안 이슈를 AX위원회에 보고한다
- 분기마다 미사용 계정 회수 및 쿼터 재검토 진행
