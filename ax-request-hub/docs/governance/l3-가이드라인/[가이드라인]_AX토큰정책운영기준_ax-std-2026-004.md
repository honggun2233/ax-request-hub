# AX 토큰 정책 운영 기준

| 항목 | 내용 |
|------|------|
| 문서번호 | AX-STD-2026-004 |
| 버전 | v1.0 |
| 최종 개정일 | 2026-07-31 |
| 근거 | 「AI 운영 규정」 제5조, 「AI 운영 지침」 제33조 |
| 담당 | AX팀 (기술 집행), HR팀 (최종 승인) |

---

## 1. 목적

전사 AI 도구 토큰 사용량의 레벨별 배분 기준을 명시하여 비용을 통제하고 공정한 자원 배분을 실현한다.

---

## 2. 승인 구조

| 역할 | 책임 |
|------|------|
| **HR팀** | 레벨별 한도 기준 최종 승인, 분기 조정 승인 |
| **AX팀** | HR팀 승인 기준 기반 기술 설정·모니터링·알림 처리 |
| **부서장** | 부서 쿼터 내 팀원 배정 집행 |
| **임직원** | 배정된 한도 내 사용 |

> AX팀 단독으로 레벨별 한도를 신설하거나 변경할 수 없다. 한도 변경은 HR팀 승인 후 시행한다.

---

## 3. 레벨별 월 토큰 한도 (기준값)

아래 수치는 HR팀 승인 기준값이다. 변경 시 HR팀 재승인 필요.

| 레벨 | 월 토큰 한도 | 적용 서비스 |
|------|-------------|------------|
| L0 | 미배분 | — |
| L1 | 100,000 | GPT for Excel / Gemini |
| L2 | 300,000 | GPT Chat |
| L3 | 700,000 | GPT Chat · Claude |
| L4 | HR팀·AX팀 개별 협의 | 전체 |

---

## 4. 모니터링 및 알림

- 월 한도 80% 도달 시 → 임직원·부서장 자동 알림
- 월 한도 초과 시 → 해당 월 사용 제한, 익월 자동 초기화
- AX팀은 월 1회 전사 사용 현황을 AX위원회에 보고

---

## 5. 한도 예외·조정

- 개인 예외 한도 필요 시: 부서장 → HR팀 신청 → HR팀 승인 → AX팀 설정
- 레벨 기준값 변경: HR팀 검토·승인 → AX위원회 보고 후 시행
