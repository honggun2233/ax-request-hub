## 1. 목적

AX Hub에 등록되는 AI 과제의 개발 인수 기준, 배포 환경 결정, AI데이터플랫폼팀 연계 절차를 명시한다.

---

## 2. 임직원 개발 완료 기준 (AX팀 인수 조건)

임직원(현업 PoC 개발 주체)은 아래를 충족하면 AX팀에 인수한다.

1. 핵심 기능 동작 확인 가능 (로컬·개발 환경 시연)
2. 입력/출력 데이터 명세 문서화
3. 핵심 코드 버전관리 저장소 등록 (내부·기밀 데이터 포함 시 내부 GitLab 사용)
4. 데이터 기밀등급 명시 (G1 공개정보/G2 대외비/G3 기밀·극비)

**임직원이 하지 않는 것**: 운영 인프라, 인증·권한 설계, SLA·모니터링, AI데이터플랫폼팀 공식 연동

---

## 3. 배포 환경 결정 기준

| 조건 | 배포 환경 |
|------|----------|
| 기밀 데이터 포함 | 내부 온프레미스 (외부 클라우드 금지) |
| 실시간·대용량 처리 또는 코어 시스템 연동 필요 | AWS Landing Zone 우선 |
| 단기 실증 + 일반·내부 데이터만 처리 | GPT Enterprise 우선 |
| 기준 충돌·판단 곤란 | AX팀장 결정 |

> 배포 환경은 AI데이터플랫폼팀이 결정·관리하며, 환경 변경 시 AI데이터플랫폼팀과 협의한다.

---

## 4. Gate 2 기술 표준 자가점검 (인수 신청 시 제출)

Gate 2 검증 주체는 과제의 위험등급에 따라 달라진다.

**고위험 또는 기밀 데이터 취급 — 3자 공동 검증**

| 검증 주체 | 검증 내용 |
|-----------|----------|
| AX팀 | 기획 적정성, 거버넌스 기준 충족 여부, 위험등급 확정 |
| AI데이터플랫폼팀 | 배포 환경 적합성, 인프라·운영 기술 기준 충족 여부 |
| 정보전략팀 | 보안 기준·DLP·암호화 정책 충족 여부 (공식 검토·서명) |

**중위험 이하 (일반·내부 데이터) — 2자 검증**

| 검증 주체 | 검증 내용 |
|-----------|----------|
| AX팀 | 기획 적정성, 거버넌스 기준 + 정보전략팀 보안 체크리스트 기준으로 확인 |
| AI데이터플랫폼팀 | 배포 환경 적합성, 인프라·운영 기술 기준 충족 여부 |

**저위험 — 자가점검 + AX팀 사후 확인**

**자가점검 4항목** (현업이 인수 신청 시 제출)

| 항목 | 요건 |
|------|------|
| API 명세 | OpenAPI 3.0 또는 동등한 인터페이스 문서 |
| 데이터 기밀 처리 | 일반/내부/기밀 분류 및 처리 계획 명세 |
| 감사로그 설계 | 주요 이벤트 로그 구조·보존 계획 |
| 테스트 커버리지 | 비즈니스 로직 단위 테스트 80% 이상 |

AX팀·AI데이터플랫폼팀 양 팀 모두 확인 완료 시 다음 단계 진행 가능  
미충족 항목 있음 → Gate 2 보류, AX팀 컨설팅 후 재신청

---

## 5. AI데이터플랫폼팀 연계 원칙

- 임직원은 샘플·더미 데이터만 사용한다. 운영 DB·데이터레이크 직접 접근 금지.
- 운영 데이터 연동은 AX팀이 AI데이터플랫폼팀에 공식 요청한다.
- 요청 시 필요 데이터 목록, 갱신 주기, 기밀등급, 예상 부하를 명시한다.
