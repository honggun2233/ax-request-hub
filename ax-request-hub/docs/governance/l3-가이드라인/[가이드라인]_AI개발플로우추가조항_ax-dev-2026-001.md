## 1. 목적

AX Hub에 등록되는 AI 과제의 개발 인수 기준, 배포 환경 결정, 데이터플랫폼팀 연계 절차를 명시한다.

---

## 2. 임직원 개발 완료 기준 (AX팀 인수 조건)

임직원(현업 PoC 개발 주체)은 아래를 충족하면 AX팀에 인수한다.

1. 핵심 기능 동작 확인 가능 (로컬·개발 환경 시연)
2. 입력/출력 데이터 명세 문서화
3. 핵심 코드 버전관리 저장소 등록 (내부 G2 데이터 포함 시 내부 GitLab 사용)
4. 기밀등급 명시 (G1/G2/G3)

**임직원이 하지 않는 것**: 운영 인프라, 인증·권한 설계, SLA·모니터링, 데이터플랫폼 공식 연동

---

## 3. 배포 환경 결정 기준

| 조건 | 배포 환경 |
|------|----------|
| G3 기밀 데이터 포함 | 내부 온프레미스 (외부 클라우드 금지) |
| G1·G2 + 전사 임직원 대상 + 범용 LLM | GPT Enterprise |
| G1·G2 + 높은 트래픽·확장 필요 | AWS |
| G1·G2 + 사내 시스템 직접 연동 | 내부 온프레미스 |

> 배포 환경 변경은 AX팀장 승인 필요.

---

## 4. Gate 2 기술 표준 자가점검 (인수 신청 시 제출)

| 항목 | 요건 |
|------|------|
| API 명세 | OpenAPI 3.0 또는 동등한 인터페이스 문서 |
| 데이터 기밀 처리 | G1/G2/G3 분류 및 처리 계획 명세 |
| 감사로그 설계 | 주요 이벤트 로그 구조·보존 계획 |
| 테스트 커버리지 | 비즈니스 로직 단위 테스트 80% 이상 |

4개 항목 전부 충족 + 6차원 점수 70점 이상 → 자동 승인 가능  
미충족 항목 있음 → Gate 2 보류, AX팀 컨설팅 후 재신청

---

## 5. 데이터플랫폼팀 연계 원칙

- 임직원는 샘플·더미 데이터만 사용한다. 운영 DB·데이터레이크 직접 접근 금지.
- 운영 데이터 연동은 AX팀이 데이터플랫폼팀에 공식 요청한다.
- 요청 시 필요 데이터 목록, 갱신 주기, 기밀등급, 예상 부하를 명시한다.
