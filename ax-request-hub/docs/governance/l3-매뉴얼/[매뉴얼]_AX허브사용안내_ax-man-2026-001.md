---

## 1. 시스템 접속

| 기능 | 경로 |
|------|------|
| 메인·홈 | `/` |
| AI 채팅으로 과제 신청 | `/chat` |
| 직접 양식으로 과제 신청 | `/projects/new` |
| 내 과제 현황 | `/me/projects` |
| 내 AI 도구 | `/me/tools` |
| 데이터 찾기·신청 | `/data/catalog` |

> 실제 접속 주소는 AX팀이 공지한 사내 주소를 사용한다.

---

## 2. AI 과제 신청 절차

1. `/chat` 또는 `/projects/new`에서 신청서 작성·제출
2. AI 자동 평가 (6차원 스코어카드, 약 30초)
3. 판정 결과 통보

| 판정 조건 | 결과 |
|----------|------|
| 일반·내부 + 70점 이상 | 자동 파일럿 승인 |
| 68~69점 | AX팀 검토 후 5영업일 내 결정 |
| 기밀 또는 68점 미만 | 상위 결재 (최대 10영업일) |

---

## 3. 신청서 필수 기재 항목

| 항목 | 작성 기준 |
|------|----------|
| 과제명 | 도입 목적이 드러나도록 |
| 신청 부서·담당자 | 부서명 + 성명 |
| 기대 효익 | 정량 수치 포함 |
| 취급 데이터 기밀등급 | 일반 / 내부 / 기밀 선택 |

**기밀등급 선택 기준**

| 등급 | 데이터 종류 |
|------|-----------|
| 일반 | 공시자료·뉴스·공개 정보 |
| 내부 | 사내 업무문서·비공개 보고서 |
| 기밀 | 고객 개인정보·운용 포지션·미공개 투자정보 → 외부 AI 사용 금지 |

---

## 4. 데이터 신청 절차

AI데이터플랫폼팀 관리 데이터가 필요한 경우:

1. `/data/catalog`에서 데이터 검색 및 이용 신청
2. AI데이터플랫폼팀 `/dp/requests`에서 검토·승인 (기밀 포함 시 추가 시간 소요)
3. 승인 완료 후 `/me/data`에서 연결 정보 확인

> 데이터 신청 전건이 PROVISIONED 상태여야 GATE1 → GATE2 전환 가능.
