|------|------|
| 문서번호 | AX-MAN-2026-001 |
| 버전 | v1.2 |
| 최종 개정일 | 2026-08-04 |
| 적용범위 | 삼성자산운용 전 임직원 |
| 담당 | AX팀 |

---

## 1. 시스템 접속

| 기능 | 경로 |
|------|------|
| 메인·홈 | `/` |
| AI 채팅으로 AI 활용 신청 | `/chat` |
| 직접 양식으로 AI 활용 신청 | `/projects/new` |
| 내 AI 활용 현황 | `/me/projects` |
| 내 AI 도구 | `/me/tools` |
| 데이터 찾기·신청 | `/data/catalog` |

> 실제 접속 주소는 AX팀이 공지한 사내 주소를 사용한다.

---

## 2. AI 활용 신청 절차

1. `/chat` 또는 `/projects/new`에서 신청서 작성·제출
2. AI 자동 평가 (6차원 스코어카드, 약 30초)
3. 판정 결과 통보

| 판정 조건 | 결과 |
|----------|------|
| G1(공개정보)·G2(대외비) + 70점 이상 | 자동 파일럿 승인 |
| 68~69점 | AX팀 검토 후 5영업일 내 결정 |
| G3(기밀·극비) 또는 68점 미만 | 상위 결재 (최대 10영업일) |

---

## 3. 신청서 필수 기재 항목

| 항목 | 작성 기준 |
|------|----------|
| AI 활용명 | 도입 목적이 드러나도록 |
| 신청 부서·담당자 | 부서명 + 성명 |
| 기대 효익 | 정량 수치 포함 |
| 취급 데이터 기밀등급 | G1(공개정보) / G2(대외비) / G3(기밀·극비) 선택 |
| 본질적 업무 해당 여부 | G3(기밀·극비) 데이터 사용 시 필수 확인 |

**기밀등급 선택 기준**

| 등급코드 | 표시명 | 데이터 종류 |
|---------|--------|-----------|
| G1 | 공개정보 | 공시자료·뉴스·공개 정보 |
| G2 | 대외비 | 사내 업무문서·비공개 보고서 |
| G3 | 기밀·극비 | 고객 개인정보·운용 포지션·미공개 투자정보 → 외부 AI 사용 절대 금지 |

---

## 4. 데이터 신청 절차

AI데이터플랫폼팀 관리 데이터가 필요한 경우:

1. `/data/catalog`에서 데이터 검색 후 이용 신청
2. 신청 시 다음 항목을 추가로 기재한다.

| 항목 | 내용 |
|------|------|
| 이용 트랙 | Track A(데이터 활용) 또는 Track B(AI 연계) 선택 |
| 접근 유형 | 조회 / 추출 / 반출 중 선택 |
| 비식별 처리 | 적용 여부 및 처리 방법·범위 기재 |

3. 데이터 오너(소관 부서) 1차 검토(OWNER_REVIEW) → AI데이터플랫폼팀 최종 승인
4. 승인 완료 후 `/me/data`에서 연결 정보 확인

> 데이터 신청 전건이 PROVISIONED 상태여야 GATE1 → GATE2 전환 가능.

> G3(기밀·극비) 데이터는 Track B(AI 연계) 신청 시 AI 위원회 별도 심의가 필요하다.

---

## 5. 신청 수정·취소 절차

- **검토 전 단계(SUBMITTED)**: AX Hub 내 해당 신청 → [수정] 또는 [취소] 버튼으로 직접 처리 가능
- **검토 중 단계**: 수정·취소가 필요한 경우 AX Hub [문의하기] 또는 AX팀에 직접 연락
- **승인 완료 후**: 내용 변경은 신규 신청으로 처리 (기존 신청 취소 후 재제출)

## 6. 자주 묻는 질문

**Q. 신청 후 결과가 언제 나오나요?**
G1·G2 + 70점 이상이면 약 30초 내 자동 통보됩니다. 그 외는 최대 10영업일이 소요됩니다. AX Hub `/me/projects`에서 현재 상태를 확인할 수 있습니다.

**Q. 기밀등급을 잘못 선택했을 때는?**
SUBMITTED 상태에서는 [수정]으로 직접 변경합니다. 검토 중이라면 AX팀에 연락해 보정을 요청합니다.

**Q. 데이터 신청을 해야 하는데 카탈로그에 원하는 데이터가 없어요.**
AX Hub [문의하기]에 필요한 데이터를 설명하면 AX팀이 AI데이터플랫폼팀과 연계해 카탈로그 등록 여부를 검토합니다.

**Q. Gate 1 → Gate 2 전환이 안 돼요.**
데이터 신청 건이 모두 PROVISIONED 상태인지 확인하세요. 미완료 신청이 있으면 전환이 차단됩니다.

**Q. AI 도구 계정은 어디서 신청하나요?**
AI 도구 계정은 AX Hub가 아닌 부서장 경유 신청입니다. 부서장이 AX Hub `/dept/tools`에서 쿼터 확인 후 AX팀에 발급을 요청합니다.
