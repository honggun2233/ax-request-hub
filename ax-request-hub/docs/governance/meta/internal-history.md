## v1.0 확정 후 변경 이력 (공식 이력은 각 문서 문서 이력 표 참조)

### 2026-07-31 팀 R&R 정렬 (AX/PI센터 4개 팀 구성 확정에 따른 수정)

배경: AX/PI센터가 AX팀·AI데이터플랫폼팀·IT업무개발팀·정보전략팀 4개 팀으로 구성됨 확정.  
배포 환경 관리 소관 = AI데이터플랫폼팀으로 명시적 이관 결정.

| 문서 | 변경 내용 |
|------|-----------|
| L1 규정 (AX-REGULATION-2026-001) | 제14조 수정(운영 전환 분리), 제15조 신설(AI데이터플랫폼팀), 제16조 신설(정보전략팀) → v1.1 |
| L1 위원회 규정 (AX-COMMITTEE-2026-001) | 제1조 위원회 구성 확정(CFO 위원장 등), 제8조 실무협의체 구성 반영 → v1.1 |
| L2 지침 (AX-POLICY-2026-001) | 제9조 — 배포 환경 결정을 AI데이터플랫폼팀 협의로 명시 → v1.1 |
| L3 AI개발플로우 (AX-DEV-2026-001) | 팀명 정정, 배포 환경 결정권 AI데이터플랫폼팀 명시 → v1.1 |
| L3 전사개발표준 (AX-DEV-2026-002) | Phase 3 역할 분리 — AX팀 인수 / AI데이터플랫폼팀 배포 → v1.1 |
| 매뉴얼 (AX-MAN-2026-001) | 팀명 정정(데이터플랫폼팀 → AI데이터플랫폼팀) → v1.1 |

*AX/PI센터 AX팀 | 내부 개발 참고 이력 | 공식 문서 이력 아님*
