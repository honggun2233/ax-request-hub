## 2026-07-28 — 거버넌스 전면 개편 (REGULATION v2.0 / POLICY v5.0 / STANDARD v1.0 신설 / COMMITTEE v1.1)

### 변경 개요

거버넌스 개정 태스크포스(Fable 검토) 완료 → Full 문서 전면 교체. 핵심 변경: 수치 분리(STANDARD 신설), GUIDELINE 폐지·통합, 문서 간 중복 제거, 실무 유연성 강화.

| 파일 | 이전 → 이후 | 방향 |
|------|------------|------|
| AX-REGULATION | v1.x → **v2.0** | GUIDELINE 흡수, 수치→STANDARD 위임 |
| AX-POLICY | v4.x → **v5.0** | 463줄→~180줄, 수치 전면 삭제 |
| AX-STANDARD | (신설) → **v1.0** | 수치 SSOT — AX팀장 전결 개정 |
| AX-COMMITTEE | v1.0 → **v1.1** | 위임전결·서면결의 신설 |
| AX-GUIDELINE | v1.x → **폐지** | REGULATION 제5조로 흡수 |

| # | 변경 | 문서 | 조항 |

## 2026-07-14 — ETF 앙상블 에이전트 Gate 라이프사이클 반영

### 변경 개요

ETF 앙상블 에이전트 19종의 등록·운영 체계를 정립하고, AX Hub 에이전트 레지스트리 UI를 라이프사이클 기반으로 전면 재설계함에 따라 관련 지침을 업데이트.

---

### 파일별 변경 상세

#### 1. `지침_AI_에이전트등록통제.md` — v1.1 → v1.2

| 변경 구분 | 상세 내용 |
|---------|---------|
| **제15조의4 신설** | ETF 앙상블 에이전트 Gate 라이프사이클 — 범용 Phase 라이프사이클과 별도로 Gate 3단계(기능·도메인·스트레스) 기반 전문 라이프사이클 적용 |
| **Gate 단계 정의** | DEVELOPING → GATE1(fallback≤30%) → GATE2(SAM LAB 30일 정확도≥55%+신뢰점수≥3) → GATE3(크래시0) → ACTIVE → DEGRADED → RETIRED |
| **운용역 리뷰 절차** | Gate2 통과 기준: SAM LAB + AX Hub 레지스트리에서 신뢰점수(1~5) 태깅 |
| **DEGRADED 자동감지 기준** | 정확도<50% 또는 fallback율>70%, 2주 연속 |
| **제17조② 추가** | AX Hub 에이전트 레지스트리(http://localhost:3005/registry)를 ETF 에이전트 인벤토리 단일 공식 기록 시스템으로 지정 |
