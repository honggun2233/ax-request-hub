## 문서 계층 구조

```
L1  규정        — 전사 강제 준수 사항 (임원·위원회 승인)
 └─ L2  지침    — 방침·기준 설정 (AX팀 운영 기준)
     └─ L3  가이드라인  — 업무 수행 절차·기술 기준
         └─ L3  매뉴얼  — 시스템 사용법 (임직원 참고)
```
