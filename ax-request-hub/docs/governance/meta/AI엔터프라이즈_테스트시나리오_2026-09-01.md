## 도입 배경 및 전제

- 삼성자산운용은 Claude Enterprise를 포함한 기업용 AI 3종을 도입 중
- Claude = **순량제(종량제)**, 나머지 2종 = 정액(허용량) 기반
- 현재 업무망: 웹챗만 허용 (Cowork·Code 차단)
- AI연구망: 미개방 (열릴 예정)
- 핵심 질문: "Claude를 어디에, 얼마나 써야 비용 대비 효과가 나오는가?"

## 시나리오 A — "Claude만 되는 일" 실측 (우선순위 1)

**목적**: 다른 AI도 되는지, Claude 고유 우위인지 3종 비교 실측으로 확정

| # | 시나리오 | 입력 조건 | 측정 항목 |
|---|---------|----------|----------|
| A-1 | Excel/PDF → 정형 리포트 자동 생성 | 운용 포지션 요약 Excel (대외비 마스킹) + 양식 템플릿 | 오류 건수 / 양식 준수율 / 손질 시간 |
| A-2 | 규정 문서 질의응답 (프로젝트 업로드) | AI-REG-2026-001 전문 + 임직원 질문 10종 | 정확도 / hallucination 감지 |
| A-3 | 스킬 MD 작성 후 자기 실행 검증 | 기존 반복 업무 절차 1개 (예: ETF 일일 보고) | 재현 성공률 / 오류 없는 입력 처리 여부 |
| A-4 | 코드 생성 + 즉시 실행 검증 (Claude Code) | 데이터 정제 Python 요건 + 샘플 CSV | 동작률 / 수정 없이 사용 가능 비율 |

**방법**: 동일 프롬프트·동일 데이터로 3종 AI 동시 실행 → 오류 건수·양식·토큰·손질 시간 채점

**채점 기준** (A3 의사결정 카드 기준)

| 측정 항목 | 기준 |
|----------|------|
| 동작 | 고정 입력 3종 × 3회 실행, 오류 없는 입력 1종 혼합 |
| 품질 | 양식 준수, 지어내기 없음, 최종 확인자 검토 불필요 수준 |
| 토큰 | `/usage`로 세션별 기록, 단가 × 토큰 = 실비용 |
| 타 AI 대비 | 동일 조건으로 3종 실행, 오류·손질 시간 비교 |

## 시나리오 B — 스킬 표준 절차 검증 (우선순위 2)

**목적**: 스킬 작성 → 검증 → 배포 6단계가 실제로 작동하는지 확인

| 단계 | 작업 내용 | 담당 | 성공 기준 |
|------|----------|------|----------|
| B-1 | 챗에서 반복 업무 절차 탐색 (업무망) | 현업 1명 | 탐색 토큰 기록, 30분 이내 절차 도출 |
| B-2 | 절차를 스킬 템플릿 MD로 작성 | 현업 | 7항목(입력 조건·데이터·시점·승인 지점·자기검증·금지 목록·토큰 기준) 충족 |
| B-3 | 고정 입력 3종 × 3회 + 오류 입력 1종 실행 | AX | 재현율 100%, hallucination 없음 |
| B-4 | AX 검수 (데이터 경로·금지 항목·소유자·폐기 조건) | AX | 체크리스트 전 항목 통과 |
| B-5 | 관리자 그룹 배포 → 타 현업 2명 첫 실행 | 관리자 → 현업 | 첫 실행 성공률 100% |

## 시나리오 C — 토큰 비용 3구간 실측 (우선순위 3)

**목적**: PoC 비용과 운영 비용을 구간별로 분리, 손익분기 실행 횟수 도출

| 구간 | 측정 방법 | 기록 방식 |
|------|----------|----------|
| C-1 탐색 | 챗 브레인스토밍 1세션 | `/usage` → 토큰 수 기록 |
| C-2 제작 | 스킬 MD 완성까지 별도 세션 | `/usage` → 토큰 수 기록 |
| C-3 운영 | 스킬 실행 10회 | 회당 `/usage` 기록, 평균 산출 |
| C-4 ROI | (탐색+제작 단가) ÷ 월 실행 횟수 + 운영 회당 단가 | 손익분기 N회 계산 |

**판단 공식**

```
월 실행 횟수 ≥ (탐색+제작 비용) / (비교 AI 회당 비용 - Claude 회당 비용)
→ 스킬화 + Claude 사용이 이득
```

**목적**: 실제 도입 과제가 AI-GUI-2026-001 절차를 처음부터 끝까지 준수하는지

|------|---------|------------|
| D-1 | 현업이 AX Hub에 과제 신청 | 신청서 필수 항목(과제명·신청 부서·기대 효익·데이터 개요) 기재 |
| D-2 | 자동 평가 점수 산정 | 기밀등급·배점 정확도 (AI-STD-2026-001 §1 기준) |
| D-3 | Gate 1 → 파일럿 샌드박스 착수 | 운영 환경 접근 차단 여부 확인 |
| D-4 | Gate 2 기술표준 자가점검 | 고위험: AX + AI데이터플랫폼 + 정보전략팀 3자 검증 완료 여부 |

| D-6 | 위험 평가표 작성 (R-01~R-11) | 11개 유형 전부 평가·잔류 위험 등급 산정 완료 |

| D-8 | 위원회 상정 준비 | devStage ≥ GATE3 + 파일럿 30일 실측 + 목표 KPI 달성 여부 |
