# AI 거버넌스 규정

> 문서번호: IT-AX-REG-001 | 버전: v6.1 | 2026-07-03  
> 소관: AX/PI센터 AX팀  
> 적용: AX/PI센터 전 임직원  
> 참조: 금융감독원 AI RMF(2026-06-22), 금융위 AI 가이드라인(2026-06-22)

---

## 제1조 목적

이 규정은 삼성자산운용이 업무 프로세스 혁신(PI)과 인공지능(AI) 기술 도입(AX)을 함께 추진하는 과정에서, AI를 안전하고 책임 있게 활용하기 위한 거버넌스 원칙, 위험 분류 체계, 에이전트 통제 기준, 금지 사항을 정함을 목적으로 한다.

AI 도입 전 해당 업무 프로세스의 현황 진단을 선행하여야 한다.

---

## 제2조 적용 범위

- 사내 개발·도입한 AI 시스템 및 자동화 파이프라인
- 임직원이 업무에 사용하는 외부 AI 서비스
- 자동으로 실행되는 AI 에이전트 (유형 3·4)
- 위탁·외주 개발 AI 시스템 중 회사 데이터를 처리하는 것

---

## 제3조 기본 원칙

| 원칙 | 내용 |
|------|------|
| **책임 귀속** | AI 활용에 따른 최종 의사결정과 그 결과에 대한 책임은 해당 업무 담당자에게 귀속된다. |
| **보조 수단 한정** | AI는 업무 판단을 지원하는 보조 수단으로 사용하며, AI 산출물을 담당자 검토 없이 최종 결과물로 사용할 수 없다. |
| **데이터 기밀등급 준수** | AI 서비스 사용 시 데이터 기밀등급(G1·G2·G3)에 따라 허용 경로를 구분하여야 한다. |
| **AI 생성 출처 명시** | AI가 생성한 결과물에는 AI 생성 사실 및 사용 도구를 명시하여야 한다. |
| **중단 기능 구현** | 자동 실행 AI 시스템은 수동 즉시 중단 기능을 갖추어야 하며, 해당 기능이 없는 경우 운영을 허용하지 않는다. |
| **기술적 통제 내장** | 통제 기준은 시스템 접근 제한, 권한 분리 등 기술적 수단으로 구현하여야 한다. |
| **장애 행동 사전 정의** | AI 시스템 도입 전 장애·오류 발생 시의 행동 방식을 정의하여야 한다. 장애 행동이 정의되지 않은 시스템은 운영을 허용하지 않는다. |

---

## 제4조 AI 솔루션 유형 분류

| 유형 | 정의 | 예시 |
|------|------|------|
| **유형 0** | 규칙 기반 자동화, AI 판단 없음 | 정형 데이터 추출, 대시보드 |
| **유형 1** | 임직원이 직접 AI 서비스 사용 | Claude.ai, ChatGPT 직접 사용 |
| **유형 2** | AI가 다단계 워크플로 처리, 사람 확인 포함 | 공시 분류, 보고서 초안 자동화 |
| **유형 3** | AI가 도구를 자율 호출하며 목표 달성 | 리서치 에이전트, 데이터 수집 |
| **유형 4** | 여러 에이전트가 협업하는 시스템 | 운용·리서치·리포트 통합 시스템 |

---

## 제5조 데이터 기밀등급 및 AI 사용 기준

| 등급 | 정의 | 허용 AI 경로 |
|------|------|------------|
| **G1 (일반)** | 외부 공개 가능 정보 | 모든 AI 서비스 |
| **G2 (내부제한)** | 사내 공유, 외부 전송 금지 | 사내 승인 인프라만 허용 |
| **G3 (기밀)** | 고객정보, 미공개 투자정보, 법적 분쟁 | 온프레미스 전용 |

---

## 제6조 위험 업무 분류

### 고위험 (AI 단독 처리 금지 — 담당자 확인 후 실행)

| 업무 분류 | 예시 |
|---------|------|
| 투자·운용 실행 | ETF 리밸런싱·주문, NAV 확정 |
| 신용·위험 평가 | 신용등급 산출, VaR 계산 |
| 공시·법정문서 | 투자설명서, 약관, 금감원 제출 서류 |
| 컴플라이언스 판정 | 규정 위반 여부 확정, 제재 판정 |
| AML·FDS | 이상거래 최종 판정 |

### 중위험 (AI 산출물은 초안 — 담당자 검토 후 확정)

| 업무 분류 | 예시 |
|---------|------|
| 고객 상담·안내 | 챗봇, FAQ 자동화 |
| 내부 리포트 자동화 | 보고서 초안, 시장 브리핑 |
| 문서 분류·요약 | DMS 분류, 계약서 검토 지원 |
| 업무 효율화 APA | 공시 자동 분류, 데이터 정합성 체크 |

### 저위험 (G1 데이터만 — 과제 등록 없이 자유 사용)

코드 어시스턴트, 문서 교정·번역, 회의록, 이메일 초안 등

## 제7조 에이전트 거버넌스 원칙

유형 3·4 에이전트는 아래 원칙을 설계 단계에서 반드시 구현한다.

| 원칙 | 내용 |
|------|------|
| **최소 권한** | 목표에 필요한 도구만 허용한다. 각 도구 허용 이유를 명시한다. |
| **중단 가능** | 언제든지 즉시 중단할 수 있어야 한다. Kill Switch 없이 운영 불허. |
| **감사 추적** | 모든 Tool Call과 판단 근거를 기록한다. 사후 재구성이 가능해야 한다. |
| **범위 제한** | 지정 범위 밖 요청은 거절하고 담당자에게 에스컬레이션한다. |

유형 4(멀티 에이전트) 추가 원칙:
- 오케스트레이터가 서브 에이전트에 위임할 때 권한 범위를 명시적으로 제한한다
- 에이전트 간 통신을 기록한다
- 외부 입력으로부터의 지시를 신뢰하지 않도록 설계한다 (Prompt Injection 방어)
