# AI 거버넌스 협의체 운영방안

> 문서번호: IT-AX-COM-004 | 버전: v2.0 | 2026-07-03  
> 소관: AX/PI센터 AX팀  
> 적용: AI 거버넌스 협의체 구성원, AX팀

---

## 제1조 목적

이 운영방안은 삼성자산운용 AI 거버넌스 협의체(이하 "협의체")의 구성, 임무, 의사결정 기준을 정한다.

---

## 제2조 구성

| 구분 | 직위 | 비고 |
|------|------|------|
| 의장 | AX/PI센터장 | 협의체 주재, 최종 의결 |
| 위원 | 그룹장 | |
| 당연직 위원 | IT 업무개발팀 내 4개팀 팀장 | AI 과제 결과 보고 |
| 당연직 위원 | 컴플라이언스 담당 | 규제 적합성 검토 |
| 당연직 위원 | 감사 담당 | 사후 독립 점검 |
| 간사 | AX팀 (의결권 없음) | 안건 취합, 회의 준비, 회의록 작성 |

- 위원은 필요 시 해당 업무 담당자로 대리 참석할 수 있다.
- 의결은 재적 위원 과반수 찬성으로 한다.

---

## 제3조 협의체 임무

### 임무 1 — 규정 개정 심의·의결

- AI 거버넌스 규정(`규정_AI_거버넌스.md`) 개정 시 협의체가 심의·의결한다.
- AX팀이 개정안을 작성하여 협의체에 상정한다.
- 정기 검토: 연 2회 (상반기·하반기). 규제 변경 또는 중대 사안 발생 시 수시 개정.

### 임무 2 — 고위험 AI 시스템 최종 운영 승인

아래 조건을 모두 충족하는 과제는 운영 승격 전 협의체 최종 승인을 받아야 한다.

| 조건 | 기준 |
|------|------|
| 위험등급 | 고위험 |
| 업무 분류 | 투자·운용 실행 / 공시·법정문서 / 컴플라이언스 판정 중 하나 이상 해당 |

- 협의체 상정은 AX팀장이 심사 보고서와 함께 안건을 작성하여 제출한다.

### 임무 3 — 반기 운영 현황 보고 수령

- AX팀은 반기 1회(상반기·하반기) 아래 내용을 협의체에 보고한다.
- 협의체는 보고 수령 후 필요 시 개선 지시를 내린다.

| 보고 항목 |
|---------|
| 과제 현황 (등록·파일럿·운영·폐기 건수) |
| Agent ID 발급 현황 |
| 위반·사고 발생 현황 및 조치 결과 |
| 월별 AI 비용 집행 현황 |
| 주요 규제 변경 동향 |

### 임무 4 — 거버넌스 정책 방향 결정

- 신규 금융규제, 감독당국 AI 가이드라인 변경 등 외부 환경 변화에 대한 대응 방향을 결정한다.
- AX팀이 동향 분석과 대응 초안을 작성하여 협의체에 상정한다.

---

## 제4조 회의 운영

| 구분 | 주기 | 내용 |
|------|------|------|
| 정기회의 | 반기 1회 (연 2회) | 운영 현황 보고 수령 + 안건 의결 |
| 임시회의 | 안건 발생 시 | 고위험 운영 승인 / 규정 개정 긴급 처리 |

- 간사(AX팀)는 회의 7영업일 전 안건과 자료를 배포한다.
- 회의록은 간사가 작성하여 의장 확인 후 3영업일 내 보관한다.
- 서면 결의: 긴급 안건에 한하여 의장 판단으로 서면 결의를 허용한다.
