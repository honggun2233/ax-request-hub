## 1. 문제 정의

**어제 시연에서 드러난 근본 문제**: ETF 관련 데이터가 출처 없이 생성되어, 틀리거나 상충하는 정보가 혼재했다.

| 증상 | 원인 |
|------|------|
| ETF 성과 수치가 실제와 다름 | 검증된 단일 데이터 소스 없음 |
| 같은 질문에 다른 답이 나옴 | RAG 없이 LLM이 생성 (환각) |
| 출처를 물었을 때 답 못함 | 인용 근거 구조 부재 |

**해결 방향**: 리서치 센터 = 출처 강제 + 환각 검증이 내장된 RAG 기반 데이터 허브

---

## 2. 리서치 센터 정의

**리서치 어시스턴트 (RAG, G2)**

공시·리포트·뉴스·ETF 유니버스 데이터를 단일 검증된 소스로 통합하고, AI가 이 데이터에서만 답하도록 강제하는 시스템.

### 핵심 기능

| 기능 | 설명 | 기밀등급 |
|------|------|---------|
| 공시 검색 | DART 공시 자동 수집·인덱싱, 자연어 검색 | G2 |
| ETF 리포트 RAG | 운용사·증권사 리포트 RAG 검색 + 인용 | G2 |
| 뉴스 모니터링 | ETF 관련 뉴스 자동 수집·요약·알림 | G1 |
| ETF 유니버스 | KRX 상장 ETF 마스터·구성종목·성과 데이터 | G2 |
| 어닝콜 STT | IR·어닝콜 음성→텍스트→요약·핵심지표 추출 | G2 |
| 교차 검증 | 동일 주제 여러 소스 비교, 불일치 탐지 | G2 |

### 출처 강제 원칙
```
모든 AI 답변 = 주장 + [출처: 문서명, 날짜, 페이지/섹션]
출처 없는 단정 → 시스템 레벨에서 응답 거부
"모름" 응답이 틀린 정보보다 낫다
```

### 3.3 현재 보유 자산 (재활용)

- `mhlab-etf` 브리지의 IndexConstructor 산출 데이터

## 4. 아키텍처

```
[데이터 수집 파이프라인]
  ├── DART API → 정제 → Snowflake (G2)
  ├── KRX API → 정제 → Snowflake (G2)
  ├── 뉴스/RSS → 정제 → Snowflake (G1)
  └── 수동 업로드 → 검토 → Snowflake (G2/G3)

[벡터 인덱스 (RAG)]
  └── Snowflake Cortex Search (G2 통합)
      또는 pgvector (로컬 초기 버전)

[리서치 어시스턴트 API]
  ├── 자연어 질의 → 관련 문서 검색 → Claude 요약
  ├── 출처 인용 강제 (소스 없으면 응답 거부)
  └── 환각 검증 (LLM-judge, 신뢰점수 표시)

[사용자 인터페이스]
  └── 리서치 센터 웹 UI (Next.js, 사내 배포)
      ├── 검색 패널 (공시/리포트/뉴스 통합)
      ├── ETF 비교 분석 (숫자는 반드시 출처 첨부)
      └── 어닝콜 요약 뷰어
```

## 5. 구축 단계 (WBS)

### Phase 1 — 데이터 기반 구축 (1~2주)

| 태스크 | 담당 | 산출물 |
|-------|------|-------|
| DART API 연동 + 공시 수집 파이프라인 | CTO | 일일 자동 수집 스크립트 |
| KRX ETF 마스터·NAV 파이프라인 | CTO | ETF 유니버스 DB |
| yfinance 수정주가 파이프라인 | CTO | 가격 히스토리 DB |
| 데이터 품질 검증 규칙 정의 | CDO + 운용역 | 검증 체크리스트 |

### Phase 2 — RAG 구축 (2~3주)

| 태스크 | 담당 | 산출물 |
|-------|------|-------|
| 문서 임베딩 파이프라인 | CTO | 벡터 인덱스 |
| 출처 강제 프롬프트 설계 | AX팀 | 시스템 프롬프트 v1 |
| 환각 검증 LLM-judge 구현 | CTO | 신뢰점수 출력 모듈 |
| 리서치 어시스턴트 API | CTO | `/api/research` 엔드포인트 |

### Phase 3 — UI + 검증 (1주)

| 태스크 | 담당 | 산출물 |
|-------|------|-------|
| 리서치 센터 웹 UI | CTO | localhost:3006 (초기) |
| 운용역·리서치팀 사용 테스트 | 운용역 (fundops) | 검증 보고서 |
| 데이터 정합성 교차 검증 | CDO | 품질 보고서 |
