# AX Hub — Mulesoft 벤치마킹 개념 검토

**작성일**: 2026-08-21
**배경**: Mulesoft 미팅에서 나온 "에이전트 카탈로그/데이터 카탈로그 축 + 스캐너 + 라우팅 기반 플로우 컨트롤" 개념을 AX Hub에 접목할지 검토

---

## 1. 대조 결과

| Mulesoft 개념 | AX Hub 현재 상태 |
|---|---|
| 에이전트 카탈로그 | `AgentRegistry` — 이미 있음, 심사자 뒤에 숨어 안 드러남 |
| 데이터 카탈로그 | `dp/catalog` — 이미 있음, DATA_PLATFORM 역할 뒤에 숨어 있음 |
| **스캐너** | **없음** — AX Hub에 없는 새로운 개념 |

---

## 2. 카탈로그 — 노출 강화, 채택 권장 (★★)

### 문제
지금 두 카탈로그는 심사자 역할(AX_TEAM/DATA_PLATFORM) 전용 화면에 갇혀 있습니다. 일반 직원은 "내가 신청한 것"만 보지 "회사 전체에 이미 뭐가 있는지"는 볼 수 없습니다.

### 제안
두 카탈로그를 **전 직원 탐색 가능한 공개 화면**으로 노출(조회만, 수정 권한은 기존대로 역할 제한 유지).

### 연결되는 기존 작업
- 신청 전 "이미 비슷한 에이전트가 있나" 검색 → 중복 신청 방지
- 인테이크 재설계안(방향2, 과거 유사사례 참고)이 카탈로그 검색으로 자연스럽게 연결됨
- 기존 미결사항인 "지식그래프 영향도 질의 엔진"(데이터 자산 회수 시 영향받는 에이전트 N개 배지, ★★★ 미착수)도 결국 이 카탈로그 위에서 동작하는 기능 — 같은 작업 라인의 연장

### 사이드바 반영
IA 재편(9섹션안)의 "에이전트 거버넌스"·"데이터 거버넌스" 안에 있던 레지스트리/카탈로그 조회 기능을, **읽기 전용으로 "홈" 또는 "내 정보" 근처 전 직원 접근 영역에도 노출**하는 방식을 권장.

---

## 3. 스캐너 — 채택하되 용도를 감사(audit) 도구로 한정 (★★★)

### 왜 필요한가
AX Hub에 없는 새로운 개념이면서, 동시에 오래된 미결사항 하나를 풀 열쇠이기도 합니다 — "Snowflake/Glue 연동이 `DataProvision.revokedAt` 등 기록만 하지 실제 외부 시스템 접근권한 집행은 안 한다"는 문제(v3 이전부터 이어진 미결사항). 스캐너가 실제 시스템을 주기적으로 스캔해서 카탈로그를 실제 상태와 동기화하면 이 갭이 메워집니다.

### 반드시 지켜야 할 경계
**스캐너는 "발견해서 심사 큐에 올리는" 용도로만 한정합니다. "발견하면 자동으로 카탈로그 등재·승인"으로 가면 안 됩니다.**

이유: 지금까지 워크플로우 설계 전반에서 지켜온 원칙 — **"판단이 개입하면 통제 영역"** — 을 스캐너가 깨뜨리게 됩니다. 스캐너가 뭔가(그림자 에이전트, 미등록 데이터 접근)를 발견했다는 것 자체가 이미 "이걸 통제 대상으로 편입할지"를 판단해야 하는 지점이라, 이 지점을 자동승인으로 스킵하면 안 됩니다.

### 채택 범위
- 용도: "그림자 에이전트/데이터"(신청 절차 없이 이미 존재하는 것들)를 찾아내 **Gate1 심사 큐에 자동 상정**
- 효과: 통제를 우회하는 게 아니라 **통제 범위를 넓히는 방향** — 지금까지 신청 안 하고 조용히 쓰던 것들을 수면 위로 끌어올림
- 제외: 스캐너 발견 즉시 자동 등재·승인·권한부여는 하지 않음

## 4. 라우팅 기반 플로우 컨트롤 — 채택 보류 (범위 이탈 우려)

### 판단
이건 "실시간 트래픽을 어느 에이전트로 보낼지" 결정하는 런타임 기능인데, AX Hub는 거버넌스 허브(신청→심사→승인)지 실시간 요청을 처리하는 런타임 시스템이 아닙니다.

### 우려
억지로 붙이면 범위이탈(scope creep) 위험이 큽니다. AX Hub의 정체성("판단하고 파악하는 존재")과 정면으로 어긋나는 기능입니다 — 이미 "실제 배포·실행은 AWS 랜딩존, AX Hub는 판단만"으로 인프라 이원화를 확정한 바 있습니다(인프라 이원화 확정 문서 참조).

### 대안
배포된 에이전트끼리의 라우팅이 실제로 필요하다면, 그건 AWS 인프라(랜딩존) 쪽 역할로 남겨두고 AX Hub는 관여하지 않는 것을 권장.
