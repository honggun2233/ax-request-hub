# AX Hub — 화면 설계서

| 항목 | 내용 |
|------|------|
| 문서번호 | AX-SCREEN-2026-001 |
| 버전 | v1.0 |

> 각 화면의 UI 상세는 `localhost:3005` 실행 후 직접 확인. 본 문서는 라우트·역할·기능 기준 정의서.

---

## 역할 정의

| 역할 코드 | 대상 | 주요 접근 범위 |
|-----------|------|----------------|
| `EMPLOYEE` | 일반 직원 | 과제 신청, 내 정보, 데이터 카탈로그 조회, AI 채팅 |
| `DEPT_HEAD` | 부서장 | EMPLOYEE + 부서 AI 도구 배정 |
| `AX_TEAM` | AX팀 | 전체 관리 (과제 승인, 직원 관리, 토큰 정책, 에이전트 레지스트리) |
| `DATA_PLATFORM` | 데이터플랫폼팀 | 데이터 요청 처리, 데이터 카탈로그 관리 |
| `EXECUTIVE` | 경영진 | 읽기 전용 대시보드 |

## 화면 목록

### 1. 인증

#### `/login` — 로그인
- **접근**: 비인증 사용자
- **기능**: NextAuth 세션 기반 로그인
- **로그인 후**: 역할에 따라 `/dashboard` 또는 `/admin`으로 리다이렉트

---

### 2. 메인 대시보드

#### `/dashboard` — 과제 대시보드
- **접근**: 전체 직원
- **기능**:
  - 내 진행 중인 과제 목록 (status, score, gate 단계)
  - 전체 과제 현황 집계 (AX_TEAM에게는 전사 뷰)
  - 빠른 과제 신청 버튼
  - 알림 뱃지 (미확인 알림 수)

---

### 3. 과제 신청 · 조회

#### `/submit` — 과제 신청
- **접근**: EMPLOYEE 이상
- **기능**:
  - 과제 신청 폼 (제목, 문제 설명, 기대효과, 사용 AI 모델, 데이터 필요 여부, 기밀등급)
  - Gate 2 자가점검 체크리스트 (기술 표준 4항목)
  - 제출 시 Claude API 자동 스코어링 트리거
- **제출 후**: `/status/[id]`로 이동

#### `/status/[id]` — 과제 상태 상세
- **접근**: 과제 신청자 + AX_TEAM
- **기능**:
  - 과제 기본 정보 (제목, 신청일, 현재 단계)
  - 스코어카드 6차원 점수 시각화
  - 승인/반려 이력 타임라인
  - 데이터 신청 현황 (연결된 DataRequest 목록)
  - 에이전트 등록 현황 (AgentRegistry devStage)
  - 이의신청 버튼 (반려 시 활성화)

---

### 4. 내 정보 (직원 자기서비스)

#### `/me` — 내 프로필
- **접근**: EMPLOYEE 이상
- **기능**: 내 정보 요약 (이름, 부서, 레벨, 리터러시 점수, 토큰 사용량)

#### `/me/projects` — 내 과제
- **접근**: EMPLOYEE 이상
- **기능**: 내가 신청한 과제 전체 목록, 상태별 필터

#### `/me/usage` — 내 토큰 사용량
- **접근**: EMPLOYEE 이상
- **기능**:
  - 서비스별 월간 토큰 사용량 차트
  - 잔여 한도 대비 사용량 게이지
  - 최근 6개월 추이

#### `/me/services` — 내 할당 서비스
- **접근**: EMPLOYEE 이상
- **기능**: 본인에게 할당된 AI 서비스 목록, 접근 방법 안내

#### `/me/level` — AI 리터러시 레벨 신청
- **접근**: EMPLOYEE 이상
- **기능**:
  - 현재 레벨 확인 (L0~L4)
  - 레벨 상향 신청 폼
  - 신청 이력 및 현재 처리 상태

#### `/me/literacy` — 리터러시 학습
- **접근**: EMPLOYEE 이상
- **기능**: 리터러시 교육 콘텐츠 목록, 완료 처리

#### `/me/tools` — 내 AI 도구
- **접근**: EMPLOYEE 이상
- **기능**: 배정된 AI 도구 목록, 도구 신청 버튼

#### `/me/data` — 내 데이터 신청
- **접근**: EMPLOYEE 이상
- **기능**: 내가 신청한 데이터 요청 목록, 처리 상태 확인

---

### 5. 데이터 프로비저닝

#### `/data/catalog` — 데이터 카탈로그 (직원용)
- **접근**: EMPLOYEE 이상
- **기능**:
  - 데이터 자산 목록 조회 (이름, 분류, 기밀등급 G1/G2/G3, 소유 부서)
  - 키워드 검색 + 기밀등급 필터
  - 자산 선택 후 이용 신청 → `/data/requests` 생성
  - Snowflake 연동 자산 표시 (sourceSystem=SNOWFLAKE) *(PR #12)*

#### `/dp/requests` — 데이터 요청 처리 (데이터플랫폼팀용)
- **접근**: DATA_PLATFORM, AX_TEAM
- **기능**:
  - 전체 데이터 요청 목록 (PENDING / APPROVED / REJECTED / PROVISIONED)
  - 요청 승인/반려 처리
  - G3 데이터 요청 → 정보보호 협의 표시
  - DataProvision 생성 (이용 기간 설정)

#### `/dp/catalog` — 데이터 카탈로그 관리 (데이터플랫폼팀용)
- **접근**: DATA_PLATFORM, AX_TEAM
- **기능**:
  - 데이터 자산 등록/수정/삭제
  - Snowflake 동기화 트리거 버튼 *(PR #12)*
  - 기밀등급 설정, 이용 정책 관리

---

### 6. 에이전트 레지스트리

#### `/registry` — AI 에이전트 레지스트리
- **접근**: AX_TEAM (관리), EMPLOYEE (조회)
- **기능**:
  - 에이전트 목록 (파이프라인 바: GATE1 / GATE2 / GATE3 / PRODUCTION)
  - 개발 단계(devStage) + 상용 단계(prodStatus) 이중 라이프사이클 표시
  - 에이전트 카드: 신뢰점수, Gate 진행도, Fallback 구현 여부
  - 슬라이드오버: 단계 전환, 신뢰점수 입력, AX 프로젝트 연결 M:N
  - AX 프로젝트 뷰 / 에이전트 뷰 탭 전환

---

### 7. AI 위원회

#### `/council` — AI 위원회 목록
- **접근**: AX_TEAM, EXECUTIVE
- **기능**: AI 위원회 회의 목록, 상태 (DRAFT / SCHEDULED / IN_PROGRESS / CLOSED), 신규 회의 생성

#### `/council/[meetingId]` — AI 위원회 회의 상세
- **접근**: AX_TEAM, EXECUTIVE
- **기능**:
  - 안건 목록 (상정된 에이전트/과제)
  - 안건별 심의 조건 체크
  - 승인 / 반려 / 조건부 의결 기록
  - 의결 결과 에이전트 라이프사이클 자동 업데이트

---

### 8. AI 스킬 라이브러리

#### `/skills` — 스킬 라이브러리
- **접근**: EMPLOYEE 이상
- **기능**:
  - 전사 AI 스킬 목록 (카테고리, 사용 횟수, 평점)
  - 스킬 카드: 제목, 설명, 예시 프롬프트
  - 별점 평가
  - AX_TEAM: 스킬 등록/수정

---

### 9. 거버넌스 문서

#### `/docs` — 거버넌스 문서 뷰어
- **접근**: EMPLOYEE 이상
- **기능**: 마크다운 거버넌스 문서 열람 (규정/지침/매뉴얼)

#### `/governance` — 거버넌스 현황
- **접근**: AX_TEAM
- **기능**: 거버넌스 지표 요약, 문서 버전 현황

---

### 10. AI 채팅

#### `/chat` — AI 어시스턴트 채팅
- **접근**: EMPLOYEE 이상 (리터러시 레벨에 따라 가용 모델 차등)
- **기능**:
  - Claude API 기반 실시간 채팅
  - 토큰 사용량 실시간 누적 (UsageRecord)
  - 대화 이력 (세션 내)

---

### 11. 경영진 대시보드

#### `/executive` — 경영진 대시보드
- **접근**: EXECUTIVE, C_LEVEL, AX_TEAM
- **기능**:
  - 전사 AI 과제 현황 (진행 중 / 상용 전환 / 폐기)
  - 부서별 AI 도입률
  - 월별 토큰 비용 추이 (최근 6개월)
  - 에이전트 상태 분포

---

### 12. 부서장 전용

#### `/dept/tools` — 부서 AI 도구 배정 관리
- **접근**: DEPT_HEAD, AX_TEAM
- **기능**:
  - 부서 쿼터 내 AI 도구 계정 배정 목록
  - 직원별 도구 배정 / 회수
  - 부서 쿼터 잔여량 확인

---

### 13. 관리자 전용 (AX팀)

#### `/admin` — 관리자 대시보드
- **접근**: AX_TEAM
- **기능**: 전체 시스템 현황 요약, 주요 KPI 카드

#### `/admin/employees` — 직원 관리
- **접근**: AX_TEAM
- **기능**: 직원 목록, 레벨/역할 수정, 활성화/비활성화, CSV 내보내기

#### `/admin/tokens` — 토큰 정책 관리
- **접근**: AX_TEAM
- **기능**:
  - TokenPolicy 목록 (GLOBAL / LEVEL / EMPLOYEE scope)
  - 정책 생성/수정/비활성화
  - 미확인 UsageAlert 목록

#### `/admin/distribution` — 배분 정책 관리
- **접근**: AX_TEAM
- **기능**: 레벨별 서비스 접근 정책 등록/관리, ServiceAllocation 내역

#### `/admin/tools` — AI 도구 계정 관리
- **접근**: AX_TEAM
- **기능**: ToolAccount 전체 목록, 도구 추가/수정/삭제

#### `/admin/tools/quota-setup` — 부서별 쿼터 설정
- **접근**: AX_TEAM
- **기능**: DepartmentQuota 등록/수정 (부서별 AI 도구 최대 계정 수, aiDensity 설정)

#### `/admin/literacy` — 리터러시 교육 관리
- **접근**: AX_TEAM
- **기능**: 교육 콘텐츠 관리, 직원별 수료 현황

#### `/admin/skills` — 스킬 등록 관리
- **접근**: AX_TEAM
- **기능**: 전사 AI 스킬 CRUD

#### `/admin/benefits` — 혜택 관리
- **접근**: AX_TEAM
- **기능**: 레벨 상향 혜택 정의 관리

#### `/admin/appeals` — 이의신청 관리
- **접근**: AX_TEAM
- **기능**: 과제 반려에 대한 이의신청 목록, 재검토 처리

#### `/admin/docs` — 거버넌스 문서 관리
- **접근**: AX_TEAM
- **기능**: 거버넌스 문서 등록/버전 관리

#### `/admin/agents` — 에이전트 관리
- **접근**: AX_TEAM
- **기능**: AgentRegistry 직접 관리 (CRUD), KPI 기록, 에이전트 퇴역 처리

#### `/admin/retired` — 퇴역 에이전트 조회
- **접근**: AX_TEAM
- **기능**: RETIRED 상태 에이전트 목록, 지식 추출 내용 확인
