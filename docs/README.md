# AX 거버넌스 문서

> **SSOT 이전 완료 (2026-07-28)**
>
> 모든 거버넌스 문서는 **`ax-request-hub/docs/`** 로 통합 관리됩니다.
> 이 폴더에 직접 문서를 작성하지 마세요.

## 문서 위치

```
ax-request-hub/docs/
├── governance/
│   ├── full/        ← Full 버전 5종 (규정 완결성·감사 대응 기준)
│   ├── slim/        ← SLIM 버전 6종 (현업 실무 적용·의사결정 즉시 참조)
│   │                  ※ Full의 요약이 아닌 독립 버전 — VERSION-GUIDE.md 참조
│   ├── docx/        ← Word 파일 (대외 배포용)
│   └── meta/        ← VERSION-GUIDE·CHANGELOG·SLIM-DIFF·문서체계도
├── operations/      ← 운영 기준 문서 (지침·운영방안·가이드라인)
├── reports/         ← 보고서·구조도
├── proposals/       ← 제안서
├── external/        ← 외부업체 자료
└── archive/         ← 구버전 (OLD·review-2026-07-05)
```
