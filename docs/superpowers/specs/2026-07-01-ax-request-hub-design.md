# AX Request Hub — 설계 스펙

**작성일**: 2026-07-01  
**작성자**: Jarvis (홍인표님 승인)  
**프로젝트**: AX/PI팀 출범 청사진 실행 — 과제 접수·평가·관리 포털  
**상태**: 승인 완료, 구현 계획 대기

---

## 1. 배경 및 목적

삼성자산운용 AX/PI팀(인표님 팀장 내정)의 핵심 In-scope 업무는 "전사 AI 과제 발굴·우선순위·PI(업무 재설계)"다. 이를 위해 현업 부서가 AI 도입 과제를 신청하고 AX팀이 평가·승인하는 체계가 필요하다. 단순 폼·스프레드시트가 아니라, AX팀이 표방하는 "AI를 일하게 만드는 팀"을 시스템 자체가 실증하는 구조로 설계한다.

---

## 2. 핵심 결정 사항

| 항목 | 결정 |
|---|---|
| 시스템 형태 | 에이전트 자동화 포털 (웹앱 + AI 에이전트) |
| 신청 방향 | 양방향 (현업 Bottom-up + AX팀 Top-down 발굴) |
| 평가 기준 | 6차원 종합 스코어카드 (100점 만점) |
| 승인 방식 | 자율 승인 임계값 (G1/G2 + 70점↑ = 자동, G3 또는 70점↓ = 인표님 보고) |
| 인터페이스 | 웹폼 + AI 사전 상담 챗 통합 |

## 4. 컴포넌트 상세

### 4-1. AI 상담 에이전트 (사전 문의 창구)

현업이 자유 언어로 아이디어를 입력하면 에이전트가 순차 질문으로 과제를 구조화한다.

**추출 항목 (7개)**:
1. 과제명 (AI가 제안, 현업이 수정)
2. 신청 부서 / 담당자
3. 현재 업무 방식 (As-Is)
4. 기대 효익 (시간절감·비용절감·품질향상)
5. 관련 데이터 보유 여부 및 기밀등급 추정
6. 예상 사용자 수
7. 내부 챔피언(이 과제를 끌어갈 사람) 유무

대화 종료 시 신청서 초안 자동 생성 → "이 내용으로 신청할까요?" 확인.

### 4-2. 6차원 스코어카드 (평가 엔진)

| 차원 | 배점 | 판단 기준 |
|---|---|---|
| 임팩트 | 25점 | 영향 인원 수·업무 빈도·전략 정합성 |
| ROI | 25점 | 시간절감(h/주)·비용절감(₩)·수익기여 추정 |
| 기밀등급 | 15점 | G1=15, G2=10, G3=3 (G3은 복잡도 가산) |
| 난이도 역산 | 15점 | 낮을수록 고배점 (빠른 win 우선) |
| 현업 준비도 | 10점 | 데이터 가용성·챔피언 유무·As-Is 명확도 |
| 전략 정합성 | 10점 | AX 청사진 등대 과제 및 100일 로드맵 매칭 |

**자율 승인 규칙**:
- G3 과제 → 무조건 인표님 보고 (점수 무관)
- G1/G2 + 총점 ≥ 70점 → 자동 파일럿 승인
- G1/G2 + 총점 68~69점 → "근소 차이 검토 요청"으로 인표님 보고 (경계값 자동 처리 위험 차단)
- G1/G2 + 총점 < 68점 → 인표님 보고

### 4-3. 알림 시스템

**자동 승인 시**:
- 신청자 이메일: "파일럿 승인됨 / 스코어 OO점 / 담당 에이전트 배정 예정"
- AX 포트폴리오 자동 등록

**인표님 보고 시**:
- 텔레그램 알림: 스코어카드 요약 + [승인] [보류] [반려] 버튼
- 인표님이 텔레그램에서 탭 하나로 결재

### 4-4. 관리자 포트폴리오 대시보드

- 파이프라인 뷰: 접수 → 평가 → 파일럿 → 운영 → 완료
- 필터: 부서별·기밀등급별·스코어별·출처(현업신청/AX발굴)별
- AX 자체 발굴 과제 직접 등록 (양방향 대응)
- 월별 승인 건수·평균 스코어·부서별 참여율 통계

## 5. 기술 스택

| 레이어 | 선택 | 이유 |
|---|---|---|
| 프론트엔드 | Next.js + Tailwind CSS | 기존 urango1·blue-seeart 스택 일치 |
| AI 에이전트 | Claude API (claude-sonnet-4-6) | 상담·평가 동일 모델, OpenClaw 래핑 |
| 백엔드 | Next.js API Routes | 단일 레포, 별도 서버 불필요 |
| DB | SQLite (초기) → PostgreSQL (확장) | 빠른 시작, 과제 100건↑ 시 전환 |
| 벡터 검색 | pgvector (추후) | 과거 유사 과제 추천, Snowflake Cortex 이전 가능 |
| 알림 | Gmail API + 텔레그램 (기존 인프라) | 신규 설치 없음 |
| 배포 | 사내 서버 (온프레미스) | 기밀 데이터 외부 유출 방지 정책 준수 |

## 7. 에러 처리

- AI 평가 실패 시: 자동 승인 금지, 무조건 인표님 보고로 폴백
- 상담 중 30분 비활성 시: 임시 저장 후 재접속 시 복원
- 경계값(68~69점) 과제: 자동 승인 대신 "근소 차이 검토 요청"으로 인표님 알림
- 알림 발송 실패 시: DB에 pending 상태로 저장, 재시도 큐

## 8. 테스트 전략

**평가 에이전트 검증**:
- 골든셋: AX 청사진의 기존 등대 과제 5개 + 가상 저스코어 과제 5개
- 기준: 기존 등대 과제 → 70점↑, 저스코어 과제 → 70점↓ 정확히 분류

**상담 에이전트 검증 (3가지 시나리오)**:
1. G1 단순 과제: 계약서 검토 자동화 (데이터 있음, 챔피언 있음)
2. G3 민감 과제: 운용 포지션 AI 분석 (기밀 데이터 관련)
3. 데이터 없는 과제: "AI 뭔가 써보고 싶은데" 수준의 막연한 요청
