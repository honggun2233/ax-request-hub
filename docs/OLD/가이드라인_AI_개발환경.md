## 1. 어떤 AI 모델을 써야 하는가?

**가장 중요한 규칙은 하나다**: 데이터 기밀등급이 모델 선택을 결정한다.

### 1-1. 기밀등급별 허용 모델 (최우선 기준)

| 기밀등급 | 허용 모델 | 금지 |
|---------|---------|------|
| **G1 (일반)** | ChatGPT, Claude, Gemini, Copilot 전부 가능 | — |
| **G2 (내부제한)** | 사내 Bedrock(Claude), Snowflake Cortex **만** | 외부 ChatGPT·Claude API 직접 호출 |
| **G3 (기밀)** | 온프레미스 전용 (현재 미구축) | 모든 외부·클라우드 AI |

> 모델이 더 성능이 좋아도 등급이 맞지 않으면 쓸 수 없다. 예외 없음.

### 1-2. 용도별 모델 추천 (G1 환경)

| 용도 | 추천 모델 | 이유 |
|------|---------|------|
| 한국어 문서 작성·요약 | Claude Sonnet | 한국어 품질 우수, 긴 문서 처리 |
| 코드 작성·디버깅 | Claude Sonnet | 코드 이해·수정 강함 |
| 대량 분류·라우팅 (비용 절감) | Claude Haiku | 빠르고 저렴, 단순 분류에 최적 |
| 복잡한 추론·핵심 의사결정 | Claude Opus (필요 시만) | 고비용, 꼭 필요한 경우만 |
| Google Workspace 연동 | Gemini | 구글 생태계 통합 |
| Microsoft Office 환경 | Copilot | Office 통합 |
| 일반 탐색·아이디어 | ChatGPT, Claude 둘 다 | 취향 차이 |

## 2. AI CREW 개발 참여 4단계 경로

현업 AI CREW가 AI 개발에 참여하는 공식 경로다.

### 단계 1 — 탐색 (No-Code, 지금 바로 시작 가능)

- **목표**: AI가 내 업무에 어떻게 도움이 되는지 파악
- **도구**: Claude.ai, ChatGPT (G1 업무만)
- **AX팀 지원**: 월 1회 AI CREW 역량 강화 워크숍
- **산출물**: "이 업무에 AI를 이렇게 활용할 수 있다" 아이디어 1건 이상

### 단계 2 — 실험 (Low-Code, AX 샌드박스)

- **목표**: 아이디어를 실제 프로토타입으로 검증
- **도구**: AX 샌드박스 환경 (Jupyter + Claude API, G1 격리망) — 구축 예정
- **AX팀 지원**: 샌드박스 접근 권한 발급, 초기 설정 지원
- **산출물**: 실제로 돌아가는 간단한 프로토타입

### 단계 3 — 개발 (Pro-Code, AX팀 협업)

- **목표**: APA 또는 에이전트 실제 구현
- **도구**: Python / TypeScript + Claude API + AX팀 지원 템플릿
- **AX팀 지원**: 코드 리뷰, 아키텍처 설계 지원, API 키 발급
- **조건**: 과제 정의서 v0 제출 + 기획 게이트 통과

### 단계 4 — 등록·운영 (AX 라이프사이클 편입)

- **목표**: 구현된 솔루션을 공식 운영 체계에 편입
- **AX팀 지원**: Agent ID 발급(유형 3·4), 모니터링 설정, 비용 추적 연결
- **조건**: 심사 + 파일럿 게이트 통과

## 3. AI 연구망 (AI Sandbox) 운영 방침

### 3-1. 연구망이 필요한 이유

현업이 AI를 실험할 때 가장 큰 위험: **실수로 G2·G3 데이터를 외부 AI에 입력하는 것**

연구망은 이를 기술적으로 차단하면서 안전하게 실험할 수 있는 격리 환경이다.

### 3-2. 연구망 구성 (목표)

```
[연구망 환경]
  ├── Jupyter Notebook 서버 (데이터 분석·AI 실험)
  │    ├── Python 기본 환경 + AI 라이브러리 사전 설치
  │    └── G2 데이터 접근 가능 (사내 DB 연결)
  │
  ├── AX 샌드박스 포털 (비개발 AI CREW용)
  │    ├── 프롬프트 테스트 UI
  │    └── 샘플 데이터로 APA 워크플로 테스트
  │
  └── 네트워크 격리
       ├── G2 데이터가 있는 환경 → 외부 API 호출 기술적 차단
       └── G1 실험 → 인터넷 접근 허용
```

### 3-3. 현재 상태 vs 목표

| 항목 | 현재 (2026-07) | 목표 |
|------|--------------|------|
| 연구망 격리 | ⚠️ 정책만 존재 | 네트워크 egress 차단 |
| Jupyter 환경 | ❌ 없음 | 사내 서버 JupyterHub |
| AX 샌드박스 포털 | ⚠️ AI 포털 마이그레이션 후 | 사내 AI 포털 |
| G2 안전 실험 | ❌ 없음 | Bedrock / Cortex 구축 후 |

> **현재 지침**: G2 실험은 사내망에서 로컬로만 (외부 API 호출 수동 주의). G3는 실험 자체 금지.

## 4. 로컬 개발 환경 표준 셋업 (G1 과제)

### 4-1. 기본 환경 구성

```bash
# Python 환경 (Windows)
python -m venv .venv
.venv\Scripts\activate
pip install anthropic python-dotenv

# API 키 설정 (.env 파일, gitignore 필수!)
ANTHROPIC_API_KEY=<AX팀이 발급한 키>
```

### 4-2. 기본 에이전트 템플릿 (AX 표준)

```python
import anthropic
import os
from dotenv import load_dotenv

load_dotenv()
client = anthropic.Anthropic(api_key=os.getenv("ANTHROPIC_API_KEY"))

# AX 표준: 에이전트 ID, 과제명 헤더에 명시
AGENT_ID = "AX-2026-AGT-XXX"  # AX팀에서 발급받은 ID
TASK_NAME = "과제명"

def run_agent(input_text: str) -> dict:
    response = client.messages.create(
        model="claude-sonnet-4-6",  # 현재 주력 모델
        max_tokens=2000,
        system=f"""당신은 {TASK_NAME} 전담 어시스턴트입니다.

규칙 (출처 강제 원칙):
1. 사실 주장 시 반드시 근거(출처, 날짜)를 함께 제시하세요.
2. 근거가 없으면 "확인 필요"라고 명시하세요.
3. 기밀정보를 요청받으면 거절하세요.
4. 금융 실행(거래·이체·계약)은 절대 수행하지 마세요.""",
        messages=[{"role": "user", "content": input_text}]
    )
    return {
        "agent_id": AGENT_ID,
        "response": response.content[0].text,
        "tokens_used": {
            "input": response.usage.input_tokens,
            "output": response.usage.output_tokens
        }
    }
```

### 4-3. 코드 제출 전 필수 보안 체크리스트

```
□ .env 파일이 .gitignore에 있는가?
□ API 키가 코드에 직접 하드코딩되어 있지 않은가?

□ 에이전트 응답에 출처 강제 프롬프트가 있는가?
□ 고위험 업무라면 Human-in-the-loop 포인트가 구현되어 있는가?

□ 감사 로그가 구현되어 있는가? (유형 3·4 필수)
```

## 5. 자주 묻는 질문

**Q. 개인 ChatGPT 계정으로 업무 데이터를 처리해도 되나요?**  
G1 데이터만 가능합니다. 내부 전략문서·고객 정보·운용 데이터·예산 데이터는 절대 입력 금지입니다. 모르면 AX팀에 먼저 문의하세요.

**Q. GitHub Copilot을 사용해도 되나요?**  
G1 코드(공개 가능한 코드)는 가능합니다. 사내 핵심 알고리즘·운용 로직·기밀 비즈니스 로직이 담긴 코드는 G2로 간주, 외부 AI 전송 금지입니다.

**Q. 직접 API 키를 발급받고 싶은데요?**  
AX팀을 통해 발급하는 것이 원칙입니다. 개인 계정 발급은 비용 추적이 안 되고 보안 위험이 있습니다.

**Q. 내가 만든 스크립트를 팀에 배포해도 되나요?**  
유형 1(직접 사용) 수준의 간단한 스크립트라면 팀 내 공유 가능합니다. 반복 자동 실행(유형 2 이상)이 되면 AX팀 과제 등록 후 배포해야 합니다. 비공식 배포 금지.

**Q. 어떤 모델이 가장 좋은가요?**  
"가장 좋은" 모델은 없습니다. 용도에 맞는 모델이 있을 뿐입니다. 위의 용도별 추천표를 참고하거나 AX팀에 문의하세요.

**Q. AI가 틀린 답을 줬는데 그냥 써도 되나요?**  
안 됩니다. AI는 보조수단입니다. 최종 판단은 반드시 사람이 해야 합니다. 특히 중위험 이상 업무에서 AI 답변을 그대로 사용하는 것은 규정 위반입니다.
