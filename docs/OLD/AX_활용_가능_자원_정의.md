## 1. AI 모델 자원

### 1-1. 기밀등급별 허용 모델

| 등급 | 허용 모델 | 경로 | 비고 |
|------|---------|------|------|
| G1 (일반) | Claude API (claude-sonnet-4-6) | Anthropic API | 현재 주력 |
| G1 (일반) | Azure OpenAI (GPT-4o) | Azure 구독 | 대안 |
| G2 (내부제한) | AWS Bedrock (Claude) | 사내 VPC | 외부 전송 차단 |
| G2 (내부제한) | Snowflake Cortex | 사내 Snowflake | 데이터 동일 환경에서 처리 |
| G3 (기밀) | 온프레미스 LLM | 사내 서버 | **현재 미구축** — G3 AI 과제 착수 전 정보전략 협의 필요 |

### 1-2. 특수 목적 모델

| 용도 | 모델/서비스 | 등급 |
|------|-----------|------|

| 웹 스크래핑 | Firecrawl | G1 |

## 5. 인력 자원

| 역할 | 현재 가용 인원 | 최대 동시 과제 수 |
|------|--------------|----------------|
| PI / 과제기획 | 인표님 (겸무) | 2~3개 |

| 데이터 엔지니어 | CDO 에이전트 (AI) | 2~3개 |

| 데이터플랫폼팀 | Snowflake 파이프라인 구축 | AX팀장 → 데이터플랫폼팀장 협의 |
| 정보전략팀 | 보안 설정, 네트워크 격리 | 공식 요청서 |
| IT인프라팀 | 서버·환경 제공 | 공식 요청서 |
| 컴플라이언스팀 | G3 과제 사전 검토 | AX팀장 요청 |

## 6. 예산 자원

> **원칙**: AI API 비용은 과제 단위로 추적한다. 사용량이 과제 예산의 80%에 도달하면 AX팀장에게 알림.

| 항목 | 현재 상태 | 비고 |
|------|---------|------|
| Claude API (G1) | 사용 중 | 인표님 계정 |
| Tavily API | 사용 중 | 웹 검색 |
| Firecrawl | 사용 중 | 웹 스크래핑 |
| AWS Bedrock (G2) | 미착수 | 데이터플랫폼 협의 필요 |
| Snowflake Cortex (G2) | 미착수 | 데이터플랫폼 협의 필요 |

## 7. 자원 제약 요약

**현재 할 수 없는 것:**
- G3 AI 처리 (온프레미스 LLM 미구축)
- G2 완전 격리 환경 (Bedrock/Cortex 미착수)
- 24시간 상시 서버 운영 (사내 서버 미배정)

**지금 당장 할 수 있는 것:**
- G1 과제 전체 (Claude API + Vercel/Streamlit)
- G2 과제 개발·프로토타입 (로컬, 외부 전송 수동 주의)
- 공공 API 기반 데이터 파이프라인 (DART, KRX, yfinance)
